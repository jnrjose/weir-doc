## What is WEIR AI?

WEIR AI is a cutting-edge platform designed to address the complexities of **Name, Image, and Likeness (NIL)** usage in digital advertising. In an era where creator content and personal branding are paramount, WEIR AI provides a robust solution for AdTech platforms and advertisers to:

- **Detect NIL Content:** Automatically scan ad creatives (images, videos) to identify the presence of registered public figures, influencers, or any individual with managed likeness rights (referred to as "Personas").
- **Verify License Status:** Check the licensing terms associated with detected Personas to ensure compliance before an ad campaign goes live.
- **Facilitate Rights Management:** Streamline the process of understanding and adhering to usage rights, helping to prevent unauthorized use of NIL and protect all parties involved.
- **Enable Monetization:** For creators and rights holders, WEIR AI offers a pathway to manage and monetize their NIL by connecting them with advertisers through a transparent and controlled system.

Our core value proposition is to bring clarity, compliance, and confidence to the use of NIL in advertising, fostering a fair and efficient ecosystem for creators, advertisers, and AdTech platforms.

## Key Concepts & Terminology

Understanding the following terms is crucial for working effectively with the WEIR AI API:

- **NIL (Name, Image, Likeness):** Refers to the elements of a person's identity that are protected and may require permission or licensing for commercial use, especially in advertising.
- **Persona:** Within the WEIR AI ecosystem, a Persona represents an individual (e.g., celebrity, influencer, public figure, or any registered user) whose NIL is managed through the platform. Each Persona has a unique identifier.
- **License:** An agreement that defines the terms under which a Persona's NIL can be used. This includes conditions like duration, territory, media type, and compensation. WEIR AI helps verify and manage these licenses.
  - **License Types (Examples):** `Monetize` (available for use under specific terms), `DoNotUse` (explicitly not available for use), `Disputed` (terms are under review).
- **Creative:** The actual advertisement content (e.g., an image, a video file, or a URL pointing to such content) that needs to be scanned for NIL.
- **Scan:** The process of analyzing an ad creative using the WEIR AI API to detect any registered Personas and retrieve information about their associated licenses. Each scan generates a unique `scan_id`.
- **Organization:** A company or entity registered on the WEIR AI platform (e.g., an AdTech company like "Yoyodyne Ad Network" or an advertiser). Developers and platforms are typically associated with an Organization.
- **Platform:** A specific AdTech system (e.g., "Yoyodyne DSP") registered under an Organization on WEIR AI, for which API access is managed.
- **API Key:** A unique secret token used to authenticate requests made to the WEIR AI API. It identifies the calling application/platform and grants access to the API's functionalities.
- **Interaction:** An action taken by an advertiser or platform in response to a NIL detection, such as accepting the terms of a license (`AcceptTerms`) or disputing its applicability (`DisputeTerms`). These interactions are reported back to WEIR AI.
- **User Roles:**
  - **Platform Owner (e.g., "Sheryl"):** An administrator within an Organization on WEIR, responsible for managing the Organization's account, platforms, and inviting team members.
  - **Developer (e.g., "Carlton"):** A team member within an Organization, typically responsible for integrating the WEIR AI API with the Organization's platforms.

## API Design Principles & Philosophy

The WEIR AI API is built with the following principles in mind to ensure a positive and productive developer experience:

- **Simplicity and Clarity:** We strive for intuitive endpoint names, clear request/response structures, and straightforward authentication.
- **RESTful Architecture:** Our API adheres to REST (Representational State Transfer) principles, utilizing standard HTTP methods (GET, POST, etc.), status codes, and resource-oriented URLs.
- **JSON for Data Interchange:** All API requests and responses use JSON (JavaScript Object Notation) as the data format, ensuring broad compatibility and ease of parsing.
- **Security First:**
  - **Authentication:** API access is secured using API keys, transmitted via HTTP headers.
  - **HTTPS:** All communication with the API must be over HTTPS to ensure data privacy and integrity.
- **Predictability and Consistency:** We aim for consistent naming conventions, data structures, and error handling across all endpoints.
- **Actionable Error Messages:** When things go wrong, our API provides clear, structured error messages to help you diagnose and resolve issues quickly. These are designed to be both human-readable and machine-parsable.
- **Scalability and Reliability:** The API is designed to handle a high volume of requests and provide a reliable service for your critical workflows.
- **Developer-Centricity:** We are committed to providing comprehensive documentation, useful examples, and responsive support to aid your integration efforts.

By adhering to these principles, we aim to make the WEIR AI API a powerful yet easy-to-use tool for managing NIL in your advertising operations.
