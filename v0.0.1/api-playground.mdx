## Getting Started with the API Playground

The API Playground above allows you to:

- **Test endpoints directly** - Make real API calls to the Weir AI platform
- **Explore request/response schemas** - See exactly what data is expected and returned
- **Authenticate securely** - Use your API keys to test authenticated endpoints
- **View examples** - See sample requests and responses for each endpoint

## Authentication

Most endpoints require authentication using Bearer tokens. You can:

1. **Get your API key** from the Weir AI console
2. **Click the "Authorize" button** in the playground
3. **Enter your Bearer token** in the format: `Bearer YOUR_TOKEN_HERE`

## Available Endpoint Categories

### Authentication (`/auth/*`)
- User registration and login
- Token management and refresh
- Password reset functionality
- Invitee validation

### Organization Management (`/org/*`)
- Organization information and updates
- Team creation and management
- Platform and client management
- Member invitations

### Ad Validation (`/ad/*`)
- Identity validation for advertisements
- Validation status tracking

### Trial Features (`/trial/*`)
- Demo user management
- Image upload and processing
- Fake ad generation

### Event Logging (`/event/*`)
- Event log retrieval

## Tips for Using the Playground

<Tip>
  **Start with Trial Endpoints**: If you don't have API credentials yet, try the `/trial/*` endpoints which don't require authentication.
</Tip>

<Warning>
  **Use Test Environment**: Make sure you're testing against the appropriate environment (staging/production) based on your API key.
</Warning>

<Info>
  **Rate Limits**: Be mindful of API rate limits when testing. The playground will show rate limit headers in responses.
</Info>
