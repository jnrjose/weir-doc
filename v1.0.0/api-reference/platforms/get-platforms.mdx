---
title: "Get Platforms"
api: "GET /platforms"
description: "Retrieve list of available platforms and their configurations"
---

Retrieve a comprehensive list of all available platforms in the Weir AI ecosystem, including their configurations, capabilities, and integration options.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for platform management and integration.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

<CodeBlock lang="bash">
{`Authorization: Bearer <your_jwt_token>`}
</CodeBlock>

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination (default: 1)
  
  **Example**: "1"
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of platforms per page (default: 20, max: 100)
  
  **Example**: "20"
</ParamField>

<ParamField query="category" type="string" required="false">
  Filter platforms by category
  
  **Options**: "ai", "analytics", "integration", "security", "storage"
  
  **Example**: "ai"
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter platforms by status
  
  **Options**: "active", "inactive", "beta", "deprecated"
  
  **Example**: "active"
</ParamField>

<ParamField query="search" type="string" required="false">
  Search platforms by name or description
  
  **Example**: "machine learning"
</ParamField>

## Example Request

<CodeGroup>
```bash cURL
curl -X GET "https://api.example.com/platforms?category=ai&status=active" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://api.example.com/platforms?category=ai&status=active', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

params = {
    'category': 'ai',
    'status': 'active'
}

response = requests.get(
    'https://api.example.com/platforms',
    headers={
        'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
        'Content-Type': 'application/json'
    },
    params=params
)

print(response.json())
```
</CodeGroup>
