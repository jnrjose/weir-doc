---
title: "Get PAX"
api: "GET /pax"
description: "Retrieve list of PAX (Platform Access eXchange) configurations and status"
---

Retrieve a comprehensive list of PAX configurations, which manage platform access and data exchange between different systems and organizations in the Weir AI ecosystem.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for platform access management and data exchange.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
{`Authorization: Bearer <your_jwt_token>`}
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination (default: 1)
  
  **Example**: "1"
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of PAX configurations per page (default: 20, max: 100)
  
  **Example**: "20"
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter PAX configurations by status
  
  **Options**: "active", "inactive", "pending", "error"
  
  **Example**: "active"
</ParamField>

<ParamField query="type" type="string" required="false">
  Filter PAX configurations by type
  
  **Options**: "data_sync", "api_gateway", "webhook", "sftp"
  
  **Example**: "data_sync"
</ParamField>

<ParamField query="organization" type="string" required="false">
  Filter PAX configurations by organization ID
  
  **Example**: "org_1234567890"
</ParamField>

<ParamField query="search" type="string" required="false">
  Search PAX configurations by name or description
  
  **Example**: "customer data sync"
</ParamField>

  -H "Content-Type: application/json"

const response = await fetch('https://api.example.com/pax?status=active&type=data_sync', {

        'Content-Type': 'application/json'

print(response.json())

## Usage Notes

<AccordionGroup>
  <Accordion title="PAX Types" icon="exchange">
    Available PAX types:
    
    - **data_sync**: Synchronize data between platforms
    - **api_gateway**: API gateway for external integrations
    - **webhook**: Webhook-based data exchange
    - **sftp**: Secure file transfer protocol
  </Accordion>
  
  <Accordion title="Configuration Status" icon="info">
    PAX status levels:
    
    - **active**: Fully operational and syncing
    - **inactive**: Temporarily disabled
    - **pending**: Awaiting configuration
    - **error**: Configuration or sync errors
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    To view PAX configurations, you need:
    
    - Valid authentication token
    - PAX management permissions
    - Appropriate role level
  </Accordion>
  
  <Accordion title="Monitoring" icon="chart">
    PAX monitoring features:
    
    - Real-time sync status
    - Success/failure rates
    - Performance metrics
    - Error logging and alerts
  </Accordion>
</AccordionGroup>
