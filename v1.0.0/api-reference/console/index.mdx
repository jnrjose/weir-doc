The Console API provides comprehensive management capabilities for organizations, teams, and users within the Weir AI platform. These endpoints are designed for day-to-day platform operations and management tasks.

## Overview

The Console API is designed for organization administrators, team managers, and platform users who need to manage their workspace, teams, and organizational settings. These endpoints require user authentication and provide access to organization-specific data and operations.

## Authentication

All Console API endpoints require Bearer Token authentication:

<CodeBlock lang="bash">
{`Authorization: Bearer <user_jwt_token>`}
</CodeBlock>

## Rate Limiting

Console API endpoints have standard rate limits:

- **Standard Operations**: 500 requests per hour
- **Team Management**: 100 requests per hour
- **Email Sending**: 50 requests per hour
- **Platform Integration**: 200 requests per hour

## Error Handling

All Console API endpoints return consistent error responses:

<CodeBlock lang="json">
{`{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message",
    "details": {
      "field": "field_name",
      "reason": "Detailed error reason"
    }
  },
  "timestamp": "2024-01-15T10:30:00Z"
}`}
</CodeBlock>

## Common Error Codes

<AccordionGroup>
  <Accordion title="Authentication Errors" icon="exclamation-triangle">
    - `UNAUTHORIZED`: Invalid or expired token
    - `INVALID_CREDENTIALS`: Invalid username or password
    - `TOKEN_EXPIRED`: Access token has expired
    - `INSUFFICIENT_PRIVILEGES`: User lacks required permissions
  </Accordion>
  
  <Accordion title="Validation Errors" icon="exclamation">
    - `VALIDATION_ERROR`: Request data validation failed
    - `REQUIRED_FIELD`: Missing required field
    - `INVALID_FORMAT`: Invalid data format
    - `CONSTRAINT_VIOLATION`: Data constraint violation
  </Accordion>
  
  <Accordion title="Resource Errors" icon="search">
    - `NOT_FOUND`: Resource not found
    - `ALREADY_EXISTS`: Resource already exists
    - `CONFLICT`: Resource conflict
    - `GONE`: Resource no longer available
  </Accordion>
  
  <Accordion title="Permission Errors" icon="user-slash">
    - `FORBIDDEN`: Insufficient permissions
    - `TEAM_ACCESS_REQUIRED`: Team access required
    - `ORGANIZATION_ACCESS_REQUIRED`: Organization access required
    - `ADMIN_ACCESS_REQUIRED`: Admin access required
  </Accordion>
</AccordionGroup>

## Integration Examples

<AccordionGroup>
  <Accordion title="JavaScript SDK" icon="code">
    <CodeBlock lang="javascript">
{`// Initialize the Weir Console API client
const weirClient = new WeirConsoleClient({
  baseURL: 'https://api.example.com',
  apiKey: 'your_api_key'
});

// Get organization information
const orgInfo = await weirClient.getOrganizationInfo();

// Create a new team
const team = await weirClient.createTeam({
  name: 'Development Team',
  description: 'Core development team'
});

// Invite team members
await weirClient.inviteTeamMember(team.id, {
  email: 'member@example.com',
  role: 'Organization_User'
});`}
    </CodeBlock>
  </Accordion>
