---
title: "Invite Team Member"
api: "POST /org/invite/team/member/{teamId}"
description: "Invite a new member to join a team"
---

Invite a new member to join a specific team within your organization. This endpoint sends an invitation to the specified email address with the assigned role and permissions.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team member management and invitations.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

<CodeBlock lang="bash">
{`Authorization: Bearer <your_jwt_token>`}
</CodeBlock>

## Path Parameters

<ParamField path="teamId" type="string" required>
  ID of the team to invite member to
  
  **Example**: "team_1234567890abcdef"
</ParamField>

## Request

<ParamField body="firstname" type="string" required>
  First name of the person being invited
  
  **Example**: "John"
  
  **Constraints**: 
  - Minimum length: 1 character
  - Maximum length: 50 characters
  - Must contain only letters, spaces, hyphens, and apostrophes
</ParamField>

<ParamField body="lastname" type="string" required>
  Last name of the person being invited
  
  **Example**: "Doe"
  
  **Constraints**: 
  - Minimum length: 1 character
  - Maximum length: 50 characters
  - Must contain only letters, spaces, hyphens, and apostrophes
</ParamField>

<ParamField body="email" type="string" required>
  Email address to send the invitation to
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: 
  - Must be a valid email format
  - Must be unique within the organization
  - Will receive the invitation email
</ParamField>

<ParamField body="role" type="string" required>
  Role to assign to the invited member
  
  **Options**: "Organization_User", "Team_Admin", "Viewer"
  
  **Example**: "Organization_User"
  
  **Constraints**: 
  - Must be one of the predefined role values
  - Determines permissions and access level
</ParamField>

<ParamField body="message" type="string" required="false">
  Personal message to include with the invitation
  
  **Example**: "Welcome to our development team!"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional field
</ParamField>

<ParamField body="expires_at" type="string" required="false">
  Invitation expiration date (ISO 8601 format)
  
  **Example**: "2024-02-15T23:59:59Z"
  
  **Constraints**: 
  - Must be a valid ISO 8601 date
  - Must be in the future
  - Default: 7 days from now
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Role Permissions" icon="shield">
    Available roles and their permissions:
    
    - **Organization_User**: Standard team member with basic permissions
    - **Team_Admin**: Can manage team members and settings
    - **Viewer**: Read-only access to team resources
  </Accordion>
  
  <Accordion title="Invitation Process" icon="mail">
    Invitation workflow:
    
    - Invitation email is sent immediately
    - Invitee has 7 days to accept (configurable)
    - Invitation can be cancelled before acceptance
    - Status updates are tracked and logged
  </Accordion>
  
  <Accordion title="Permissions" icon="key">
    To invite team members, you need:
    
    - Valid authentication token
    - Team management permissions
    - Appropriate role level for the team
  </Accordion>
  
  <Accordion title="Rate Limiting" icon="clock">
    Invitation limits:
    
    - Maximum 10 invitations per hour per user
    - Maximum 50 invitations per day per organization
    - Rate limit resets after the specified time
  </Accordion>

{`class BulkTeamInvitations {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async inviteMultipleMembers(teamId, invitations) {
    const results = [];
    const errors = [];
    
    for (const invitation of invitations) {
      try {
        const response = await this.apiClient.makeRequest(\`/org/invite/team/member/\${teamId}\`, {
          method: 'POST',
          body: JSON.stringify(invitation)
        });
        
        if (response.ok) {
          const result = await response.json();
          results.push({
            email: invitation.email,
            success: true,
            data: result.data
          });
        } else {
          const error = await response.json();
          errors.push({
            email: invitation.email,
            success: false,
            error: error.error.message
          });
        }
      } catch (error) {
        errors.push({
          email: invitation.email,
          success: false,
          error: error.message
        });
      }
    }
    
    return {
      results,
      errors,
      summary: {
        total: invitations.length,
        successful: results.length,
        failed: errors.length
      }
    };
  }
  
  async inviteFromCSV(teamId, csvData) {
    const invitations = this.parseCSV(csvData);
    return await this.inviteMultipleMembers(teamId, invitations);
  }
  
  parseCSV(csvData) {
    const lines = csvData.split('\n');
    const headers = lines[0].split(',').map(h => h.trim());
    const invitations = [];
    
    for (let i = 1; i < lines.length; i++) {
      const values = lines[i].split(',').map(v => v.trim());
      const invitation = {
        firstname: values[0],
        lastname: values[1],
        email: values[2],
        role: values[3] || 'Organization_User',
        message: values[4] || '',
        expires_at: values[5] || this.getDefaultExpiration()
      };
      
      invitations.push(invitation);
    }
    
    return invitations;
  }
  
  getDefaultExpiration() {
    const date = new Date();
    date.setDate(date.getDate() + 7); // 7 days from now
    return date.toISOString();

    const report = {
      timestamp: new Date().toISOString(),

        invitation_id: r.data.invitation_id,
        status: r.data.status
      })),
      failed_invitations: results.errors.map(e => ({
        email: e.email,
        error: e.error
      }))
    };

  }
