---
title: "Get Talent"
api: "GET /talent"
description: "Retrieve list of talent profiles and their information"
---

Retrieve a comprehensive list of talent profiles in the Weir AI platform, including their skills, availability, and performance metrics. This endpoint is designed for talent management and recruitment purposes.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for talent management and recruitment.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

<CodeBlock lang="bash">
{`Authorization: Bearer <your_jwt_token>`}
</CodeBlock>

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination (default: 1)
  
  **Example**: "1"
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of talent profiles per page (default: 20, max: 100)
  
  **Example**: "20"
</ParamField>

<ParamField query="skills" type="string" required="false">
  Filter by skills (comma-separated)
  
  **Example**: "javascript,python,react"
</ParamField>

<ParamField query="availability" type="string" required="false">
  Filter by availability status
  
  **Options**: "available", "busy", "unavailable"
  
  **Example**: "available"
</ParamField>

<ParamField query="experience_level" type="string" required="false">
  Filter by experience level
  
  **Options**: "junior", "mid", "senior", "expert"
  
  **Example**: "senior"
</ParamField>

<ParamField query="location" type="string" required="false">
  Filter by location
  
  **Example**: "San Francisco, CA"
</ParamField>

<ParamField query="search" type="string" required="false">
  Search talent by name or skills
  
  **Example**: "full stack developer"
</ParamField>

<ParamField query="sort" type="string" required="false">
  Sort talent profiles by field
  
  **Options**: "name", "experience", "rating", "availability", "created_at"
  
  **Default**: "rating"
</ParamField>

<ParamField query="order" type="string" required="false">
  Sort order
  
  **Options**: "asc", "desc"
  
  **Default**: "desc"
</ParamField>

## Example Request

<CodeGroup>
```bash cURL
curl -X GET "https://api.example.com/talent?skills=javascript,python&availability=available&experience_level=senior" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://api.example.com/talent?skills=javascript,python&availability=available&experience_level=senior', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

params = {
    'skills': 'javascript,python',
    'availability': 'available',
    'experience_level': 'senior'
}

response = requests.get(
    'https://api.example.com/talent',
    headers={
        'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
        'Content-Type': 'application/json'
    },
    params=params
)

print(response.json())
```
</CodeGroup>
