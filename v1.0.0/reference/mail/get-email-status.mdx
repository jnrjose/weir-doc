---
title: "Get Email Status"
api: "GET /mail/status/{messageId}"
description: "Check email delivery status and tracking information"
---

Retrieve the current status and delivery information for a specific email message. This endpoint provides real-time tracking of email delivery, including delivery status, bounce information, and engagement metrics.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for email tracking and delivery monitoring.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="messageId" type="string" required>
  Unique identifier for the email message
  
  **Example**: "msg_1234567890abcdef"
</ParamField>

## Query Parameters

<ParamField query="include_events" type="boolean" required="false">
  Whether to include detailed delivery events
  
  **Example**: true
  
  **Default**: false
</ParamField>

<ParamField query="include_engagement" type="boolean" required="false">
  Whether to include engagement metrics (opens, clicks)
  
  **Example**: true
  
  **Default**: false
</ParamField>

<ParamField query="include_recipients" type="boolean" required="false">
  Whether to include recipient-specific status information
  
  **Example**: false
  
  **Default**: false
</ParamField>

  <Accordion title="Delivery Status" icon="info">
    Email delivery statuses:
    
    - **queued**: Email is queued for delivery
    - **sent**: Email has been sent to the mail server
    - **delivered**: Email has been successfully delivered
    - **bounced**: Email bounced back
    - **failed**: Email delivery failed
    - **opened**: Email has been opened by recipient
  </Accordion>
  
  <Accordion title="Engagement Tracking" icon="chart">
    Engagement metrics:
    
    - **Opens**: Number of times email was opened
    - **Clicks**: Number of link clicks
    - **Open Rate**: Percentage of recipients who opened
    - **Click Rate**: Percentage of recipients who clicked
    - **Time Tracking**: When opens and clicks occurred
  </Accordion>
  
  <Accordion title="Delivery Events" icon="list">
    Event types:
    
    - **sent**: Email was sent to mail server
    - **delivered**: Email was delivered to recipient
    - **bounced**: Email bounced back
    - **opened**: Email was opened
    - **clicked**: Link in email was clicked
    - **unsubscribed**: Recipient unsubscribed
  </Accordion>
  
  <Accordion title="Error Handling" icon="exclamation-triangle">

    - **Error codes**: Specific error identifiers
    - **Error messages**: Human-readable error descriptions
    - **Error details**: Additional context and troubleshooting
    - **Retry information**: Whether the email will be retried

    ```javascript
class EmailStatusTracker {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async getEmailStatus(messageId, includeEngagement = true) {
    try {
      const response = await this.apiClient.makeRequest(`/mail/status/${messageId}`, {
        method: 'GET',
        params: {
          include_events: true,
          include_engagement: includeEngagement,
          include_recipients: true
        }
      });
      
      if (!response.ok) {
        throw new Error('Failed to get email status');
      }
      
      return await response.json();
      
    } catch (error) {
      console.error('Error getting email status:', error);
      throw error;
    }
  }
  
  async trackEmailDelivery(messageId) {
    const status = await this.getEmailStatus(messageId);
    const data = status.data;
    
    return {
      messageId: data.message_id,
      status: data.status,
      delivered: data.status === 'delivered',
      bounced: data.status === 'bounced',
      failed: data.status === 'failed',
      openRate: data.engagement?.open_rate || 0,
      clickRate: data.engagement?.click_rate || 0,
      lastOpened: data.engagement?.last_opened,
      lastClicked: data.engagement?.last_clicked
    };
  }
  
  async getEmailEngagement(messageId) {
    const status = await this.getEmailStatus(messageId, true);
    return status.data.engagement;
  }
  
  async getEmailEvents(messageId) {
    const status = await this.getEmailStatus(messageId);
    return status.data.events;
  }
}
```

    ```python
import requests
from typing import Dict, List, Optional
from datetime import datetime

class EmailMonitor:
    def __init__(self, api_client):
        self.api_client = api_client
    
    def get_email_status(self, 
                        message_id: str,
                        include_events: bool = True,
                        include_engagement: bool = True,
                        include_recipients: bool = False) -> Dict:
        """Get email delivery status and tracking information"""
        try:
            params = {
                "include_events": include_events,
                "include_engagement": include_engagement,
                "include_recipients": include_recipients
            }
            
            response = self.api_client.get(f'/mail/status/{message_id}', params=params)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to get email status: {e}")
            raise
    
    def is_email_delivered(self, message_id: str) -> bool:
        """Check if email was successfully delivered"""
        result = self.get_email_status(message_id)
        return result.get("data", {}).get("status") == "delivered"
    
    def get_engagement_metrics(self, message_id: str) -> Dict:
        """Get email engagement metrics"""
        result = self.get_email_status(message_id, include_engagement=True)
        return result.get("data", {}).get("engagement", {})
    
    def get_delivery_events(self, message_id: str) -> List[Dict]:
        """Get email delivery events"""
        result = self.get_email_status(message_id, include_events=True)
        return result.get("data", {}).get("events", [])
    
    def get_bounce_reasons(self, message_id: str) -> List[str]:
        """Get bounce reasons for failed deliveries"""
        result = self.get_email_status(message_id, include_recipients=True)
        recipients = result.get("data", {}).get("recipients", [])
        
        bounce_reasons = []
        for recipient in recipients:
            if recipient.get("status") == "bounced":
                bounce_reason = recipient.get("bounce_reason")
                if bounce_reason:
                    bounce_reasons.append(bounce_reason)
        
        return bounce_reasons
    
    def get_email_summary(self, message_id: str) -> Dict:
        """Get comprehensive email summary"""
        result = self.get_email_status(message_id, True, True, True)
        data = result.get("data", {})
        
        return {
            "message_id": data.get("message_id"),
            "subject": data.get("subject"),
            "status": data.get("status"),
            "sent_at": data.get("sent_at"),
            "delivered_at": data.get("delivered_at"),
            "open_rate": data.get("engagement", {}).get("open_rate", 0),
            "click_rate": data.get("engagement", {}).get("click_rate", 0),
            "total_opens": data.get("engagement", {}).get("opens", 0),
            "total_clicks": data.get("engagement", {}).get("clicks", 0),
            "has_errors": data.get("error") is not None
        }
```
