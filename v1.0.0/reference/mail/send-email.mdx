---
title: "Send Email"
api: "POST /mail/send"
description: "Send email notifications and communications"
---

Send email notifications, invitations, alerts, and other communications through the Weir AI platform. This endpoint supports various email types including team invitations, system notifications, and custom messages.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for email communication and notifications.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="to" type="array" required>
  List of recipient email addresses
  
  **Example**: ["user@example.com", "admin@example.com"]
  
  **Constraints**: 
  - Must be valid email addresses
  - Maximum 50 recipients per request
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line
  
  **Example**: "Welcome to Weir AI Platform"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Must not be empty
</ParamField>

<ParamField body="template" type="string" required>
  Email template to use
  
  **Options**: "welcome", "invitation", "notification", "alert", "custom"
  
  **Example**: "welcome"
</ParamField>

<ParamField body="variables" type="object" required="false">
  Template variables for dynamic content
  
  **Example**: {"user_name": "John Doe", "team_name": "Development Team"}
</ParamField>

<ParamField body="priority" type="string" required="false">
  Email priority level
  
  **Options**: "low", "normal", "high", "urgent"
  
  **Default**: "normal"
  
  **Example**: "high"
</ParamField>

<ParamField body="cc" type="array" required="false">
  List of CC email addresses
  
  **Example**: ["manager@example.com"]
  
  **Constraints**: 
  - Must be valid email addresses
  - Maximum 10 CC recipients
</ParamField>

<ParamField body="bcc" type="array" required="false">
  List of BCC email addresses
  
  **Example**: ["audit@example.com"]
  
  **Constraints**: 
  - Must be valid email addresses
  - Maximum 10 BCC recipients
</ParamField>

<ParamField body="attachments" type="array" required="false">
  List of file attachments
  
  **Example**: [{"filename": "document.pdf", "content": "base64_encoded_content", "type": "application/pdf"}]
</ParamField>

<ParamField body="schedule" type="string" required="false">
  Schedule email for future delivery (ISO 8601 format)
  
  **Example**: "2024-01-20T09:00:00Z"
</ParamField>

</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Email Templates" icon="file-text">
    Available email templates:
    
    - **welcome**: Welcome new users to the platform
    - **invitation**: Team and organization invitations
    - **notification**: System notifications and alerts
    - **alert**: Critical alerts and warnings
    - **custom**: Custom email content
  </Accordion>
  
  <Accordion title="Rate Limits" icon="clock">
    Email sending limits:
    
    - **Free tier**: 100 emails per day
    - **Pro tier**: 1,000 emails per day
    - **Enterprise**: 10,000 emails per day
    - **Burst limit**: 50 emails per minute
  </Accordion>
  
  <Accordion title="Template Variables" icon="code">
    Common template variables:
    
    - `user_name`: Recipient's name
    - `team_name`: Team or organization name
    - `inviter_name`: Name of person sending invitation
    - `platform_url`: Link to the platform
    - `support_email`: Support contact email
  </Accordion>
  
  <Accordion title="Delivery Status" icon="check">
    Email delivery tracking:
    
    - **sent**: Email queued for delivery
    - **delivered**: Email successfully delivered
    - **failed**: Email delivery failed
    - **bounced**: Email bounced back
    - **opened**: Email was opened by recipient
  </Accordion>
</AccordionGroup>

class EmailService {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async sendWelcomeEmail(userEmail, userName, teamName) {
    try {
      const response = await this.apiClient.makeRequest('/mail/send', {
        method: 'POST',
        body: JSON.stringify({
          to: [userEmail],
          subject: 'Welcome to Weir AI Platform',
          template: 'welcome',
          variables: {
            user_name: userName,
            team_name: teamName
          },
          priority: 'normal'
        })
      });
      
      if (!response.ok) {
        throw new Error('Failed to send welcome email');
      }
      
      return await response.json();
      
    } catch (error) {
      console.error('Error sending welcome email:', error);
      throw error;
    }
  }
  
  async sendTeamInvitation(emails, teamName, inviterName) {
    try {
      const response = await this.apiClient.makeRequest('/mail/send', {
        method: 'POST',
        body: JSON.stringify({
          to: emails,
          subject: 'Invitation to join ' + teamName,
          template: 'invitation',
          variables: {
            team_name: teamName,
            inviter_name: inviterName
          },
          priority: 'normal'
        })
      });
      
      if (!response.ok) {
        throw new Error('Failed to send team invitation');
      }
      
      return await response.json();
      
    } catch (error) {
      console.error('Error sending team invitation:', error);
      throw error;
    }
  }
}

import requests
from datetime import datetime

class AlertService:
    def __init__(self, api_client):
        self.api_client = api_client
    
    def send_system_alert(self, alert_type, message, recipients):
        """Send system alert to administrators"""
        try:
            payload = {
                "to": recipients,
                "subject": f"System Alert: {alert_type}",
                "template": "alert",
                "variables": {
                    "alert_type": alert_type,
                    "message": message,
                    "timestamp": datetime.utcnow().isoformat()
                },
                "priority": "high"
            }
            
            response = self.api_client.post('/mail/send', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to send system alert: {e}")
            raise
    
    def send_maintenance_notification(self, maintenance_time, affected_services):
        """Send maintenance notification to users"""
        try:
            payload = {
                "to": ["all-users@example.com"],
                "subject": "Scheduled Maintenance Notification",
                "template": "notification",
                "variables": {
                    "maintenance_time": maintenance_time,
                    "affected_services": ", ".join(affected_services)
                },
                "priority": "normal"
            }
            
            response = self.api_client.post('/mail/send', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to send maintenance notification: {e}")
            raise
