---
title: "Get Cards"
api: "GET /org/cards"
description: "Retrieve list of organization cards and payment methods"
---

Retrieve a paginated list of all cards and payment methods associated with the organization. This endpoint provides comprehensive card information including status, type, and billing details.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for organization payment method management.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination (default: 1)
  
  **Example**: "1"
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of cards per page (default: 20, max: 100)
  
  **Example**: "20"
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter cards by status
  
  **Options**: "active", "inactive", "expired", "pending"
  
  **Example**: "active"
</ParamField>

<ParamField query="type" type="string" required="false">
  Filter cards by type
  
  **Options**: "credit", "debit", "prepaid", "virtual"
  
  **Example**: "credit"
</ParamField>

<ParamField query="sort" type="string" required="false">
  Sort cards by field
  
  **Options**: "created_at", "updated_at", "last_used", "expiry_date"
  
  **Default**: "created_at"
</ParamField>

<ParamField query="order" type="string" required="false">
  Sort order
  
  **Options**: "asc", "desc"
  
  **Default**: "desc"
</ParamField>

## Example Request

<CodeGroup>
```bash cURL
curl -X GET "https://api.example.com/org/cards?page=1&limit=10&status=active" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://api.example.com/org/cards?page=1&limit=10&status=active', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

params = {
    'page': 1,
    'limit': 10,
    'status': 'active'
}

response = requests.get(
    'https://api.example.com/org/cards',
    headers={
        'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
        'Content-Type': 'application/json'
    },
    params=params
)

print(response.json())
```
</CodeGroup>

## Usage Notes

<AccordionGroup>
  <Accordion title="Permissions" icon="shield">
    To view cards, you need:
    
    - Valid authentication token
    - Organization admin or billing manager role
    - Appropriate access level for payment methods
  </Accordion>
  
  <Accordion title="Card Information" icon="credit-card">
    Card details include:
    
    - Masked card numbers (last 4 digits only)
    - Expiry dates for monitoring
    - Usage history and status
    - Default payment method indicator
  </Accordion>
  
  <Accordion title="Security" icon="lock">
    Security considerations:
    
    - Full card numbers are never exposed
    - Sensitive data is encrypted at rest
    - Access is logged for audit purposes
    - PCI DSS compliance maintained
  </Accordion>
</AccordionGroup>
