---
title: "Create Client"
api: "POST /clients"
description: "Create a new API client for the organization"
---

Create a new API client with specified permissions and configurations. This endpoint allows you to set up API clients for different applications, integrations, or services that need to access your organization's APIs.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for API client management and configuration.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  Name of the API client
  
  **Example**: "Mobile App Client"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must be unique within the organization
</ParamField>

<ParamField body="description" type="string" required="false">
  Description of the API client's purpose
  
  **Example**: "API client for iOS and Android mobile applications"
  
  **Constraints**: 
  - Maximum length: 500 characters
</ParamField>

<ParamField body="type" type="string" required>
  Type of API client
  
  **Options**: "web", "mobile", "server", "integration", "desktop"
  
  **Example**: "mobile"
</ParamField>

<ParamField body="permissions" type="array" required>
  List of permissions to grant to the client
  
  **Example**: ["read:teams", "write:teams", "read:members"]
  
  **Available Permissions**:
  - `read:*` - Read access to all resources
  - `write:*` - Write access to all resources
  - `read:teams` - Read team information
  - `write:teams` - Create and modify teams
  - `read:members` - Read member information
  - `write:members` - Create and modify members
  - `read:organization` - Read organization information
  - `write:organization` - Modify organization settings
  - `admin:*` - Administrative access
</ParamField>

<ParamField body="redirect_uris" type="array" required="false">
  List of allowed redirect URIs (for web clients)
  
  **Example**: ["https://app.example.com/callback", "https://localhost:3000/callback"]
  
  **Constraints**: 
  - Must be valid URLs
  - Maximum 10 redirect URIs
</ParamField>

<ParamField body="scopes" type="array" required="false">
  OAuth scopes for the client
  
  **Example**: ["read", "write", "admin"]
  
  **Available Scopes**:
  - `read` - Read access
  - `write` - Write access
  - `admin` - Administrative access
  - `offline_access` - Offline access
</ParamField>

<ParamField body="rate_limits" type="object" required="false">
  Rate limiting configuration for the client
  
  **Properties**:
  - `requests_per_hour` (integer): Maximum requests per hour
  - `requests_per_day` (integer): Maximum requests per day
  - `burst_limit` (integer): Maximum burst requests
</ParamField>

<ParamField body="expires_at" type="string" required="false">
  Client expiration date (ISO 8601 format)
  
  **Example**: "2024-12-31T23:59:59Z"
  
  **Note**: If not provided, client will not expire
</ParamField>

<ParamField body="settings" type="object" required="false">
  Additional client-specific settings
  
  **Properties**:
  - `auto_approve` (boolean): Whether to auto-approve requests
  - `require_https` (boolean): Whether to require HTTPS
  - `allowed_ips` (array): List of allowed IP addresses
  - `webhook_url` (string): Webhook URL for notifications
</ParamField>

import requests
from typing import Dict, List, Optional

class ClientManager:
    def __init__(self, api_client):
        self.api_client = api_client
    
    def create_client(self, 
                     name: str,
                     description: str,
                     client_type: str,
                     permissions: List[str],
                     redirect_uris: Optional[List[str]] = None,
                     scopes: Optional[List[str]] = None,
                     rate_limits: Optional[Dict] = None,
                     settings: Optional[Dict] = None) -> Dict:
        """Create a new API client"""
        try:
            payload = {
                "name": name,
                "description": description,
                "type": client_type,
                "permissions": permissions,
                "redirect_uris": redirect_uris or [],
                "scopes": scopes or [],
                "rate_limits": {
                    "requests_per_hour": rate_limits.get("requests_per_hour", 1000) if rate_limits else 1000,
                    "requests_per_day": rate_limits.get("requests_per_day", 10000) if rate_limits else 10000,
                    "burst_limit": rate_limits.get("burst_limit", 100) if rate_limits else 100
                },
                "settings": {
                    "auto_approve": settings.get("auto_approve", False) if settings else False,
                    "require_https": settings.get("require_https", True) if settings else True,
                    "allowed_ips": settings.get("allowed_ips", []) if settings else [],
                    "webhook_url": settings.get("webhook_url") if settings else None
                }
            }
            
            response = self.api_client.post('/clients', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to create client: {e}")
            raise
    
    def create_mobile_client(self, 
                           name: str,
                           description: str,
                           permissions: List[str]) -> Dict:
        """Create a mobile API client"""
        return self.create_client(
            name=name,
            description=description,
            client_type="mobile",
            permissions=permissions,
            scopes=["read", "write"],
            rate_limits={
                "requests_per_hour": 1000,
                "requests_per_day": 10000,
                "burst_limit": 100
            },
            settings={
                "auto_approve": False,
                "require_https": True
            }
        )
    
    def create_web_client(self, 
                         name: str,
                         description: str,
                         permissions: List[str],
                         redirect_uris: List[str]) -> Dict:
        """Create a web API client"""
        return self.create_client(
            name=name,
            description=description,
            client_type="web",
            permissions=permissions,
            redirect_uris=redirect_uris,
            scopes=["read", "write", "offline_access"],
            rate_limits={
                "requests_per_hour": 2000,
                "requests_per_day": 20000,
                "burst_limit": 200
            },
            settings={
                "auto_approve": False,
                "require_https": True
            }
        )
    
    def create_server_client(self, 
                           name: str,
                           description: str,
                           permissions: List[str]) -> Dict:
        """Create a server-to-server API client"""
        return self.create_client(
            name=name,
            description=description,
            client_type="server",
            permissions=permissions,
            scopes=["read", "write", "admin"],
            rate_limits={
                "requests_per_hour": 5000,
                "requests_per_day": 50000,
                "burst_limit": 500
            },
            settings={
                "auto_approve": True,
                "require_https": True
            }
        )
