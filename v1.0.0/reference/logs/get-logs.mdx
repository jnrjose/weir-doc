---
title: "Get Logs"
api: "GET /logs"
description: "Retrieve system and application logs with filtering and search capabilities"
---

Retrieve system logs, application logs, and audit trails with comprehensive filtering, search, and pagination capabilities. This endpoint provides detailed logging information for monitoring, debugging, and compliance purposes.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for system monitoring and audit trail access.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination (default: 1)
  
  **Example**: "1"
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of logs per page (default: 50, max: 1000)
  
  **Example**: "50"
</ParamField>

<ParamField query="level" type="string" required="false">
  Filter logs by severity level
  
  **Options**: "debug", "info", "warn", "error", "fatal"
  
  **Example**: "error"
</ParamField>

<ParamField query="source" type="string" required="false">
  Filter logs by source component
  
  **Options**: "api", "auth", "database", "external", "system"
  
  **Example**: "api"
</ParamField>

<ParamField query="start_date" type="string" required="false">
  Start date for log filtering (ISO 8601 format)
  
  **Example**: "2024-01-01T00:00:00Z"
</ParamField>

<ParamField query="end_date" type="string" required="false">
  End date for log filtering (ISO 8601 format)
  
  **Example**: "2024-01-31T23:59:59Z"
</ParamField>

<ParamField query="search" type="string" required="false">
  Search logs by message content
  
  **Example**: "authentication failed"
</ParamField>

<ParamField query="user_id" type="string" required="false">
  Filter logs by user ID
  
  **Example**: "user_1234567890"
</ParamField>

<ParamField query="ip_address" type="string" required="false">
  Filter logs by IP address
  
  **Example**: "192.168.1.100"
</ParamField>

## Example Request

<CodeGroup>
```bash cURL
curl -X GET "https://api.example.com/logs?level=error&start_date=2024-01-01T00:00:00Z&end_date=2024-01-31T23:59:59Z" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://api.example.com/logs?level=error&start_date=2024-01-01T00:00:00Z&end_date=2024-01-31T23:59:59Z', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

params = {
    'level': 'error',
    'start_date': '2024-01-01T00:00:00Z',
    'end_date': '2024-01-31T23:59:59Z'
}

response = requests.get(
    'https://api.example.com/logs',
    headers={
        'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
        'Content-Type': 'application/json'
    },
    params=params
)

print(response.json())
```
</CodeGroup>

## Usage Notes

<AccordionGroup>
  <Accordion title="Log Levels" icon="info">
    Available log levels:
    
    - **debug**: Detailed information for debugging
    - **info**: General information about system operation
    - **warn**: Warning messages for potential issues
    - **error**: Error messages for failed operations
    - **fatal**: Critical errors that may cause system failure
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    To view logs, you need:
    
    - Valid authentication token
    - Admin role with log viewing permissions
    - Appropriate access level for sensitive data
  </Accordion>
  
  <Accordion title="Log Retention" icon="clock">
    Log retention policies:
    
    - Debug logs: 7 days
    - Info logs: 30 days
    - Warning logs: 90 days
    - Error logs: 1 year
    - Fatal logs: 2 years
  </Accordion>
  
  <Accordion title="Search Capabilities" icon="search">
    Advanced search features:
    
    - Full-text search across log messages
    - Filter by date ranges
    - Filter by user, IP, or source
    - Combine multiple filters
    - Export search results
  </Accordion>
</AccordionGroup>
