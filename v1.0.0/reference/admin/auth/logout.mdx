---
title: "Admin Logout"
api: "POST /auth/logout"
description: "Logout and invalidate the current admin session"
---

Logout from the admin system and invalidate the current session. This endpoint ensures secure session termination and clears authentication tokens.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for secure admin session management within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="logout_all_sessions" type="boolean" required="false">
  Whether to logout from all admin sessions
  
  **Example**: true
  
  **Default**: false
  
  **Note**: If true, invalidates all admin sessions for the user
</ParamField>

<ParamField body="reason" type="string" required="false">
  Reason for logout (for audit purposes)
  
  **Example**: "User requested logout"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Optional but recommended for audit trails
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the logout was successful
</ResponseField>

<ResponseField name="data" type="object">
  Contains logout information
</ResponseField>

<ResponseField name="data.logout_time" type="string">
  ISO 8601 timestamp when the logout occurred
</ResponseField>

<ResponseField name="data.sessions_invalidated" type="integer">
  Number of sessions that were invalidated
</ResponseField>

<ResponseField name="data.logout_reason" type="string">
  Reason for the logout (if provided)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Session Management" icon="users">
    Session features:
    
    - **Single Session Logout**: Logout from current session only
    - **All Sessions Logout**: Invalidate all admin sessions for the user
    - **Session Tracking**: Track logout events for audit purposes
    - **Token Invalidation**: Immediately invalidate JWT tokens
  </Accordion>
  
  <Accordion title="Security Features" icon="shield">
    Security considerations:
    
    - **Immediate Invalidation**: Tokens are invalidated immediately
    - **Audit Trail**: All logout events are logged
    - **Session Cleanup**: Clean up server-side session data
    - **Client Cleanup**: Clear client-side tokens and cookies
  </Accordion>
  
  <Accordion title="Best Practices" icon="check">
    Recommended practices:
    
    - **Always Logout**: Logout when done with admin tasks
    - **All Sessions**: Use logout_all_sessions for security
    - **Audit Reason**: Provide reason for audit purposes
    - **Client Cleanup**: Clear tokens from client storage
  </Accordion>

<AccordionGroup>
  <Accordion title="Admin Logout Service" icon="cog">
    ```javascript
    class AdminLogoutService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async logout(logoutAllSessions = false, reason = null) {
        try {
          const response = await this.apiClient.makeRequest('/auth/logout', {
            method: 'POST',
            body: JSON.stringify({
              logout_all_sessions: logoutAllSessions,
              reason: reason
            })
          });
          
          if (!response.ok) {
            throw new Error('Failed to logout');
          }
          
          const result = await response.json();
          
          // Clear client-side tokens
          this.clearClientTokens();
          
          // Log logout success
          console.log(`Logout successful: ${result.data.sessions_invalidated} sessions invalidated`);
          
          return result;
          
        } catch (error) {
          console.error('Error during logout:', error);
          throw error;
        }
      }
      
      async logoutCurrentSession(reason = null) {
        return this.logout(false, reason);
      }
      
      async logoutAllSessions(reason = null) {
        return this.logout(true, reason);
      }
      
      clearClientTokens() {
        // Clear localStorage
        localStorage.removeItem('admin_token');
        localStorage.removeItem('admin_refresh_token');
        
        // Clear sessionStorage
        sessionStorage.removeItem('admin_token');
        sessionStorage.removeItem('admin_refresh_token');
        
        // Clear cookies (if using cookies)
        document.cookie = 'admin_token=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;';
        document.cookie = 'admin_refresh_token=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;';
      }
      
      async secureLogout(reason = 'Security logout') {
        try {
          // Logout from all sessions
          const result = await this.logoutAllSessions(reason);
          
          // Clear all client-side data
          this.clearClientTokens();
          
          // Redirect to login page
          window.location.href = '/admin/login';
          
          return result;
          
        } catch (error) {
          console.error('Error during secure logout:', error);
          // Still clear client-side data even if server logout fails
          this.clearClientTokens();
          window.location.href = '/admin/login';
          throw error;
        }
      }
    }
    
    // Usage example
    const adminLogoutService = new AdminLogoutService(apiClient);
    
    // Logout from current session
    await adminLogoutService.logoutCurrentSession('User requested logout');
    
    // Logout from all sessions
    await adminLogoutService.logoutAllSessions('Security logout');
    
    // Secure logout with cleanup
    await adminLogoutService.secureLogout('Session timeout');
    ```

  <Accordion title="Python Admin Client" icon="python">
    ```python
    import requests
    from typing import Optional
    
    class AdminLogoutClient:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def logout(self, logout_all_sessions: bool = False, reason: Optional[str] = None) -> dict:
            """Logout from admin system"""
            try:
                payload = {
                    "logout_all_sessions": logout_all_sessions
                }
                
                if reason:
                    payload["reason"] = reason
                
                response = self.api_client.post('/auth/logout', json=payload)
                response.raise_for_status()
                
                result = response.json()
                print(f"Logout successful: {result['data']['sessions_invalidated']} sessions invalidated")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error during logout: {e}")
                raise
        
        def logout_current_session(self, reason: Optional[str] = None) -> dict:
            """Logout from current session only"""
            return self.logout(False, reason)
        
        def logout_all_sessions(self, reason: Optional[str] = None) -> dict:
            """Logout from all sessions"""
            return self.logout(True, reason)
        
        def secure_logout(self, reason: str = "Security logout") -> dict:
            """Secure logout with cleanup"""
            try:
                # Logout from all sessions
                result = self.logout_all_sessions(reason)
                
                # Clear client-side tokens
                self.clear_client_tokens()
                
                return result
                
            except Exception as e:
                print(f"Error during secure logout: {e}")
                # Still clear client-side data
                self.clear_client_tokens()
                raise
        
        def clear_client_tokens(self):
            """Clear client-side authentication tokens"""
            # Clear from memory
            if hasattr(self.api_client, 'token'):
                self.api_client.token = None
            if hasattr(self.api_client, 'refresh_token'):
                self.api_client.refresh_token = None
            
            # Clear from file storage (if applicable)
            try:
                import os
                token_file = os.path.expanduser('~/.weir_admin_token')
                if os.path.exists(token_file):
                    os.remove(token_file)
            except Exception:
                pass
        
        def logout_on_timeout(self) -> dict:
            """Logout when session times out"""
            return self.secure_logout("Session timeout")
        
        def logout_on_security_breach(self) -> dict:
            """Logout due to security breach"""
            return self.secure_logout("Security breach detected")
    
    # Usage example
    admin_logout_client = AdminLogoutClient(api_client)
    
    # Logout from current session
    result = admin_logout_client.logout_current_session("User requested logout")
    
    # Logout from all sessions
    result = admin_logout_client.logout_all_sessions("Security logout")
    
    # Secure logout
    result = admin_logout_client.secure_logout("Session timeout")
    
    # Logout on timeout
    result = admin_logout_client.logout_on_timeout()
    
    # Logout on security breach
    result = admin_logout_client.logout_on_security_breach()
    ```
