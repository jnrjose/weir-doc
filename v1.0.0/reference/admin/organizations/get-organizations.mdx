---
title: "Get Organizations"
api: "GET /admin/organizations"
description: "Retrieve list of all organizations in the system"
---

Retrieve a comprehensive list of all organizations in the system with detailed information about their status, configuration, and usage statistics. This endpoint provides admin-level visibility into all organizations.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for system administration and monitoring within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of organizations to return per page
  
  **Example**: "20"
  
  **Default**: "20"
  
  **Constraints**: 
  - Must be between 1 and 100
  - Recommended: 20-50 for optimal performance
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter organizations by status
  
  **Options**: "active", "inactive", "suspended", "pending", "trial"
  
  **Example**: "active"
  
  **Default**: "active"
  
  **Note**: If not specified, returns organizations of all statuses
</ParamField>

<ParamField query="plan" type="string" required="false">
  Filter organizations by subscription plan
  
  **Options**: "free", "basic", "professional", "enterprise", "custom"
  
  **Example**: "enterprise"
  
  **Note**: If not specified, returns organizations of all plans
</ParamField>

<ParamField query="search" type="string" required="false">
  Search organizations by name or domain
  
  **Example**: "acme corp"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches organization name and domain
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort organizations by specified field
  
  **Options**: "name", "created_at", "updated_at", "status", "plan", "user_count", "last_activity"
  
  **Example**: "created_at"
  
  **Default**: "created_at"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "desc"
</ParamField>

<ParamField query="created_after" type="string" required="false">
  Filter organizations created after this date (ISO 8601 format)
  
  **Example**: "2024-01-01T00:00:00Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be more than 2 years in the past
</ParamField>

<ParamField query="created_before" type="string" required="false">
  Filter organizations created before this date (ISO 8601 format)
  
  **Example**: "2024-12-31T23:59:59Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be in the future
</ParamField>

<ParamField query="include_usage" type="string" required="false">
  Whether to include usage statistics
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Default**: "false"
  
  **Note**: Setting to true will include detailed usage metrics
</ParamField>

<ParamField query="include_billing" type="string" required="false">
  Whether to include billing information
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Default**: "false"
  
  **Note**: Setting to true will include billing and subscription details
</ParamField>

    import requests
    from typing import Dict, List, Optional
    from datetime import datetime, timedelta
    
    class AdminOrganizationManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_organizations(self, 
                            page: int = 1,
                            limit: int = 20,
                            status: Optional[str] = None,
                            plan: Optional[str] = None,
                            search: Optional[str] = None,
                            sort_by: str = "created_at",
                            sort_order: str = "desc",
                            created_after: Optional[str] = None,
                            created_before: Optional[str] = None,
                            include_usage: bool = False,
                            include_billing: bool = False) -> Dict:
            """Get organizations with optional filtering and pagination"""
            try:
                params = {
                    "page": page,
                    "limit": limit,
                    "sort_by": sort_by,
                    "sort_order": sort_order,
                    "include_usage": str(include_usage).lower(),
                    "include_billing": str(include_billing).lower()
                }
                
                if status:
                    params["status"] = status
                if plan:
                    params["plan"] = plan
                if search:
                    params["search"] = search
                if created_after:
                    params["created_after"] = created_after
                if created_before:
                    params["created_before"] = created_before
                
                response = self.api_client.get('/admin/organizations', params=params)
                response.raise_for_status()
                
                return response.json()
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting organizations: {e}")
                raise
        
        def get_active_organizations(self) -> Dict:
            """Get all active organizations"""
            return self.get_organizations(
                status="active",
                sort_by="last_activity",
                sort_order="desc"
            )
        
        def get_trial_organizations(self) -> Dict:
            """Get all trial organizations"""
            return self.get_organizations(
                status="trial",
                sort_by="trial_ends_at",
                sort_order="asc"
            )
        
        def get_enterprise_organizations(self) -> Dict:
            """Get all enterprise organizations"""
            return self.get_organizations(
                plan="enterprise",
                status="active",
                include_usage=True,
                include_billing=True
            )
        
        def get_organizations_by_plan(self, plan: str) -> Dict:
            """Get organizations by subscription plan"""
            return self.get_organizations(
                plan=plan,
                status="active",
                sort_by="created_at",
                sort_order="desc"
            )
        
        def search_organizations(self, search_term: str) -> Dict:
            """Search organizations by name or domain"""
            return self.get_organizations(
                search=search_term,
                sort_by="name",
                sort_order="asc"
            )
        
        def get_organizations_with_usage(self) -> Dict:
            """Get organizations with usage statistics"""
            return self.get_organizations(
                include_usage=True,
                sort_by="usage_stats.api_calls",
                sort_order="desc"
            )

                sort_by="billing_info.amount",
                sort_order="desc"

            """Get organizations created in the last N days"""
            end_date = datetime.now()
            start_date = end_date - timedelta(days=days)
            
            return self.get_organizations(

                    if trial_end <= cutoff_date:

                amount = org.get("billing_info", {}).get("amount", 0)

                revenue_by_plan[plan] += amount
