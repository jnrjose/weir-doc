---
title: "Create Log Entry"
api: "POST /logs/create"
description: "Create a new log entry in the system"
---

Create a new log entry in the system for tracking events, errors, and system activities. This endpoint allows admins to manually create log entries for audit and monitoring purposes.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for logging and audit management within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="level" type="string" required>
  Log level
  
  **Options**: "debug", "info", "warning", "error", "critical"
  
  **Example**: "info"
  
  **Constraints**: 
  - Must be one of the valid log levels
  - Determines log severity and filtering
</ParamField>

<ParamField body="message" type="string" required>
  Log message
  
  **Example**: "User authentication successful"
  
  **Constraints**: 
  - Maximum length: 1000 characters
  - Must not be empty
  - Should be descriptive and clear
</ParamField>

<ParamField body="source" type="string" required>
  Source component or service
  
  **Example**: "auth-service"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Should identify the component generating the log
</ParamField>

<ParamField body="category" type="string" required="false">
  Log category
  
  **Options**: "authentication", "authorization", "system", "database", "api", "security", "performance", "business", "audit"
  
  **Example**: "authentication"
  
  **Default**: "system"
  
  **Note**: Helps organize and filter logs by category
</ParamField>

<ParamField body="user_id" type="string" required="false">
  User ID associated with the log entry
  
  **Example**: "user_1234567890abcdef"
  
  **Note**: Include if the log entry is related to a specific user
</ParamField>

<ParamField body="session_id" type="string" required="false">
  Session ID associated with the log entry
  
  **Example**: "session_1234567890abcdef"
  
  **Note**: Include if the log entry is related to a specific session
</ParamField>

<ParamField body="request_id" type="string" required="false">
  Request ID associated with the log entry
  
  **Example**: "req_1234567890abcdef"
  
  **Note**: Include if the log entry is related to a specific request
</ParamField>

<ParamField body="ip_address" type="string" required="false">
  IP address associated with the log entry
  
  **Example**: "192.168.1.100"
  
  **Note**: Include if the log entry is related to a specific IP address
</ParamField>

<ParamField body="user_agent" type="string" required="false">
  User agent string
  
  **Example**: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
  
  **Note**: Include if the log entry is related to a specific user agent
</ParamField>

<ParamField body="metadata" type="object" required="false">
  Additional metadata for the log entry
  
  **Example**: {"endpoint": "/api/users", "method": "GET", "status_code": 200}
  
  **Note**: Can contain any additional structured data
</ParamField>

<ParamField body="tags" type="array" required="false">
  Tags for categorizing the log entry
  
  **Example**: ["security", "authentication", "success"]
  
  **Note**: Array of strings for additional categorization
</ParamField>

<ParamField body="timestamp" type="string" required="false">
  Custom timestamp for the log entry
  
  **Example**: "2024-01-15T10:30:00Z"
  
  **Default**: Current timestamp
  
  **Note**: ISO 8601 format timestamp
</ParamField>

<ParamField body="environment" type="string" required="false">
  Environment where the log entry was created
  
  **Options**: "production", "staging", "development", "testing"
  
  **Example**: "production"
  
  **Default**: "production"
</ParamField>

<ParamField body="region" type="string" required="false">
  Region where the log entry was created
  
  **Example**: "us-east-1"
  
  **Default**: "us-east-1"
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Log Levels" icon="info">
    Log level hierarchy:
    
    - **debug**: Detailed information for debugging
    - **info**: General information about system operation
    - **warning**: Warning messages for potential issues
    - **error**: Error messages for failed operations
    - **critical**: Critical errors that require immediate attention
  </Accordion>
  
  <Accordion title="Log Categories" icon="folder">
    Available categories:
    
    - **authentication**: User authentication events
    - **authorization**: Permission and access control events
    - **system**: System-level events and operations
    - **database**: Database operations and queries
    - **api**: API requests and responses
    - **security**: Security-related events
    - **performance**: Performance metrics and monitoring
    - **business**: Business logic events
    - **audit**: Audit trail events
  </Accordion>
  
  <Accordion title="Metadata and Tags" icon="tag">
    Organization features:
    
    - **Metadata**: Structured data for additional context
    - **Tags**: String array for flexible categorization
    - **Search**: Both metadata and tags are searchable
    - **Filtering**: Use for advanced log filtering and analysis
  </Accordion>
  
  <Accordion title="Retention and Indexing" icon="database">
    Storage features:
    
    - **Retention**: Logs are retained for specified number of days
    - **Indexing**: Logs are indexed for fast searching
    - **Archival**: Old logs are archived for long-term storage
    - **Compliance**: Meets audit and compliance requirements
  </Accordion>
</AccordionGroup>

## Code Examples

<AccordionGroup>
  <Accordion title="Log Entry Service" icon="cog">
    ```javascript
    class LogEntryService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async createLogEntry(logData) {
        try {
          const response = await this.apiClient.makeRequest('/logs/create', {
            method: 'POST',
            body: JSON.stringify(logData)
          });
          
          if (!response.ok) {
            throw new Error('Failed to create log entry');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error creating log entry:', error);
          throw error;
        }
      }
      
      async logAuthentication(userId, sessionId, success, ipAddress, userAgent) {
        return this.createLogEntry({
          level: success ? 'info' : 'warning',
          message: success ? 'User authentication successful' : 'User authentication failed',
          source: 'auth-service',
          category: 'authentication',
          user_id: userId,
          session_id: sessionId,
          ip_address: ipAddress,
          user_agent: userAgent,
          tags: ['security', 'authentication', success ? 'success' : 'failure'],
          metadata: {
            success: success,
            timestamp: new Date().toISOString()
          }
        });
      }
      
      async logApiRequest(endpoint, method, statusCode, responseTime, requestId, userId) {
        return this.createLogEntry({
          level: statusCode >= 400 ? 'error' : 'info',
          message: `API request: ${method} ${endpoint}`,
          source: 'api-gateway',
          category: 'api',
          user_id: userId,
          request_id: requestId,
          tags: ['api', 'request', statusCode >= 400 ? 'error' : 'success'],
          metadata: {
            endpoint: endpoint,
            method: method,
            status_code: statusCode,
            response_time: responseTime
          }
        });
      }
      
      async logSecurityEvent(eventType, description, userId, ipAddress, severity = 'warning') {
        return this.createLogEntry({
          level: severity,
          message: `Security event: ${description}`,
          source: 'security-service',
          category: 'security',
          user_id: userId,
          ip_address: ipAddress,
          tags: ['security', 'event', eventType],
          metadata: {
            event_type: eventType,
            description: description,
            severity: severity
          }
        });
      }
      
      async logSystemEvent(eventType, description, metadata = {}) {
        return this.createLogEntry({
          level: 'info',
          message: `System event: ${description}`,
          source: 'system-service',
          category: 'system',
          tags: ['system', 'event', eventType],
          metadata: {
            event_type: eventType,
            description: description,
            ...metadata
          }
        });
      }
      
      async logDatabaseOperation(operation, table, success, executionTime, queryId) {
        return this.createLogEntry({
          level: success ? 'info' : 'error',
          message: `Database operation: ${operation} on ${table}`,
          source: 'database-service',
          category: 'database',
          tags: ['database', 'operation', success ? 'success' : 'error'],
          metadata: {
            operation: operation,
            table: table,
            success: success,
            execution_time: executionTime,
            query_id: queryId
          }
        });
      }
      
      async logBusinessEvent(eventType, description, userId, metadata = {}) {
        return this.createLogEntry({
          level: 'info',
          message: `Business event: ${description}`,
          source: 'business-service',
          category: 'business',
          user_id: userId,
          tags: ['business', 'event', eventType],
          metadata: {
            event_type: eventType,
            description: description,
            ...metadata
          }
        });
      }
      
      async logPerformanceMetric(metricName, value, unit, source, metadata = {}) {
        return this.createLogEntry({
          level: 'info',
          message: `Performance metric: ${metricName}`,
          source: source,
          category: 'performance',
          tags: ['performance', 'metric', metricName],
          metadata: {
            metric_name: metricName,
            value: value,
            unit: unit,
            ...metadata
          }
        });
      }
      
      async logAuditEvent(action, resource, userId, metadata = {}) {
        return this.createLogEntry({
          level: 'info',
          message: `Audit event: ${action} on ${resource}`,
          source: 'audit-service',
          category: 'audit',
          user_id: userId,
          tags: ['audit', 'event', action],
          metadata: {
            action: action,
            resource: resource,
            ...metadata
          }
        });
      }
    }
    
    // Usage example
    const logService = new LogEntryService(apiClient);
    
    // Log authentication event
    const authLog = await logService.logAuthentication(
      'user_1234567890abcdef',
      'session_1234567890abcdef',
      true,
      '192.168.1.100',
      'Mozilla/5.0...'
    );
    console.log('Authentication logged:', authLog.data.log_id);
    
    // Log API request
    const apiLog = await logService.logApiRequest(
      '/api/users',
      'GET',
      200,
      150,
      'req_1234567890abcdef',
      'user_1234567890abcdef'
    );
    console.log('API request logged:', apiLog.data.log_id);
    
    // Log security event
    const securityLog = await logService.logSecurityEvent(
      'failed_login',
      'Multiple failed login attempts',
      'user_1234567890abcdef',
      '192.168.1.100',
      'warning'
    );
    console.log('Security event logged:', securityLog.data.log_id);
    
    // Log system event
    const systemLog = await logService.logSystemEvent(
      'maintenance',
      'Scheduled maintenance completed',
      { duration: 3600, affected_services: ['api', 'database'] }
    );
    console.log('System event logged:', systemLog.data.log_id);
    ```
