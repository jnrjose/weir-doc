---
title: "Update Mail Template"
api: "PUT /mail/template/{id}"
description: "Update an existing email template"
---

Update an existing email template with new content, configuration, or settings. This endpoint allows admins to modify template properties while maintaining version history.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for email template management within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="id" type="string" required>
  Template ID to update
  
  **Example**: "tpl_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid template ID
  - Template must exist in the system
</ParamField>

## Request

<ParamField body="name" type="string" required="false">
  Updated template name
  
  **Example**: "Updated Welcome Email Template"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Must be unique if changed
</ParamField>

<ParamField body="subject" type="string" required="false">
  Updated email subject line
  
  **Example**: "Welcome to {{platform_name}} - Updated!"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Supports template variables
</ParamField>

<ParamField body="content" type="string" required="false">
  Updated email content (HTML or plain text)
  
  **Example**: "<h1>Welcome {{user_name}}!</h1><p>Thank you for joining {{platform_name}}.</p><p>We have exciting updates for you!</p>"
  
  **Constraints**: 
  - Supports HTML and template variables
  - Maximum length: 50,000 characters
</ParamField>

<ParamField body="type" type="string" required="false">
  Updated template type
  
  **Options**: "welcome", "notification", "alert", "invitation", "custom"
  
  **Example**: "welcome"
</ParamField>

<ParamField body="variables" type="array" required="false">
  Updated available template variables
  
  **Example**: ["user_name", "platform_name", "organization_name"]
</ParamField>

<ParamField body="is_active" type="boolean" required="false">
  Updated active status
  
  **Example**: true
  
  **Note**: Setting to false will disable the template
</ParamField>

<ParamField body="version_notes" type="string" required="false">
  Notes about this update
  
  **Example**: "Updated welcome message and added organization branding"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional but recommended for tracking changes
</ParamField>

## Code Examples

<AccordionGroup>
  <Accordion title="Template Update Service" icon="cog">
    ```javascript
    class TemplateUpdateService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async updateTemplate(templateId, updateData) {
        try {
          const response = await this.apiClient.makeRequest(`/mail/template/${templateId}`, {
            method: 'PUT',
            body: JSON.stringify(updateData)
          });
          
          if (!response.ok) {
            throw new Error('Failed to update template');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error updating template:', error);
          throw error;
        }
      }
      
      async updateTemplateContent(templateId, content, versionNotes) {
        return this.updateTemplate(templateId, {
          content: content,
          version_notes: versionNotes
        });
      }
      
      async updateTemplateSubject(templateId, subject, versionNotes) {
        return this.updateTemplate(templateId, {
          subject: subject,
          version_notes: versionNotes
        });
      }
      
      async activateTemplate(templateId) {
        return this.updateTemplate(templateId, {
          is_active: true,
          version_notes: 'Template activated'
        });
      }
      
      async deactivateTemplate(templateId) {
        return this.updateTemplate(templateId, {
          is_active: false,
          version_notes: 'Template deactivated'
        });
      }
      
      async updateTemplateVariables(templateId, variables, versionNotes) {
        return this.updateTemplate(templateId, {
          variables: variables,
          version_notes: versionNotes
        });
      }
    }
    
    // Usage example
    const updateService = new TemplateUpdateService(apiClient);
    
    // Update template content
    const updatedTemplate = await updateService.updateTemplateContent(
      'tpl_1234567890abcdef',
      '<h1>Welcome {{user_name}}!</h1><p>Thank you for joining {{platform_name}}.</p>',
      'Updated welcome message'
    );
    
    console.log('Template updated:', updatedTemplate.data.template_id);
    console.log('New version:', updatedTemplate.data.version);
    ```
  </Accordion>
</AccordionGroup>
