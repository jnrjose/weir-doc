---
title: "Create Mail Template"
api: "POST /mail/create/template"
description: "Create a new email template for the system"
---

Create a new email template with customizable content, variables, and styling. This endpoint allows admins to create reusable email templates for various system communications.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for email template management within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  Template name
  
  **Example**: "Welcome Email Template"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Must be unique
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line
  
  **Example**: "Welcome to {{platform_name}}!"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Supports template variables
</ParamField>

<ParamField body="content" type="string" required>
  Email content (HTML or plain text)
  
  **Example**: "<h1>Welcome {{user_name}}!</h1><p>Thank you for joining {{platform_name}}.</p>"
  
  **Constraints**: 
  - Supports HTML and template variables
  - Maximum length: 50,000 characters
</ParamField>

<ParamField body="type" type="string" required>
  Template type
  
  **Options**: "welcome", "notification", "alert", "invitation", "custom"
  
  **Example**: "welcome"
</ParamField>

<ParamField body="variables" type="array" required="false">
  Available template variables
  
  **Example**: ["user_name", "platform_name", "organization_name"]
</ParamField>

<ParamField body="is_active" type="boolean" required="false">
  Whether template is active
  
  **Example**: true
  
  **Default**: true
</ParamField>

## Code Examples

<AccordionGroup>
  <Accordion title="Mail Template Service" icon="cog">
    ```javascript
    class MailTemplateService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async createTemplate(templateData) {
        try {
          const response = await this.apiClient.makeRequest('/mail/create/template', {
            method: 'POST',
            body: JSON.stringify(templateData)
          });
          
          if (!response.ok) {
            throw new Error('Failed to create template');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error creating template:', error);
          throw error;
        }
      }
      
      async createWelcomeTemplate() {
        return this.createTemplate({
          name: 'Welcome Email Template',
          subject: 'Welcome to {{platform_name}}!',
          content: `
            <h1>Welcome {{user_name}}!</h1>
            <p>Thank you for joining {{platform_name}}.</p>
            <p>We're excited to have you on board!</p>
          `,
          type: 'welcome',
          variables: ['user_name', 'platform_name'],
          is_active: true
        });
      }
      
      async createNotificationTemplate() {
        return this.createTemplate({
          name: 'Notification Template',
          subject: '{{notification_title}}',
          content: `
            <h2>{{notification_title}}</h2>
            <p>{{notification_message}}</p>
            <p>Best regards,<br>{{organization_name}}</p>
          `,
          type: 'notification',
          variables: ['notification_title', 'notification_message', 'organization_name'],
          is_active: true
        });
      }
    }
    
    // Usage example
    const templateService = new MailTemplateService(apiClient);
    
    // Create welcome template
    const welcomeTemplate = await templateService.createWelcomeTemplate();
    console.log('Welcome template created:', welcomeTemplate.data.template_id);
    
    // Create notification template
    const notificationTemplate = await templateService.createNotificationTemplate();
    console.log('Notification template created:', notificationTemplate.data.template_id);
    ```
  </Accordion>
</AccordionGroup>
