---
title: "Start Pod"
api: "POST /pax/start/pod/{podId}"
description: "Start a specific pod for processing and execution"
---

Start a specific pod that is currently stopped or in maintenance mode. This endpoint allows admins to activate pods for processing tasks and workloads.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for pod management and control within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="podId" type="string" required>
  Pod ID to start
  
  **Example**: "pod_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid pod ID
  - Pod must exist in the system
</ParamField>

## Request

<ParamField body="force_start" type="boolean" required="false">
  Force start even if pod has issues
  
  **Example**: false
  
  **Default**: false
  
  **Note**: If true, starts pod even if health checks fail
</ParamField>

<ParamField body="start_reason" type="string" required="false">
  Reason for starting the pod
  
  **Example**: "Scheduled maintenance completed"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Optional but recommended for audit purposes
</ParamField>

<ParamField body="wait_for_ready" type="boolean" required="false">
  Wait for pod to be ready before returning
  
  **Example**: true
  
  **Default**: false
  
  **Note**: If true, waits for pod to be fully operational
</ParamField>

<ParamField body="timeout_seconds" type="integer" required="false">
  Timeout for waiting for pod to be ready
  
  **Example**: 300
  
  **Default**: 60
  
  **Constraints**: 
  - Must be between 10 and 1800 seconds
  - Only used if wait_for_ready is true
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Pod States" icon="info">
    Pod state transitions:
    
    - **stopped** → **starting** → **running**
    - **maintenance** → **starting** → **running**
    - **error** → **starting** → **running** (with force_start)
    - **running** → Cannot start (already running)
  </Accordion>
  
  <Accordion title="Startup Process" icon="play">
    Startup features:
    
    - **Health Checks**: Verify pod health before marking as ready
    - **Resource Allocation**: Allocate required resources
    - **Service Registration**: Register pod with load balancer
    - **Ready State**: Wait for pod to be fully operational
  </Accordion>
  
  <Accordion title="Monitoring" icon="monitor">
    Monitoring features:
    
    - **Startup Time**: Track time taken to start pod
    - **Health Status**: Monitor health during startup
    - **Resource Usage**: Track resource consumption
    - **Ready State**: Monitor when pod becomes ready
  </Accordion>
</AccordionGroup>

## Code Examples

<AccordionGroup>
  <Accordion title="Pod Control Service" icon="cog">
    ```javascript
    class PodControlService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async startPod(podId, options = {}) {
        try {
          const response = await this.apiClient.makeRequest(`/pax/start/pod/${podId}`, {
            method: 'POST',
            body: JSON.stringify({
              force_start: options.forceStart || false,
              start_reason: options.startReason || 'Pod started',
              wait_for_ready: options.waitForReady || false,
              timeout_seconds: options.timeoutSeconds || 60
            })
          });
          
          if (!response.ok) {
            throw new Error('Failed to start pod');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error starting pod:', error);
          throw error;
        }
      }
      
      async startPodAndWait(podId, reason, timeoutSeconds = 300) {
        return this.startPod(podId, {
          startReason: reason,
          waitForReady: true,
          timeoutSeconds: timeoutSeconds
        });
      }
      
      async forceStartPod(podId, reason) {
        return this.startPod(podId, {
          forceStart: true,
          startReason: reason,
          waitForReady: false
        });
      }
      
      async startMultiplePods(podIds, reason) {
        const results = [];
        
        for (const podId of podIds) {
          try {
            const result = await this.startPod(podId, {
              startReason: reason,
              waitForReady: true,
              timeoutSeconds: 300
            });
            results.push({ success: true, podId, data: result.data });
          } catch (error) {
            results.push({ success: false, podId, error: error.message });
          }
        }
        
        return results;
      }
      
      async startPodsByTag(tagKey, tagValue, reason) {
        // First get pods with the tag
        const podsResponse = await this.apiClient.makeRequest(`/pax/pods?tag_filter=${tagKey}:${tagValue}&status=stopped`);
        const pods = await podsResponse.json();
        
        const podIds = pods.data.map(pod => pod.pod_id);
        return this.startMultiplePods(podIds, reason);
      }
      
      async startPodsByEnvironment(environment, reason) {
        const podsResponse = await this.apiClient.makeRequest(`/pax/pods?environment=${environment}&status=stopped`);
        const pods = await podsResponse.json();
        
        const podIds = pods.data.map(pod => pod.pod_id);
        return this.startMultiplePods(podIds, reason);
      }
    }
    
    // Usage example
    const podControlService = new PodControlService(apiClient);
    
    // Start pod and wait for ready
    const startedPod = await podControlService.startPodAndWait(
      'pod_1234567890abcdef',
      'Scheduled maintenance completed',
      300
    );
    console.log('Pod started:', startedPod.data.name);
    
    // Force start pod
    const forceStarted = await podControlService.forceStartPod(
      'pod_0987654321fedcba',
      'Emergency restart required'
    );
    console.log('Pod force started:', forceStarted.data.name);
    
    // Start multiple pods
    const multipleResults = await podControlService.startMultiplePods(
      ['pod_1234567890abcdef', 'pod_0987654321fedcba'],
      'Batch startup after maintenance'
    );
    console.log('Multiple pods started:', multipleResults.length);
    
    // Start pods by tag
    const tagResults = await podControlService.startPodsByTag(
      'department',
      'engineering',
      'Engineering pods startup'
    );
    console.log('Engineering pods started:', tagResults.length);
    ```
