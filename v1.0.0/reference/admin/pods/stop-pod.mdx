---
title: "Stop Pod"
api: "POST /pax/stop/pod/{podId}"
description: "Stop a specific pod completely"
---

Stop a specific pod completely, terminating all processes and freeing up resources. This endpoint allows admins to shut down pods permanently or temporarily.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for pod management and control within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="podId" type="string" required>
  Pod ID to stop
  
  **Example**: "pod_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid pod ID
  - Pod must exist in the system
</ParamField>

## Request

<ParamField body="stop_reason" type="string" required="false">
  Reason for stopping the pod
  
  **Example**: "Scheduled shutdown"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Optional but recommended for audit purposes
</ParamField>

<ParamField body="graceful_stop" type="boolean" required="false">
  Whether to stop gracefully
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, waits for current operations to complete
</ParamField>

<ParamField body="timeout_seconds" type="integer" required="false">
  Timeout for graceful stop
  
  **Example**: 60
  
  **Default**: 30
  
  **Constraints**: 
  - Must be between 5 and 300 seconds
  - Only used if graceful_stop is true
</ParamField>

<ParamField body="preserve_data" type="boolean" required="false">
  Whether to preserve data during stop
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, preserves data for future restart
</ParamField>

<ParamField body="force_stop" type="boolean" required="false">
  Force stop even if operations are running
  
  **Example**: false
  
  **Default**: false
  
  **Note**: If true, stops immediately without waiting
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Pod States" icon="info">
    Pod state transitions:
    
    - **running** → **stopping** → **stopped**
    - **paused** → **stopping** → **stopped**
    - **stopped** → Cannot stop (already stopped)
    - **error** → **stopping** → **stopped** (with force_stop)
  </Accordion>
  
  <Accordion title="Stop Types" icon="stop">
    Stop options:
    
    - **Graceful Stop**: Wait for operations to complete
    - **Force Stop**: Stop immediately without waiting
    - **Data Preservation**: Preserve data for future restart
    - **Backup Creation**: Create backup before stopping
  </Accordion>
  
  <Accordion title="Data Management" icon="database">
    Data features:
    
    - **Data Preservation**: Keep data for future restart
    - **Backup Creation**: Automatic backup before stop
    - **State Cleanup**: Clean up temporary state
    - **Resource Release**: Free up allocated resources
  </Accordion>
</AccordionGroup>

## Code Examples

<AccordionGroup>
  <Accordion title="Pod Stop Service" icon="cog">
    ```javascript
    class PodStopService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async stopPod(podId, options = {}) {
        try {
          const response = await this.apiClient.makeRequest(`/pax/stop/pod/${podId}`, {
            method: 'POST',
            body: JSON.stringify({
              stop_reason: options.stopReason || 'Pod stopped',
              graceful_stop: options.gracefulStop !== false,
              timeout_seconds: options.timeoutSeconds || 30,
              preserve_data: options.preserveData !== false,
              force_stop: options.forceStop || false
            })
          });
          
          if (!response.ok) {
            throw new Error('Failed to stop pod');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error stopping pod:', error);
          throw error;
        }
      }
      
      async gracefulStopPod(podId, reason, timeoutSeconds = 60) {
        return this.stopPod(podId, {
          stopReason: reason,
          gracefulStop: true,
          timeoutSeconds: timeoutSeconds,
          preserveData: true,
          forceStop: false
        });
      }
      
      async forceStopPod(podId, reason) {
        return this.stopPod(podId, {
          stopReason: reason,
          gracefulStop: false,
          preserveData: true,
          forceStop: true
        });
      }
      
      async stopPodWithoutData(podId, reason) {
        return this.stopPod(podId, {
          stopReason: reason,
          gracefulStop: true,
          preserveData: false,
          forceStop: false
        });
      }
      
      async stopMultiplePods(podIds, reason) {
        const results = [];
        
        for (const podId of podIds) {
          try {
            const result = await this.gracefulStopPod(podId, reason);
            results.push({ success: true, podId, data: result.data });
          } catch (error) {
            results.push({ success: false, podId, error: error.message });
          }
        }
        
        return results;
      }
      
      async stopPodsByTag(tagKey, tagValue, reason) {
        // First get running pods with the tag
        const podsResponse = await this.apiClient.makeRequest(`/pax/pods?tag_filter=${tagKey}:${tagValue}&status=running`);
        const pods = await podsResponse.json();
        
        const podIds = pods.data.map(pod => pod.pod_id);
        return this.stopMultiplePods(podIds, reason);
      }
      
      async stopPodsByEnvironment(environment, reason) {
        const podsResponse = await this.apiClient.makeRequest(`/pax/pods?environment=${environment}&status=running`);
        const pods = await podsResponse.json();
        
        const podIds = pods.data.map(pod => pod.pod_id);
        return this.stopMultiplePods(podIds, reason);
      }
      
      async stopPodsForMaintenance(reason = 'Scheduled maintenance') {
        const podsResponse = await this.apiClient.makeRequest('/pax/pods?status=running');
        const pods = await podsResponse.json();
        
        const podIds = pods.data.map(pod => pod.pod_id);
        return this.stopMultiplePods(podIds, reason);
      }
      
      async emergencyStopAllPods(reason = 'Emergency shutdown') {
        const podsResponse = await this.apiClient.makeRequest('/pax/pods?status=running');
        const pods = await podsResponse.json();
        
        const results = [];
        for (const pod of pods.data) {
          try {
            const result = await this.forceStopPod(pod.pod_id, reason);
            results.push({ success: true, podId: pod.pod_id, data: result.data });
          } catch (error) {
            results.push({ success: false, podId: pod.pod_id, error: error.message });
          }
        }
        
        return results;
      }
    }
    
    // Usage example
    const podStopService = new PodStopService(apiClient);
    
    // Graceful stop with data preservation
    const stoppedPod = await podStopService.gracefulStopPod(
      'pod_1234567890abcdef',
      'Scheduled shutdown',
      60
    );
    console.log('Pod stopped:', stoppedPod.data.name);
    
    // Force stop
    const forceStopped = await podStopService.forceStopPod(
      'pod_0987654321fedcba',
      'Emergency stop required'
    );
    console.log('Pod force stopped:', forceStopped.data.name);
    
    // Stop multiple pods
    const multipleResults = await podStopService.stopMultiplePods(
      ['pod_1234567890abcdef', 'pod_0987654321fedcba'],
      'Batch shutdown'
    );
    console.log('Multiple pods stopped:', multipleResults.length);
    
    // Stop pods by tag
    const tagResults = await podStopService.stopPodsByTag(
      'department',
      'engineering',
      'Engineering shutdown'
    );
    console.log('Engineering pods stopped:', tagResults.length);
    
    // Emergency stop all pods
    const emergencyResults = await podStopService.emergencyStopAllPods();
    console.log('Emergency stop completed:', emergencyResults.length);
    ```
