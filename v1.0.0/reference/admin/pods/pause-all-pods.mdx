---
title: "Pause All Pods"
api: "POST /pax/pause/pods"
description: "Pause all pods in the system temporarily"
---

Pause all pods in the system temporarily while preserving their state and configuration. This endpoint allows admins to temporarily suspend all pod operations without losing data or configuration.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for pod management and control within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="pause_reason" type="string" required="false">
  Reason for pausing all pods
  
  **Example**: "System maintenance"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Optional but recommended for audit purposes
</ParamField>

<ParamField body="environment" type="string" required="false">
  Filter pods by environment to pause
  
  **Options**: "production", "staging", "development", "testing"
  
  **Example**: "production"
  
  **Note**: If not specified, pauses pods from all environments
</ParamField>

<ParamField body="region" type="string" required="false">
  Filter pods by region to pause
  
  **Example**: "us-east-1"
  
  **Note**: If not specified, pauses pods from all regions
</ParamField>

<ParamField body="pod_type" type="string" required="false">
  Filter pods by type to pause
  
  **Options**: "processing", "storage", "compute", "analytics", "custom"
  
  **Example**: "processing"
  
  **Note**: If not specified, pauses pods of all types
</ParamField>

<ParamField body="tag_filter" type="string" required="false">
  Filter pods by tag key-value pairs to pause
  
  **Example**: "department:engineering,priority:high"
  
  **Format**: "key:value,key:value"
</ParamField>

<ParamField body="preserve_state" type="boolean" required="false">
  Whether to preserve pod state during pause
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, preserves memory and processing state
</ParamField>

<ParamField body="graceful_pause" type="boolean" required="false">
  Whether to pause gracefully
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, waits for current operations to complete
</ParamField>

<ParamField body="timeout_seconds" type="integer" required="false">
  Timeout for graceful pause
  
  **Example**: 300
  
  **Default**: 60
  
  **Constraints**: 
  - Must be between 30 and 1800 seconds
  - Only used if graceful_pause is true
</ParamField>

<ParamField body="parallel_pause" type="boolean" required="false">
  Pause pods in parallel
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, pauses multiple pods simultaneously
</ParamField>

<ParamField body="max_parallel" type="integer" required="false">
  Maximum number of pods to pause in parallel
  
  **Example**: 10
  
  **Default**: 5
  
  **Constraints**: 
  - Must be between 1 and 20
  - Only used if parallel_pause is true
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Bulk Operations" icon="layers">
    Bulk pause features:
    
    - **Parallel Processing**: Pause multiple pods simultaneously
    - **Filtering**: Pause pods based on environment, region, type, or tags
    - **Progress Tracking**: Monitor progress of bulk operations
    - **Error Handling**: Handle individual pod failures gracefully
  </Accordion>
  
  <Accordion title="State Preservation" icon="database">
    State features:
    
    - **Memory Preservation**: Keep data in memory during pause
    - **Processing State**: Preserve current processing state
    - **Connection State**: Maintain connection information
    - **Configuration**: Preserve all configuration settings
  </Accordion>
  
  <Accordion title="Graceful Operations" icon="handshake">
    Graceful features:
    
    - **Operation Completion**: Wait for current operations to complete
    - **Connection Handling**: Handle active connections appropriately
    - **Timeout Control**: Control operation timeout for large deployments
    - **Error Recovery**: Handle timeout and error scenarios
  </Accordion>
</AccordionGroup>

    ```javascript
    class BulkPodPauseService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async pauseAllPods(options = {}) {
        try {
          const response = await this.apiClient.makeRequest('/pax/pause/pods', {
            method: 'POST',
            body: JSON.stringify({
              pause_reason: options.pauseReason || 'Bulk pod pause',
              environment: options.environment,
              region: options.region,
              pod_type: options.podType,
              tag_filter: options.tagFilter,
              preserve_state: options.preserveState !== false,
              graceful_pause: options.gracefulPause !== false,
              timeout_seconds: options.timeoutSeconds || 60,
              parallel_pause: options.parallelPause !== false,
              max_parallel: options.maxParallel || 5
            })
          });
          
          if (!response.ok) {
            throw new Error('Failed to pause all pods');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error pausing all pods:', error);
          throw error;
        }
      }
      
      async pauseProductionPods(reason = 'Production maintenance') {
        return this.pauseAllPods({
          pauseReason: reason,
          environment: 'production',
          gracefulPause: true,
          timeoutSeconds: 300,
          parallelPause: true,
          maxParallel: 10
        });
      }
      
      async pausePodsByRegion(region, reason) {
        return this.pauseAllPods({
          pauseReason: reason,
          region: region,
          gracefulPause: true,
          timeoutSeconds: 180,
          parallelPause: true,
          maxParallel: 8
        });
      }
      
      async pausePodsByType(podType, reason) {
        return this.pauseAllPods({
          pauseReason: reason,
          podType: podType,
          gracefulPause: true,
          timeoutSeconds: 180,
          parallelPause: true,
          maxParallel: 6
        });
      }
      
      async pausePodsByTag(tagKey, tagValue, reason) {
        return this.pauseAllPods({
          pauseReason: reason,
          tagFilter: `${tagKey}:${tagValue}`,
          gracefulPause: true,
          timeoutSeconds: 120,
          parallelPause: true,
          maxParallel: 5
        });
      }
      
      async pauseAllPodsGraceful(reason, timeoutSeconds = 300) {
        return this.pauseAllPods({
          pauseReason: reason,
          gracefulPause: true,
          timeoutSeconds: timeoutSeconds,
          parallelPause: true,
          maxParallel: 10
        });
      }
      
      async pauseAllPodsImmediate(reason) {
        return this.pauseAllPods({
          pauseReason: reason,
          gracefulPause: false,
          parallelPause: true,
          maxParallel: 15
        });
      }
      
      async pausePodsForMaintenance(reason = 'Scheduled maintenance') {
        return this.pauseAllPods({
          pauseReason: reason,
          gracefulPause: true,
          timeoutSeconds: 300,
          parallelPause: true,
          maxParallel: 15
        });
      }
      
      async pausePodsByDepartment(department, reason) {
        return this.pausePodsByTag('department', department, reason);
      }
      
      async pausePodsByProject(project, reason) {
        return this.pausePodsByTag('project', project, reason);
      }
      
      async pausePodsByPriority(priority, reason) {
        return this.pausePodsByTag('priority', priority, reason);
      }
    }

    const bulkPauseService = new BulkPodPauseService(apiClient);

    console.log(`Paused ${productionResult.data.pods_paused} production pods`);
    
    // Pause pods by region
    const regionResult = await bulkPauseService.pausePodsByRegion('us-east-1', 'Regional maintenance');
    console.log(`Paused ${regionResult.data.pods_paused} pods in us-east-1`);
    
    // Pause pods by type
    const typeResult = await bulkPauseService.pausePodsByType('processing', 'Processing maintenance');
    console.log(`Paused ${typeResult.data.pods_paused} processing pods`);
    
    // Pause pods by department
    const deptResult = await bulkPauseService.pausePodsByDepartment('engineering', 'Engineering maintenance');
    console.log(`Paused ${deptResult.data.pods_paused} engineering pods`);
    
    // Pause all pods gracefully

    console.log(`Paused ${gracefulResult.data.pods_paused} pods gracefully`);
    
    // Pause pods for maintenance
    ```
