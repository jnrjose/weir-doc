---
title: "Admin Login"
api: "POST /auth/login"
description: "Authenticate admin user and receive access token for administrative operations"
---

Authenticate as an admin user to gain access to administrative functions and system-wide management capabilities. This endpoint provides elevated privileges for platform administration.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and provides access to system administration functions. Admin users have elevated privileges and can manage organizations, users, and platform resources.
</Note>

## Authentication

This endpoint does not require authentication (it's used to obtain authentication). However, the response will include access tokens that should be used for subsequent API calls.

## Request

<ParamField body="username" type="string" required>
  Admin username or email address
  
  **Example**: "admin@example.com"
  
  **Constraints**: 
  - Must be a valid email format
  - Must be associated with an admin account
</ParamField>

<ParamField body="password" type="string" required>
  Admin password
  
  **Constraints**: 
  - Minimum length: 8 characters
  - Must contain at least one uppercase letter, one lowercase letter, and one number
  - Special characters are recommended for enhanced security
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the login was successful
</ResponseField>

<ResponseField name="data" type="object">
  Contains authentication tokens and user information
</ResponseField>

<ResponseField name="data.access_token" type="string">
  JWT access token for API authentication (expires in 1 hour)
</ResponseField>

<ResponseField name="data.refresh_token" type="string">
  Refresh token for obtaining new access tokens (expires in 7 days)
</ResponseField>

<ResponseField name="data.expires_in" type="integer">
  Access token expiration time in seconds (3600 = 1 hour)
</ResponseField>

<ResponseField name="data.token_type" type="string">
  Token type, always "Bearer"
</ResponseField>

<ResponseField name="data.user" type="object">
  Admin user information
</ResponseField>

<ResponseField name="data.user.user_id" type="string">
  Unique identifier for the admin user
</ResponseField>

<ResponseField name="data.user.username" type="string">
  Admin username
</ResponseField>

<ResponseField name="data.user.role" type="string">
  Admin role (e.g., "super_admin", "admin", "moderator")
</ResponseField>

<ResponseField name="data.user.permissions" type="array">
  List of permissions granted to the admin user
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the login result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Token Management" icon="key">
    - Access tokens expire after 1 hour and must be refreshed
    - Use the refresh token to obtain new access tokens
    - Store tokens securely and never expose them in client-side code
    - Implement automatic token refresh for long-running applications
  </Accordion>
  
  <Accordion title="Admin Privileges" icon="user-shield">
    Admin users have access to:
    - System-wide user management
    - Organization oversight and management
    - Platform monitoring and control
    - Logging and analytics
    - System configuration and settings
  </Accordion>
  
  <Accordion title="Security Considerations" icon="shield">
    - Use strong, unique passwords for admin accounts
    - Enable multi-factor authentication when available
    - Monitor admin login activity and unusual access patterns
    - Regularly rotate admin credentials
    - Use secure networks for admin operations
  </Accordion>
  
  <Accordion title="Rate Limiting" icon="clock">
    Login attempts are rate limited to prevent brute force attacks:
    - Maximum 5 login attempts per minute per IP
    - Account locked for 30 minutes after 10 failed attempts
    - Check response headers for rate limit information
  </Accordion>
</AccordionGroup>

{`class WeirAdminClient {
  constructor(baseURL) {
    this.baseURL = baseURL;
    this.accessToken = null;
    this.refreshToken = null;
    this.tokenExpiry = null;
  }
  
  async login(username, password) {
    try {
      const response = await fetch(\`\${this.baseURL}/auth/login\`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({ username, password })
      });
      
      if (!response.ok) {
        const error = await response.json();
        throw new Error(\`Login failed: \${error.error.message}\`);
      }
      
      const data = await response.json();
      this.accessToken = data.data.access_token;
      this.refreshToken = data.data.refresh_token;
      this.tokenExpiry = Date.now() + (data.data.expires_in * 1000);
      
      console.log(\`Admin login successful. Role: \${data.data.user.role}\`);
      return data.data;
      
    } catch (error) {
      console.error('Admin login failed:', error.message);
      throw error;
    }
  }
  
  async refreshAccessToken() {
    if (!this.refreshToken) {
      throw new Error('No refresh token available. Please login again.');
    }
    
    const response = await fetch(\`\${this.baseURL}/auth/refresh/token\`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ refresh_token: this.refreshToken })
    });
    
    if (!response.ok) {
      throw new Error('Token refresh failed. Please login again.');
    }
    
    const data = await response.json();
    this.accessToken = data.data.access_token;
    this.tokenExpiry = Date.now() + (data.data.expires_in * 1000);
    
    return this.accessToken;
  }
  
  async makeRequest(endpoint, options = {}) {
    if (!this.accessToken || Date.now() >= this.tokenExpiry) {
      await this.refreshAccessToken();
    }
    
    return fetch(\`\${this.baseURL}\${endpoint}\`, {
      ...options,
      headers: {
        'Authorization': \`Bearer \${this.accessToken}\`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
  }
  
  async logout() {
    if (this.refreshToken) {
      try {
        await this.makeRequest('/auth/logout', {
          method: 'POST',
          body: JSON.stringify({ refresh_token: this.refreshToken })
        });
      } catch (error) {
        console.warn('Logout request failed:', error.message);
      }
    }
    
    this.accessToken = null;
    this.refreshToken = null;
    this.tokenExpiry = null;
  }
}

// Usage
const adminClient = new WeirAdminClient('https://api.example.com');
await adminClient.login('admin@example.com', 'secure_password123');`}

{`async function adminLoginWithRetry(username, password, maxRetries = 3) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const response = await fetch('https://api.example.com/auth/login', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({ username, password })
      });
      
      if (response.status === 429) {
        // Rate limited - wait and retry
        const retryAfter = response.headers.get('Retry-After') || 60;
        console.log(\`Rate limited. Waiting \${retryAfter} seconds before retry \${attempt}\`);
        await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
        continue;
      }
      
      if (response.ok) {
        return await response.json();
      }
      
      const error = await response.json();
      
      // Don't retry on authentication errors
      if (response.status === 401 || response.status === 403) {
        throw new Error(\`Authentication failed: \${error.error.message}\`);
      }
      
      throw new Error(\`Login failed: \${error.error.message}\`);
      
    } catch (error) {
      if (attempt === maxRetries) {
        throw new Error(\`Failed to login after \${maxRetries} attempts: \${error.message}\`);
      }
      
      console.log(\`Login attempt \${attempt} failed: \${error.message}. Retrying...\`);
      await new Promise(resolve => setTimeout(resolve, 1000 * attempt));
    }
  }
}`}
