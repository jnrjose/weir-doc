---
title: "Get Admin Members"
api: "GET /admin/members"
description: "Retrieve list of all admin members in the system"
---

Retrieve a comprehensive list of all admin members with their roles, permissions, and activity information. This endpoint provides admin-level visibility into system administrators and their access levels.

<Note>
  **Admin API Endpoint**
  
  This endpoint is part of the Admin API category and requires Bearer Token authentication. It's designed for system administration and user management within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of members to return per page
  
  **Example**: "20"
  
  **Default**: "20"
  
  **Constraints**: 
  - Must be between 1 and 100
  - Recommended: 20-50 for optimal performance
</ParamField>

<ParamField query="role" type="string" required="false">
  Filter members by role
  
  **Options**: "super_admin", "admin", "moderator", "support", "readonly"
  
  **Example**: "admin"
  
  **Note**: If not specified, returns members of all roles
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter members by status
  
  **Options**: "active", "inactive", "suspended", "pending"
  
  **Example**: "active"
  
  **Default**: "active"
  
  **Note**: If not specified, returns members of all statuses
</ParamField>

<ParamField query="search" type="string" required="false">
  Search members by name or email
  
  **Example**: "john doe"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches name and email fields
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort members by specified field
  
  **Options**: "name", "email", "role", "status", "created_at", "last_login", "last_activity"
  
  **Example**: "last_login"
  
  **Default**: "created_at"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "desc"
</ParamField>

<ParamField query="created_after" type="string" required="false">
  Filter members created after this date (ISO 8601 format)
  
  **Example**: "2024-01-01T00:00:00Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be more than 2 years in the past
</ParamField>

<ParamField query="created_before" type="string" required="false">
  Filter members created before this date (ISO 8601 format)
  
  **Example**: "2024-12-31T23:59:59Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be in the future
</ParamField>

<ParamField query="include_permissions" type="string" required="false">
  Whether to include detailed permissions
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Default**: "false"
  
  **Note**: Setting to true will include detailed permission information
</ParamField>

<ParamField query="include_activity" type="string" required="false">
  Whether to include activity information
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Default**: "false"
  
  **Note**: Setting to true will include last login and activity data
</ParamField>

    ```javascript
          const params = new URLSearchParams();

          if (options.role) params.append('role', options.role);
          if (options.status) params.append('status', options.status);
          if (options.search) params.append('search', options.search);
          if (options.sortBy) params.append('sort_by', options.sortBy);
          if (options.sortOrder) params.append('sort_order', options.sortOrder);
          if (options.createdAfter) params.append('created_after', options.createdAfter);
          if (options.createdBefore) params.append('created_before', options.createdBefore);
          if (options.includePermissions) params.append('include_permissions', options.includePermissions);
          if (options.includeActivity) params.append('include_activity', options.includeActivity);
          
          const response = await this.apiClient.makeRequest(
            `/admin/members?${params.toString()}`
          );
          
          if (!response.ok) {
            throw new Error('Failed to get admin members');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error getting admin members:', error);
          throw error;
        }
      }

          sortOrder: 'desc',
          includeActivity: true

          status: 'active',

          sortBy: 'name',
          sortOrder: 'asc'
        });
      }

        return this.getMembers({
          includePermissions: true,
          sortBy: 'role',
          sortOrder: 'asc'
        });

        return this.getMembers({
          includeActivity: true,
          sortBy: 'last_activity',

        const endDate = new Date();
    ```

    ```python
    import requests
    from typing import Dict, List, Optional
    from datetime import datetime, timedelta
    
    class AdminMemberManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_members(self, 
                       page: int = 1,
                       limit: int = 20,
                       role: Optional[str] = None,
                       status: Optional[str] = None,
                       search: Optional[str] = None,
                       sort_by: str = "created_at",
                       sort_order: str = "desc",
                       created_after: Optional[str] = None,
                       created_before: Optional[str] = None,
                       include_permissions: bool = False,
                       include_activity: bool = False) -> Dict:
            """Get admin members with optional filtering and pagination"""
            try:
                params = {
                    "page": page,
                    "limit": limit,
                    "sort_by": sort_by,
                    "sort_order": sort_order,
                    "include_permissions": str(include_permissions).lower(),
                    "include_activity": str(include_activity).lower()
                }
                
                if role:
                    params["role"] = role
                if status:
                    params["status"] = status
                if search:
                    params["search"] = search
                if created_after:
                    params["created_after"] = created_after
                if created_before:
                    params["created_before"] = created_before
                
                response = self.api_client.get('/admin/members', params=params)
                response.raise_for_status()
                
                return response.json()
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting admin members: {e}")
                raise
        
        def get_active_members(self) -> Dict:
            """Get all active admin members"""
            return self.get_members(
                status="active",
                sort_by="last_login",
                sort_order="desc",
                include_activity=True
            )
        
        def get_super_admins(self) -> Dict:
            """Get all super admin members"""
            return self.get_members(
                role="super_admin",
                status="active",
                include_permissions=True
            )
        
        def get_members_by_role(self, role: str) -> Dict:
            """Get members by specific role"""
            return self.get_members(
                role=role,
                status="active",
                sort_by="name",
                sort_order="asc"
            )
        
        def search_members(self, search_term: str) -> Dict:
            """Search members by name or email"""
            return self.get_members(
                search=search_term,
                sort_by="name",
                sort_order="asc"
            )
        
        def get_members_with_permissions(self) -> Dict:
            """Get members with detailed permissions"""
            return self.get_members(
                include_permissions=True,
                sort_by="role",
                sort_order="asc"
            )
        
        def get_members_with_activity(self) -> Dict:
            """Get members with activity information"""
            return self.get_members(
                include_activity=True,
                sort_by="last_activity",
                sort_order="desc"
            )
        
        def get_recent_members(self, days: int = 30) -> Dict:
            """Get members created in the last N days"""
            end_date = datetime.now()
            start_date = end_date - timedelta(days=days)
            
            return self.get_members(
                created_after=start_date.isoformat() + "Z",
                sort_by="created_at",
                sort_order="desc"
            )
        
        def get_member_statistics(self) -> Dict:
            """Get member statistics and summary"""
            result = self.get_members(limit=1)
            return result["summary"]
        
        def get_members_without_2fa(self) -> List[Dict]:
            """Get members without two-factor authentication"""
            result = self.get_members_with_activity()
            return [member for member in result["data"] if not member.get("two_factor_enabled", False)]
        
        def get_inactive_members(self, days: int = 30) -> List[Dict]:
            """Get members who haven't been active in N days"""
            result = self.get_members_with_activity()
            cutoff_date = datetime.now() - timedelta(days=days)
            
            inactive = []
            for member in result["data"]:
                if not member.get("last_activity"):
                    inactive.append(member)
                else:
                    last_activity = datetime.fromisoformat(member["last_activity"].replace("Z", "+00:00"))
                    if last_activity < cutoff_date:
                        inactive.append(member)
            
            return inactive
        
        def get_members_by_permission(self, permission: str) -> List[Dict]:
            """Get members with specific permission"""
            result = self.get_members_with_permissions()
    ```
