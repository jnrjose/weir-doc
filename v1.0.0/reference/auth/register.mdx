title: "Register"
api: "POST /auth/register"
description: "Register a new user account with organization"
---

Register a new user account and create an organization in the Weir AI platform. This endpoint allows new users to sign up and establish their organization with initial settings and configurations.

<Note>
  **Auth API Endpoint**
  
  This endpoint is part of the Auth API category and does not require authentication (it's used to create new accounts). It's designed for new user registration and organization setup.
</Note>

## Authentication

This endpoint does not require authentication as it's used to create new user accounts and organizations.

## Request

<ParamField body="fullname" type="string" required>
  Full name of the user registering
  
  **Example**: "John Doe"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must contain at least first and last name
</ParamField>

<ParamField body="email" type="string" required>
  Email address for the user account
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: 
  - Must be a valid email address format
  - Must be unique across the platform
  - Will be used for account verification and login
</ParamField>

<ParamField body="password" type="string" required>
  Password for the user account
  
  **Example**: "secure_password123"
  
  **Constraints**: 
  - Minimum length: 8 characters
  - Must contain at least one uppercase letter, one lowercase letter, and one number
  - Cannot contain common passwords or personal information
</ParamField>

<ParamField body="organization" type="object" required>
  Organization information to create
  
  **Properties**:
  - `name` (string): Name of the organization
  - `type` (string): Type of organization (Platform, Agency, Enterprise, Other)
  - `description` (string): Description of the organization
  
  **Example**:
  ```json
  {
    "name": "Acme Corporation",
    "type": "Platform",
    "description": "A business platform for managing teams and projects"
  }
  ```
</ParamField>

<ParamField body="terms_accepted" type="boolean" required>
  Whether the user has accepted the terms of service
  
  **Example**: true
  
  **Constraints**: 
  - Must be true to proceed with registration
  - Required for legal compliance
</ParamField>

<ParamField body="privacy_accepted" type="boolean" required>
  Whether the user has accepted the privacy policy
  
  **Example**: true
  
  **Constraints**: 
  - Must be true to proceed with registration
  - Required for legal compliance
</ParamField>

<ParamField body="marketing_consent" type="boolean" required="false">
  Whether the user consents to receive marketing communications
  
  **Example**: false
  
  **Default**: false
  
  **Note**: Optional field for marketing preferences
</ParamField>

  Indicates if the registration was successful
</ResponseField>

package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

type RegisterRequest struct {
    Fullname         string       `json:"fullname"`
    Email            string       `json:"email"`
    Password         string       `json:"password"`
    Organization     Organization `json:"organization"`
    TermsAccepted    bool         `json:"terms_accepted"`
    PrivacyAccepted  bool         `json:"privacy_accepted"`
    MarketingConsent bool         `json:"marketing_consent,omitempty"`
}

type Organization struct {
    Name        string `json:"name"`
    Type        string `json:"type"`
    Description string `json:"description"`
}

func main() {
    payload := RegisterRequest{
        Fullname: "John Doe",
        Email:    "john.doe@example.com",
        Password: "secure_password123",
        Organization: Organization{
            Name:        "Acme Corporation",
            Type:        "Platform",
            Description: "A business platform for managing teams and projects",
        },
        TermsAccepted:    true,
        PrivacyAccepted:  true,
        MarketingConsent: false,
    }
    
    jsonData, _ := json.Marshal(payload)
    
    req, _ := http.NewRequest("POST", "https://api.example.com/auth/register", bytes.NewBuffer(jsonData))
    req.Header.Set("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
    
    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("%+v\n", result)
}

## Usage Notes

<AccordionGroup>
  <Accordion title="Registration Process" icon="user-plus">
    What happens during registration:
    
    - **Account Creation**: User account is created with provided details
    - **Organization Setup**: New organization is created and linked to user
    - **Email Verification**: Verification email is sent to user's email
    - **Terms Acceptance**: Legal terms and privacy policy are recorded
    - **Initial Setup**: User becomes organization admin by default
  </Accordion>
  
  <Accordion title="Organization Types" icon="building">
    Available organization types:
    
    - **Platform**: Business platform for managing teams and projects
    - **Agency**: Marketing or service agency
    - **Enterprise**: Large enterprise organization
    - **Other**: Any other type of organization
  </Accordion>
  
  <Accordion title="Email Verification" icon="mail">
    Email verification process:
    
    - **Verification Required**: Most registrations require email verification
    - **Verification Email**: Sent automatically after successful registration
    - **Verification Token**: Unique token for verifying email address
    - **Verification Link**: Click link in email to complete verification
  </Accordion>
  
  <Accordion title="Security Features" icon="shield">
    Security measures:
    
    - **Password Requirements**: Strong password requirements enforced
    - **Rate Limiting**: Prevents spam and abuse
    - **Email Validation**: Validates email format and uniqueness
    - **Terms Compliance**: Ensures legal compliance
  </Accordion>
</AccordionGroup>

    import requests
    from typing import Dict, Optional
    
    class UserRegistrationManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def register_user(self, user_data: Dict) -> Dict:
            """Register a new user with organization"""
            try:
                response = self.api_client.post('/auth/register', json=user_data)
                response.raise_for_status()
                
                result = response.json()
                print(f"User registered: {result['data']['email']}")
                print(f"Organization created: {result['data']['organization_name']}")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error registering user: {e}")
                raise
        
        def register_with_organization(self, 
                                     fullname: str,
                                     email: str,
                                     password: str,
                                     org_name: str,
                                     org_type: str,
                                     org_description: str,
                                     marketing_consent: bool = False) -> Dict:
            """Register user with organization details"""
            user_data = {
                "fullname": fullname,
                "email": email,
                "password": password,
                "organization": {
                    "name": org_name,
                    "type": org_type,
                    "description": org_description
                },
                "terms_accepted": True,
                "privacy_accepted": True,
                "marketing_consent": marketing_consent
            }
            
            return self.register_user(user_data)
        
        def register_platform_user(self, 
                                 fullname: str,
                                 email: str,
                                 password: str,
                                 org_name: str,
                                 org_description: str) -> Dict:
            """Register a platform user"""
            return self.register_with_organization(
                fullname=fullname,
                email=email,
                password=password,
                org_name=org_name,
                org_type="Platform",
                org_description=org_description
            )
        
        def register_agency_user(self, 
                               fullname: str,
                               email: str,
                               password: str,
                               org_name: str,
                               org_description: str) -> Dict:
            """Register an agency user"""
            return self.register_with_organization(
                fullname=fullname,
                email=email,
                password=password,
                org_name=org_name,
                org_type="Agency",
                org_description=org_description
            )
        
        def register_enterprise_user(self, 
                                   fullname: str,
                                   email: str,
                                   password: str,
                                   org_name: str,
                                   org_description: str) -> Dict:
            """Register an enterprise user"""
            return self.register_with_organization(
                fullname=fullname,
                email=email,
                password=password,
                org_name=org_name,
                org_type="Enterprise",
                org_description=org_description
            )
        
        def validate_registration_data(self, user_data: Dict) -> bool:
            """Validate registration data before submission"""
            required_fields = ['fullname', 'email', 'password', 'organization']
            
            for field in required_fields:
                if field not in user_data:
                    print(f"Missing required field: {field}")
                    return False
            
            # Validate email format
            if '@' not in user_data['email']:
                print("Invalid email format")
                return False
            
            # Validate password strength
            password = user_data['password']
            if len(password) < 8:
                print("Password must be at least 8 characters long")
                return False
            
            # Validate organization data
            org = user_data['organization']
            if 'name' not in org or 'type' not in org:
                print("Organization name and type are required")
                return False
            
            return True
        
        def register_user_safe(self, user_data: Dict) -> Dict:
            """Register user with validation"""
            if not self.validate_registration_data(user_data):
                raise ValueError("Invalid registration data")
            
            return self.register_user(user_data)
