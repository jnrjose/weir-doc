---
title: "Validate Registration"
api: "POST /auth/validate-registration"
description: "Validate OTP and complete user registration process"
---

Validate the OTP (One-Time Password) received during registration and complete the user registration process. This endpoint finalizes the user account creation.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and is used to complete the user registration process by verifying the OTP sent to the user's email.
</Note>

## Authentication

This endpoint does not require authentication as it's used during the registration process.

## Request

<ParamField body="email" type="string" required>
  Email address of the user completing registration
  
  **Example**: "user@example.com"
  
  **Constraints**: 
  - Must be a valid email format
  - Must match the email used in registration
</ParamField>

<ParamField body="otp" type="string" required>
  One-Time Password received via email
  
  **Example**: "123456"
  
  **Constraints**: 
  - Must be 6 digits
  - Must not be expired
  - Must match the OTP sent to the email
</ParamField>

<ParamField body="registration_id" type="string" required>
  Registration ID from the initial registration request
  
  **Example**: "reg_1234567890abcdef"
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the registration was validated successfully
</ResponseField>

<ResponseField name="data" type="object">
  Contains user account information and authentication tokens
</ResponseField>

<ResponseField name="data.user_id" type="string">
  Unique identifier for the created user account
</ResponseField>

<ResponseField name="data.email" type="string">
  User's email address
</ResponseField>

<ResponseField name="data.fullname" type="string">
  User's full name
</ResponseField>

<ResponseField name="data.status" type="string">
  User account status (active, pending, suspended)
</ResponseField>

<ResponseField name="data.access_token" type="string">
  JWT access token for API authentication
</ResponseField>

<ResponseField name="data.refresh_token" type="string">
  Refresh token for obtaining new access tokens
</ResponseField>

<ResponseField name="data.expires_in" type="integer">
  Access token expiration time in seconds
</ResponseField>

<ResponseField name="data.token_type" type="string">
  Token type (Bearer)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="OTP Validation" icon="check">
    OTP requirements:
    
    - OTP must be exactly 6 digits
    - OTP expires after 10 minutes
    - Only the most recent OTP is valid
    - OTP can only be used once
  </Accordion>
  
  <Accordion title="Account Creation" icon="user-plus">
    Upon successful validation:
    
    - User account is created and activated
    - Authentication tokens are provided
    - User can immediately access the platform
    - Welcome email is sent to the user
  </Accordion>
  
  <Accordion title="Security" icon="shield">
    Security features:
    
    - OTP is single-use and time-limited
    - Registration ID prevents unauthorized access
    - Failed attempts are logged and monitored
    - Account is immediately active upon validation
  </Accordion>
</AccordionGroup>

## Integration Examples

<AccordionGroup>
  <Accordion title="Registration Flow" icon="flow">
    ```javascript
// Complete registration flow
async function completeRegistration(email, otp, registrationId) {
  try {
    const response = await fetch('/auth/validate-registration', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        email: email,
        otp: otp,
        registration_id: registrationId
      })
    });
    
    const data = await response.json();
    
    if (data.success) {
      // Store authentication tokens
      localStorage.setItem('access_token', data.data.access_token);
      localStorage.setItem('refresh_token', data.data.refresh_token);
      
      // Redirect to dashboard
      window.location.href = '/dashboard';
      
      return data;
    } else {
      throw new Error(data.error.message);
    }
    
  } catch (error) {
    console.error('Registration validation failed:', error);
    throw error;
  }
}
```
  </Accordion>
</AccordionGroup>
