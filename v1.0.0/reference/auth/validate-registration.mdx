---
title: "Validate Registration"
api: "POST /auth/validate/registration"
description: "Validate email address and complete user registration"
---

Validate a user's email address using the verification token received during registration. This endpoint completes the registration process by confirming the user's email address and activating their account.

<Note>
  **Auth API Endpoint**
  
  This endpoint is part of the Auth API category and does not require authentication (it's used to complete the registration process). It's designed for email verification and account activation.
</Note>

## Authentication

This endpoint does not require authentication as it's used to complete the registration process.

## Request

<ParamField body="otpSession" type="string" required>
  OTP session identifier from the registration response
  
  **Example**: "session_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid session ID from registration
  - Session must not be expired
  - Session must be in pending verification state
</ParamField>

<ParamField body="otp" type="string" required>
  One-time password (OTP) code received via email
  
  **Example**: "123456"
  
  **Constraints**: 
  - Must be a 6-digit numeric code
  - Code must match the one sent to user's email
  - Code must not be expired
</ParamField>

<ParamField body="email" type="string" required="false">
  Email address for additional verification
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: 
  - Must match the email used during registration
  - Optional but recommended for security
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the validation was successful
</ResponseField>

<ResponseField name="data" type="object">
  Contains the validation and account information
</ResponseField>

<ResponseField name="data.user_id" type="string">

</ResponseField>

<ResponseField name="data.organization_id" type="string">

</ResponseField>

<ResponseField name="data.email" type="string">
  Email address of the validated user
</ResponseField>

</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Validation Process" icon="check">
    How validation works:
    
    - **OTP Verification**: 6-digit code sent to user's email
    - **Session Validation**: Session ID must be valid and not expired
    - **Account Activation**: Account becomes active after successful validation
    - **Login Credentials**: Access and refresh tokens provided for immediate login
  </Accordion>
  
  <Accordion title="OTP Security" icon="shield">
    OTP security features:
    
    - **Time-based**: OTP codes expire after a set time period
    - **Single Use**: Each OTP can only be used once
    - **Rate Limited**: Limited number of validation attempts
    - **Session Bound**: OTP is tied to specific session
  </Accordion>
  
  <Accordion title="Account Status" icon="user">
    Account status after validation:
    
    - **Active**: Account is fully functional
    - **Verified**: Email address is confirmed
    - **Login Ready**: User can immediately log in
    - **Organization Access**: Full access to organization features
  </Accordion>
  
  <Accordion title="Error Handling" icon="exclamation-triangle">
    Common error scenarios:
    
    - **Invalid OTP**: Wrong or expired verification code
    - **Expired Session**: Session has expired
    - **Already Verified**: Account was already verified
    - **Rate Limited**: Too many validation attempts
  </Accordion>
</AccordionGroup>

    ```javascript
    class RegistrationValidationService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async validateRegistration(otpSession, otp, email = null) {
        try {
          const payload = {
            otpSession: otpSession,
            otp: otp
          };
          
          if (email) {
            payload.email = email;
          }
          
          const response = await this.apiClient.makeRequest('/auth/validate/registration', {
            method: 'POST',
            body: JSON.stringify(payload)
          });
          
          if (!response.ok) {
            throw new Error('Validation failed');
          }
          
          const result = await response.json();
          
          // Log validation
          console.log(`Registration validated for: ${result.data.email}`);
          console.log(`Account status: ${result.data.account_status}`);
          
          return result;
          
        } catch (error) {
          console.error('Error validating registration:', error);
          throw error;
        }
      }
      
      async validateWithEmail(otpSession, otp, email) {
        return this.validateRegistration(otpSession, otp, email);
      }
      
      async validateWithoutEmail(otpSession, otp) {
        return this.validateRegistration(otpSession, otp);
      }
      
      async validateAndLogin(otpSession, otp, email = null) {
        const result = await this.validateRegistration(otpSession, otp, email);
        
        // Store login credentials
        if (result.data.login_credentials) {
          localStorage.setItem('access_token', result.data.login_credentials.access_token);
          localStorage.setItem('refresh_token', result.data.login_credentials.refresh_token);
          localStorage.setItem('user_id', result.data.user_id);
          localStorage.setItem('organization_id', result.data.organization_id);
        }
        
        return result;
      }
      
      async validateWithRetry(otpSession, otp, email = null, maxRetries = 3) {
        let lastError = null;
        
        for (let i = 0; i < maxRetries; i++) {
          try {
            return await this.validateRegistration(otpSession, otp, email);
          } catch (error) {
            lastError = error;
            
            // If it's a rate limit error, wait before retrying
            if (error.message.includes('rate limit') || error.message.includes('429')) {
              const waitTime = Math.pow(2, i) * 1000; // Exponential backoff
              await new Promise(resolve => setTimeout(resolve, waitTime));
            } else {
              // For other errors, don't retry
              throw error;
            }
          }
        }
        
        throw lastError;
      }
    }
    ```

    ```python
    import requests
    import time
    from typing import Dict, Optional
    
    class RegistrationValidationManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def validate_registration(self, 
                                otp_session: str, 
                                otp: str, 
                                email: Optional[str] = None) -> Dict:
            """Validate user registration with OTP"""
            try:
                payload = {
                    "otpSession": otp_session,
                    "otp": otp
                }
                
                if email:
                    payload["email"] = email
                
                response = self.api_client.post('/auth/validate/registration', json=payload)
                response.raise_for_status()
                
                result = response.json()
                print(f"Registration validated for: {result['data']['email']}")
                print(f"Account status: {result['data']['account_status']}")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error validating registration: {e}")
                raise
        
        def validate_with_email(self, otp_session: str, otp: str, email: str) -> Dict:
            """Validate registration with email verification"""
            return self.validate_registration(otp_session, otp, email)
        
        def validate_without_email(self, otp_session: str, otp: str) -> Dict:
            """Validate registration without email verification"""
            return self.validate_registration(otp_session, otp)
        
        def validate_and_login(self, 
                             otp_session: str, 
                             otp: str, 
                             email: Optional[str] = None) -> Dict:
            """Validate registration and store login credentials"""
            result = self.validate_registration(otp_session, otp, email)
            
            # Store login credentials
            if result["data"].get("login_credentials"):
                credentials = result["data"]["login_credentials"]
                print(f"Access token: {credentials['access_token'][:20]}...")
                print(f"Refresh token: {credentials['refresh_token'][:20]}...")
                print(f"Expires in: {credentials['expires_in']} seconds")
            
            return result
        
        def validate_with_retry(self, 
                              otp_session: str, 
                              otp: str, 
                              email: Optional[str] = None,
                              max_retries: int = 3) -> Dict:
            """Validate registration with retry logic"""
            last_error = None
            
            for attempt in range(max_retries):
                try:
                    return self.validate_registration(otp_session, otp, email)
                except requests.exceptions.RequestException as e:
                    last_error = e
                    
                    # If it's a rate limit error, wait before retrying
                    if "rate limit" in str(e) or "429" in str(e):
                        wait_time = 2 ** attempt  # Exponential backoff
                        print(f"Rate limited, waiting {wait_time} seconds before retry...")
                        time.sleep(wait_time)
                    else:
                        # For other errors, don't retry
                        raise e
            
            raise last_error
        
        def validate_otp_format(self, otp: str) -> bool:
            """Validate OTP format"""
            return otp.isdigit() and len(otp) == 6
        
        def validate_session_format(self, session: str) -> bool:
            """Validate session format"""
            return session.startswith('session_') and len(session) > 20
        
        def validate_registration_safe(self, 
                                     otp_session: str, 
                                     otp: str, 
                                     email: Optional[str] = None) -> Dict:
            """Validate registration with format validation"""
            if not self.validate_otp_format(otp):
                raise ValueError("OTP must be a 6-digit number")
            
            if not self.validate_session_format(otp_session):
                raise ValueError("Invalid session format")
            
            return self.validate_registration(otp_session, otp, email)
        
        def get_validation_status(self, result: Dict) -> str:
            """Get validation status from result"""
            return result["data"]["verification_status"]
        
        def get_account_status(self, result: Dict) -> str:
            """Get account status from result"""
            return result["data"]["account_status"]
        
        def is_validation_successful(self, result: Dict) -> bool:
            """Check if validation was successful"""
            return (result["success"] and 
                   result["data"]["verification_status"] == "verified" and
                   result["data"]["account_status"] == "active")

    validation_manager = RegistrationValidationManager(api_client)

    validation = validation_manager.validate_registration(

        otp="123456",
        email="john.doe@example.com"
    )

    retry_result = validation_manager.validate_with_retry(
        otp_session="session_1234567890abcdef",
        otp="123456",
        email="john.doe@example.com",
        max_retries=3
    )
    
    # Check validation status
    if validation_manager.is_validation_successful(validation):
        print("Registration validation successful!")
        print(f"Account status: {validation_manager.get_account_status(validation)}")
    else:
        print("Registration validation failed!")
    ```
