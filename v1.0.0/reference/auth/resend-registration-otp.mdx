---
title: "Resend Registration OTP"
api: "PUT /auth/resend/otp/{session}"
description: "Resend verification OTP code to user's email"
---

Resend a verification OTP (One-Time Password) code to the user's email address. This endpoint is useful when the original verification email was not received, expired, or the user needs a new code.

<Note>
  **Auth API Endpoint**
  
  This endpoint is part of the Auth API category and does not require authentication (it's used to resend verification codes). It's designed for email verification and account activation support.
</Note>

## Authentication

This endpoint does not require authentication as it's used to resend verification codes during the registration process.

## Path Parameters

<ParamField path="session" type="string" required>
  OTP session identifier from the registration response
  
  **Example**: "session_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid session ID from registration
  - Session must not be expired
  - Session must be in pending verification state
</ParamField>

## Request

<ParamField body="email" type="string" required="false">
  Email address to resend OTP to
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: 
  - Must match the email used during registration
  - Optional but recommended for security
</ParamField>

<ParamField body="reason" type="string" required="false">
  Reason for resending OTP
  
  **Example**: "Email not received"
  
  **Options**: 
  - "Email not received"
  - "Code expired"
  - "Code lost"
  - "Other"
  
  **Note**: Used for audit and support purposes
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the OTP was resent successfully
</ResponseField>

<ResponseField name="data" type="object">
  Contains the resend operation information
</ResponseField>

<ResponseField name="data.session_id" type="string">
  OTP session identifier
</ResponseField>

<ResponseField name="data.email" type="string">
  Email address the OTP was sent to
</ResponseField>

<ResponseField name="data.otp_expires_at" type="string">
  ISO 8601 timestamp when the OTP expires
</ResponseField>

<ResponseField name="data.resend_count" type="integer">
  Number of times OTP has been resent for this session
</ResponseField>

<ResponseField name="data.max_resends" type="integer">
  Maximum number of resends allowed for this session
</ResponseField>

<ResponseField name="data.resend_attempts_remaining" type="integer">
  Number of resend attempts remaining
</ResponseField>

<ResponseField name="data.sent_at" type="string">
  ISO 8601 timestamp when the OTP was sent
</ResponseField>

<ResponseField name="data.delivery_status" type="string">
  Status of email delivery (sent, delivered, failed)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Resend Limits" icon="clock">
    Resend restrictions:
    
    - **Maximum Resends**: Limited number of resends per session
    - **Rate Limiting**: Cooldown period between resend requests
    - **Session Expiry**: Resends only allowed for active sessions
    - **Account Status**: Resends only for unverified accounts
  </Accordion>
  
  <Accordion title="OTP Expiration" icon="hourglass">
    OTP timing:
    
    - **Expiration Time**: OTP codes expire after a set time period
    - **New Expiration**: Each resend creates a new expiration time
    - **Single Use**: Each OTP can only be used once
    - **Time Window**: Limited time to use the OTP after receiving
  </Accordion>
  
  <Accordion title="Email Delivery" icon="mail">
    Email delivery features:
    
    - **Delivery Status**: Track email delivery status
    - **Retry Logic**: Automatic retry for failed deliveries
    - **Spam Prevention**: Measures to prevent emails from going to spam
    - **Delivery Confirmation**: Confirmation when email is delivered
  </Accordion>
  
  <Accordion title="Security Measures" icon="shield">
    Security features:
    
    - **Rate Limiting**: Prevents abuse and spam
    - **Session Validation**: Ensures valid session for resend
    - **Email Verification**: Confirms email address matches registration
    - **Audit Logging**: Tracks all resend attempts
  </Accordion>
</AccordionGroup>

    ```javascript
    class OTPResendService {
      constructor(apiClient) {
        this.apiClient = apiClient;
      }
      
      async resendOTP(sessionId, email = null, reason = null) {
        try {
          const payload = {};
          
          if (email) {
            payload.email = email;
          }
          
          if (reason) {
            payload.reason = reason;
          }
          
          const response = await this.apiClient.makeRequest(`/auth/resend/otp/${sessionId}`, {
            method: 'PUT',
            body: JSON.stringify(payload)
          });
          
          if (!response.ok) {
            throw new Error('Failed to resend OTP');
          }
          
          const result = await response.json();
          
          // Log resend
          console.log(`OTP resent to: ${result.data.email}`);
          console.log(`Resend count: ${result.data.resend_count}`);
          console.log(`Attempts remaining: ${result.data.resend_attempts_remaining}`);
          
          return result;
          
        } catch (error) {
          console.error('Error resending OTP:', error);
          throw error;
        }
      }
      
      async resendOTPWithEmail(sessionId, email, reason = null) {
        return this.resendOTP(sessionId, email, reason);
      }
      
      async resendOTPWithoutEmail(sessionId, reason = null) {
        return this.resendOTP(sessionId, null, reason);
      }
      
      async resendOTPForEmailNotReceived(sessionId, email) {
        return this.resendOTP(sessionId, email, 'Email not received');
      }
      
      async resendOTPForCodeExpired(sessionId, email) {
        return this.resendOTP(sessionId, email, 'Code expired');
      }
      
      async resendOTPForCodeLost(sessionId, email) {
        return this.resendOTP(sessionId, email, 'Code lost');
      }
      
      async resendOTPWithRetry(sessionId, email = null, reason = null, maxRetries = 3) {
        let lastError = null;
        
        for (let i = 0; i < maxRetries; i++) {
          try {
            return await this.resendOTP(sessionId, email, reason);
          } catch (error) {
            lastError = error;
            
            // If it's a rate limit error, wait before retrying
            if (error.message.includes('rate limit') || error.message.includes('429')) {
              const waitTime = Math.pow(2, i) * 1000; // Exponential backoff
              await new Promise(resolve => setTimeout(resolve, waitTime));
            } else {
              // For other errors, don't retry
              throw error;
            }
          }
        }
        
        throw lastError;
      }
      
      async checkResendStatus(sessionId) {
        try {
          const response = await this.apiClient.makeRequest(`/auth/resend/otp/${sessionId}`, {
            method: 'PUT',
            body: JSON.stringify({})
          });
          
          if (!response.ok) {
            throw new Error('Failed to check resend status');
          }
          
          const result = await response.json();
          
          return {
            resendCount: result.data.resend_count,
            maxResends: result.data.max_resends,
            attemptsRemaining: result.data.resend_attempts_remaining,
            canResend: result.data.resend_attempts_remaining > 0
          };
          
        } catch (error) {
          console.error('Error checking resend status:', error);
          throw error;
        }
      }
    }
    
    // Usage example
    const otpResendService = new OTPResendService(apiClient);
    
    // Resend OTP with email
    const resendResult = await otpResendService.resendOTPWithEmail(
      'session_1234567890abcdef',
      'john.doe@example.com',
      'Email not received'
    );
    
    // Resend OTP for specific reasons
    const emailNotReceived = await otpResendService.resendOTPForEmailNotReceived(
      'session_1234567890abcdef',
      'john.doe@example.com'
    );
    
    // Check resend status
    const status = await otpResendService.checkResendStatus('session_1234567890abcdef');
    console.log(`Can resend: ${status.canResend}`);
    console.log(`Attempts remaining: ${status.attemptsRemaining}`);
    ```

    ```python
    import requests
    import time
    from typing import Dict, Optional
    
    class OTPResendManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def resend_otp(self, 
                      session_id: str, 
                      email: Optional[str] = None, 
                      reason: Optional[str] = None) -> Dict:
            """Resend OTP code to user's email"""
            try:
                payload = {}
                
                if email:
                    payload["email"] = email
                
                if reason:
                    payload["reason"] = reason
                
                response = self.api_client.put(f'/auth/resend/otp/{session_id}', json=payload)
                response.raise_for_status()
                
                result = response.json()
                print(f"OTP resent to: {result['data']['email']}")
                print(f"Resend count: {result['data']['resend_count']}")
                print(f"Attempts remaining: {result['data']['resend_attempts_remaining']}")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error resending OTP: {e}")
                raise
        
        def resend_otp_with_email(self, session_id: str, email: str, reason: Optional[str] = None) -> Dict:
            """Resend OTP with email verification"""
            return self.resend_otp(session_id, email, reason)
        
        def resend_otp_without_email(self, session_id: str, reason: Optional[str] = None) -> Dict:
            """Resend OTP without email verification"""
            return self.resend_otp(session_id, None, reason)
        
        def resend_otp_for_email_not_received(self, session_id: str, email: str) -> Dict:
            """Resend OTP because email was not received"""
            return self.resend_otp(session_id, email, "Email not received")
        
        def resend_otp_for_code_expired(self, session_id: str, email: str) -> Dict:
            """Resend OTP because code expired"""
            return self.resend_otp(session_id, email, "Code expired")
        
        def resend_otp_for_code_lost(self, session_id: str, email: str) -> Dict:
            """Resend OTP because code was lost"""
            return self.resend_otp(session_id, email, "Code lost")
        
        def resend_otp_with_retry(self, 
                                session_id: str, 
                                email: Optional[str] = None, 
                                reason: Optional[str] = None,
                                max_retries: int = 3) -> Dict:
            """Resend OTP with retry logic"""
            last_error = None
            
            for attempt in range(max_retries):
                try:
                    return self.resend_otp(session_id, email, reason)
                except requests.exceptions.RequestException as e:
                    last_error = e
                    
                    # If it's a rate limit error, wait before retrying
                    if "rate limit" in str(e) or "429" in str(e):
                        wait_time = 2 ** attempt  # Exponential backoff
                        print(f"Rate limited, waiting {wait_time} seconds before retry...")
                        time.sleep(wait_time)
                    else:
                        # For other errors, don't retry
                        raise e
            
            raise last_error
        
        def check_resend_status(self, session_id: str) -> Dict:
            """Check resend status for a session"""
            try:
                response = self.api_client.put(f'/auth/resend/otp/{session_id}', json={})
                response.raise_for_status()
                
                result = response.json()
                
                return {
                    "resend_count": result["data"]["resend_count"],
                    "max_resends": result["data"]["max_resends"],
                    "attempts_remaining": result["data"]["resend_attempts_remaining"],
                    "can_resend": result["data"]["resend_attempts_remaining"] > 0
                }
                
            except requests.exceptions.RequestException as e:
                print(f"Error checking resend status: {e}")
                raise
        
        def get_resend_reasons(self) -> list:
            """Get available resend reasons"""
            return [
                "Email not received",
                "Code expired",
                "Code lost",
                "Other"
            ]
        
        def validate_session_format(self, session_id: str) -> bool:
            """Validate session ID format"""
            return session_id.startswith('session_') and len(session_id) > 20
        
        def resend_otp_safe(self, 
                          session_id: str, 
                          email: Optional[str] = None, 
                          reason: Optional[str] = None) -> Dict:
            """Resend OTP with validation"""
            if not self.validate_session_format(session_id):
                raise ValueError("Invalid session ID format")
            
            return self.resend_otp(session_id, email, reason)
        
        def get_otp_expiration_time(self, result: Dict) -> str:
            """Get OTP expiration time from result"""
            return result["data"]["otp_expires_at"]
        
        def get_delivery_status(self, result: Dict) -> str:
            """Get email delivery status from result"""
            return result["data"]["delivery_status"]
        
        def is_resend_successful(self, result: Dict) -> bool:
            """Check if resend was successful"""
            return (result["success"] and 
                   result["data"]["delivery_status"] in ["sent", "delivered"])
    
    # Usage example
    otp_resend_manager = OTPResendManager(api_client)
    
    # Resend OTP with email
    resend_result = otp_resend_manager.resend_otp_with_email(
        session_id="session_1234567890abcdef",
        email="john.doe@example.com",
        reason="Email not received"
    )
    
    # Resend OTP for specific reasons
    email_not_received = otp_resend_manager.resend_otp_for_email_not_received(
        session_id="session_1234567890abcdef",
        email="john.doe@example.com"
    )
    
    # Check resend status
    status = otp_resend_manager.check_resend_status("session_1234567890abcdef")
    print(f"Can resend: {status['can_resend']}")
    print(f"Attempts remaining: {status['attempts_remaining']}")
    
    # Resend with retry
    retry_result = otp_resend_manager.resend_otp_with_retry(
        session_id="session_1234567890abcdef",
        email="john.doe@example.com",
        reason="Email not received",
        max_retries=3
    )
    
    # Check if resend was successful
    if otp_resend_manager.is_resend_successful(resend_result):
        print("OTP resent successfully!")
        print(f"Expires at: {otp_resend_manager.get_otp_expiration_time(resend_result)}")
    else:
        print("OTP resend failed!")
    ```
