---
title: "Resend Registration OTP"
api: "PUT /auth/resend-registration-otp"
description: "Resend OTP (One-Time Password) for user registration verification"
---

Resend the OTP (One-Time Password) for user registration verification. This endpoint is used when the original OTP has expired or was not received by the user.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and is used for user registration verification. It helps users complete their registration process when they need a new OTP.
</Note>

## Authentication

This endpoint does not require authentication as it's used during the registration process.

## Request

<ParamField body="email" type="string" required>
  Email address of the user requesting OTP resend
  
  **Example**: "user@example.com"
  
  **Constraints**: 
  - Must be a valid email format
  - Must be associated with a pending registration
</ParamField>

<ParamField body="registration_id" type="string" required>
  Registration ID from the initial registration request
  
  **Example**: "reg_1234567890abcdef"
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the OTP was resent successfully
</ResponseField>

<ResponseField name="data" type="object">
  Contains OTP resend information
</ResponseField>

<ResponseField name="data.registration_id" type="string">
  Registration ID for tracking
</ResponseField>

<ResponseField name="data.email" type="string">
  Email address where OTP was sent
</ResponseField>

<ResponseField name="data.otp_expires_at" type="string">
  ISO 8601 timestamp when the OTP expires
</ResponseField>

<ResponseField name="data.retry_count" type="integer">
  Number of OTP resend attempts
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Example Request

<CodeGroup>
```bash cURL
curl -X PUT "https://api.example.com/auth/resend-registration-otp" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "registration_id": "reg_1234567890abcdef"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.example.com/auth/resend-registration-otp', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    email: 'user@example.com',
    registration_id: 'reg_1234567890abcdef'
  })
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

data = {
    'email': 'user@example.com',
    'registration_id': 'reg_1234567890abcdef'
}

response = requests.put(
    'https://api.example.com/auth/resend-registration-otp',
    headers={'Content-Type': 'application/json'},
    json=data
)

print(response.json())
```
</CodeGroup>

## Usage Notes

<AccordionGroup>
  <Accordion title="Rate Limiting" icon="clock">
    OTP resend limits:
    
    - Maximum 3 resend attempts per hour per email
    - Rate limit resets after 1 hour
    - Exceeding limits requires waiting period
  </Accordion>
  
  <Accordion title="OTP Expiration" icon="time">
    OTP validity:
    
    - OTP expires after 10 minutes
    - New OTP invalidates previous OTP
    - Expired OTPs cannot be used for verification
  </Accordion>
  
  <Accordion title="Security" icon="shield">
    Security considerations:
    
    - OTP is sent to registered email only
    - Registration ID must match original request
    - Failed attempts are logged for security monitoring
  </Accordion>
</AccordionGroup>
