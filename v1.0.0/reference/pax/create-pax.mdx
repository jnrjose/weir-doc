---
title: "Create PAX"
api: "POST /pax"
description: "Create a new PAX (Platform Access eXchange) configuration"
---

Create a new PAX configuration to establish platform access and data exchange between different systems and organizations. This endpoint allows you to set up secure data sharing and integration capabilities.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for platform access management and data exchange setup.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

<CodeBlock lang="bash">
Authorization: Bearer <your_jwt_token>
</CodeBlock>

## Request

<ParamField body="name" type="string" required>
  Name of the PAX configuration
  
  **Example**: "Customer Data Sync"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must be unique within the organization
</ParamField>

<ParamField body="description" type="string" required="false">
  Description of the PAX configuration's purpose
  
  **Example**: "Synchronize customer data between CRM and analytics platform"
  
  **Constraints**: 
  - Maximum length: 500 characters
</ParamField>

<ParamField body="type" type="string" required>
  Type of PAX configuration
  
  **Options**: "data_exchange", "api_access", "webhook", "sso"
  
  **Example**: "data_exchange"
</ParamField>

<ParamField body="target_organization" type="string" required="false">
  Target organization ID for the PAX
  
  **Example**: "org_0987654321fedcba"
  
  **Note**: Required for data_exchange and api_access types
</ParamField>

<ParamField body="permissions" type="array" required>
  List of permissions to grant
  
  **Example**: ["read:customer_data", "write:analytics_data"]
  
  **Available Permissions**:
  - `read:*` - Read access to all data
  - `write:*` - Write access to all data
  - `read:customer_data` - Read customer data
  - `write:analytics_data` - Write analytics data
  - `execute:operations` - Execute operations
  - `admin:access` - Administrative access
</ParamField>

<ParamField body="data_schema" type="object" required="false">
  Data schema configuration for data exchange
  
  **Example**: {"customer_id": "string", "name": "string", "email": "string"}
  
  **Note**: Required for data_exchange type
</ParamField>

<ParamField body="sync_frequency" type="string" required="false">
  Data synchronization frequency
  
  **Options**: "real_time", "hourly", "daily", "weekly", "manual"
  
  **Default**: "hourly"
  
  **Example**: "hourly"
</ParamField>

<ParamField body="settings" type="object" required="false">
  Additional PAX-specific settings
  
  **Properties**:
  - `encryption` (boolean): Whether to encrypt data in transit
  - `compression` (boolean): Whether to compress data
  - `retry_attempts` (integer): Number of retry attempts on failure
  - `timeout` (integer): Request timeout in seconds
</ParamField>

<ParamField body="webhook_url" type="string" required="false">
  Webhook URL for webhook type PAX
  
  **Example**: "https://api.example.com/webhooks/pax"
  
  **Note**: Required for webhook type
</ParamField>

<ParamField body="sso_provider" type="string" required="false">
  SSO provider for SSO type PAX
  
  **Options**: "saml", "oauth2", "openid_connect"
  
  **Note**: Required for sso type
</ParamField>

import requests
from typing import Dict, List, Optional

class PAXClient:
    def __init__(self, api_client):
        self.api_client = api_client
    
    def create_pax(self, 
                   name: str,
                   description: str,
                   pax_type: str,
                   permissions: List[str],
                   target_organization: Optional[str] = None,
                   data_schema: Optional[Dict] = None,
                   sync_frequency: str = "hourly",
                   webhook_url: Optional[str] = None,
                   sso_provider: Optional[str] = None,
                   **settings) -> Dict:
        """Create a new PAX configuration"""
        try:
            payload = {
                "name": name,
                "description": description,
                "type": pax_type,
                "permissions": permissions,
                "sync_frequency": sync_frequency,
                "settings": {
                    "encryption": settings.get("encryption", True),
                    "compression": settings.get("compression", True),
                    "retry_attempts": settings.get("retry_attempts", 3),
                    "timeout": settings.get("timeout", 30)
                }
            }
            
            if target_organization:
                payload["target_organization"] = target_organization
            if data_schema:
                payload["data_schema"] = data_schema
            if webhook_url:
                payload["webhook_url"] = webhook_url
            if sso_provider:
                payload["sso_provider"] = sso_provider
            
            response = self.api_client.post('/pax', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to create PAX: {e}")
            raise
    
    def create_data_exchange_pax(self, 
                                name: str,
                                description: str,
                                target_organization: str,
                                permissions: List[str],
                                data_schema: Dict,
                                sync_frequency: str = "hourly") -> Dict:
        """Create a data exchange PAX configuration"""
        return self.create_pax(
            name=name,
            description=description,
            pax_type="data_exchange",
            permissions=permissions,
            target_organization=target_organization,
            data_schema=data_schema,
            sync_frequency=sync_frequency
        )
    
    def create_webhook_pax(self, 
                          name: str,
                          description: str,
                          webhook_url: str,
                          permissions: List[str]) -> Dict:
        """Create a webhook PAX configuration"""
        return self.create_pax(
            name=name,
            description=description,
            pax_type="webhook",
            permissions=permissions,
            webhook_url=webhook_url
        )
    
    def create_sso_pax(self, 
                      name: str,
                      description: str,
                      sso_provider: str,
                      permissions: List[str]) -> Dict:
        """Create an SSO PAX configuration"""
        return self.create_pax(
            name=name,
            description=description,
            pax_type="sso",
            permissions=permissions,
            sso_provider=sso_provider
        )
