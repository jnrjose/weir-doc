---
title: "Create Client"
api: "POST /org/create/client"
description: "Create a new client within the organization"
---

Create a new client within your organization for managing API access, authentication, and service integrations. This endpoint allows you to set up clients with different types and configurations.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for client management and API access control within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  Name of the client to create
  
  **Example**: "Mobile App Client"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must be unique within the organization
  - Cannot contain special characters except spaces, hyphens, and underscores
</ParamField>

<ParamField body="teamId" type="string" required="false">
  ID of the team to associate with this client
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID within your organization
  - Team must exist and be accessible
  - If not provided, client will be associated with the user's default team
</ParamField>

<ParamField body="description" type="string" required="false">
  Description of the client's purpose and functionality
  
  **Example**: "Client for mobile application API access"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional but recommended for documentation
</ParamField>

<ParamField body="type" type="string" required>
  Type of client being created
  
  **Options**: 
  - `Web Application`: Web-based application client
  - `Mobile Application`: Mobile app client
  - `Server Application`: Server-side application client
  - `API Client`: API integration client
  - `Third Party`: Third-party service client
  - `Other`: Any other type of client
  
  **Example**: "Mobile Application"
</ParamField>

<ParamField body="redirectUris" type="array" required="false">
  List of redirect URIs for OAuth authentication
  
  **Example**: ["https://app.example.com/callback", "https://app.example.com/auth"]
  
  **Constraints**: 
  - Must be valid HTTPS URLs
  - Maximum 10 redirect URIs per client
  - Required for OAuth-enabled clients
</ParamField>

<ParamField body="scopes" type="array" required="false">
  List of OAuth scopes the client can request
  
  **Example**: ["read", "write", "admin"]
  
  **Available Scopes**:
  - `read`: Read access to resources
  - `write`: Write access to resources
  - `admin`: Administrative access
  - `user`: User management access
  - `team`: Team management access
  - `platform`: Platform management access
  
  **Constraints**: 
  - Must be valid scope names
  - Maximum 20 scopes per client
</ParamField>

<ParamField body="settings" type="object" required="false">
  Client-specific settings and configurations
  
  **Properties**:
  - `oauth_enabled` (boolean): Whether OAuth is enabled for this client
  - `api_key_enabled` (boolean): Whether API key authentication is enabled
  - `rate_limit` (object): Rate limiting configuration
  - `security` (object): Security settings
  - `notifications` (object): Notification preferences
  
  **Example**:
  ```json
  {
    "oauth_enabled": true,
    "api_key_enabled": true,
    "rate_limit": {
      "requests_per_minute": 1000,
      "requests_per_hour": 10000,
      "burst_limit": 100
    },
    "security": {
      "require_https": true,
      "ip_whitelist": ["192.168.1.0/24"],
      "jwt_expiry": 3600
    },
    "notifications": {
      "email_alerts": true,
      "webhook_url": "https://app.example.com/webhooks/client"
    }
  }
  ```
</ParamField>

<ParamField body="tags" type="array" required="false">
  Tags for categorizing and organizing the client
  
  **Example**: ["production", "mobile", "customer-facing"]
  
  **Constraints**: 
  - Maximum 10 tags per client
  - Each tag maximum 50 characters
  - Tags are case-insensitive
</ParamField>

        def validate_client_data(self, client_data: Dict) -> bool:
            """Validate client data before creation"""
            required_fields = ['name', 'type']
            
            for field in required_fields:
                if field not in client_data:
                    print(f"Missing required field: {field}")
                    return False
            
            # Validate client type
            valid_types = [
                'Web Application', 'Mobile Application', 'Server Application',
                'API Client', 'Third Party', 'Other'
            ]
            
            if client_data['type'] not in valid_types:
                print(f"Invalid client type: {client_data['type']}")
                return False
            
            # Validate name length
            if len(client_data['name']) < 2 or len(client_data['name']) > 100:
                print("Client name must be between 2 and 100 characters")
                return False
            
            # Validate redirect URIs if provided
            if 'redirectUris' in client_data:
                for uri in client_data['redirectUris']:
                    if not uri.startswith('https://'):
                        print(f"Invalid redirect URI: {uri} (must be HTTPS)")
                        return False
            
            return True
