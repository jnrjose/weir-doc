---
title: "Get Clients"
api: "GET /org/clients"
description: "Retrieve list of clients in the organization"
---

Retrieve a comprehensive list of all clients within your organization, including their details, configurations, and status. This endpoint provides detailed information about client composition and management.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for client management and oversight within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of clients to return per page
  
  **Example**: "20"
  
  **Default**: "20"
  
  **Constraints**: 
  - Must be between 1 and 100
  - Recommended: 20-50 for optimal performance
</ParamField>

<ParamField query="type" type="string" required="false">
  Filter clients by type
  
  **Options**: "Web Application", "Mobile Application", "Server Application", "API Client", "Third Party", "Other"
  
  **Example**: "Mobile Application"
  
  **Note**: If not specified, returns all clients regardless of type
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter clients by status
  
  **Options**: "active", "inactive", "pending", "suspended"
  
  **Example**: "active"
  
  **Default**: "active"
  
  **Note**: If not specified, returns only active clients
</ParamField>

<ParamField query="teamId" type="string" required="false">
  Filter clients by team ID
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
  - You must have access to the team
</ParamField>

<ParamField query="search" type="string" required="false">
  Search clients by name or description
  
  **Example**: "mobile"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches both name and description fields
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort clients by specified field
  
  **Options**: "name", "type", "status", "created_at", "updated_at"
  
  **Example**: "created_at"
  
  **Default**: "name"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "asc"
</ParamField>

<ParamField query="tags" type="string" required="false">
  Filter clients by tags (comma-separated)
  
  **Example**: "production,mobile"
  
  **Constraints**: 
  - Multiple tags separated by commas
  - Case-insensitive matching
  - Returns clients that have any of the specified tags
</ParamField>

<ParamField query="oauth_enabled" type="string" required="false">
  Filter clients by OAuth status
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Note**: If not specified, returns clients regardless of OAuth status
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Client Types" icon="desktop">
    Available client types:
    
    - **Web Application**: Web-based application clients
    - **Mobile Application**: Mobile app clients
    - **Server Application**: Server-side application clients
    - **API Client**: API integration clients
    - **Third Party**: Third-party service clients
    - **Other**: Any other type of client
  </Accordion>
  
  <Accordion title="Client Status" icon="info">
    Client status options:
    
    - **active**: Client is active and can make requests
    - **inactive**: Client is disabled and cannot make requests
    - **pending**: Client is being set up or configured
    - **suspended**: Client access is temporarily suspended
  </Accordion>
  
  <Accordion title="OAuth Configuration" icon="key">
    OAuth features:
    
    - **Authorization Code Flow**: Standard OAuth 2.0 authorization code flow
    - **Redirect URIs**: Configured allowed redirect URIs for security
    - **Scopes**: Defined permissions the client can request
    - **Client Credentials**: Client ID and secret for authentication
  </Accordion>
  
  <Accordion title="Pagination" icon="list">
    Pagination best practices:
    
    - **Page Size**: Use 20-50 items per page for optimal performance
    - **Sorting**: Sort by relevant fields (name, created_at, updated_at)
    - **Filtering**: Use type, status, and team filters to narrow results
    - **Search**: Use search parameter for finding specific clients
  </Accordion>
</AccordionGroup>

          if (options.type) params.append('type', options.type);

          if (options.tags) params.append('tags', options.tags);
          if (options.oauthEnabled !== undefined) params.append('oauth_enabled', options.oauthEnabled);
          
          const response = await this.apiClient.makeRequest(
            `/org/clients?${params.toString()}`
          );
          
          if (!response.ok) {
            throw new Error('Failed to get clients');

    import requests
    from typing import Dict, List, Optional
    
    class ClientListingManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_clients(self, 
                       page: int = 1,
                       limit: int = 20,
                       client_type: Optional[str] = None,
                       status: str = "active",
                       team_id: Optional[str] = None,
                       search: Optional[str] = None,
                       sort_by: str = "name",
                       sort_order: str = "asc",
                       tags: Optional[List[str]] = None,
                       oauth_enabled: Optional[bool] = None) -> Dict:
            """Get clients with optional filtering and pagination"""
            try:
                params = {
                    "page": page,
                    "limit": limit,
                    "status": status,
                    "sort_by": sort_by,
                    "sort_order": sort_order
                }
                
                if client_type:
                    params["type"] = client_type
                if team_id:
                    params["teamId"] = team_id
                if search:
                    params["search"] = search
                if tags:
                    params["tags"] = ",".join(tags)
                if oauth_enabled is not None:
                    params["oauth_enabled"] = str(oauth_enabled).lower()
                
                response = self.api_client.get('/org/clients', params=params)
                response.raise_for_status()
                
                return response.json()
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting clients: {e}")
                raise
        
        def get_all_clients(self) -> List[Dict]:
            """Get all clients across all pages"""
            all_clients = []
            page = 1
            has_more = True
            
            while has_more:
                result = self.get_clients(page=page, limit=50)
                all_clients.extend(result["data"])
                has_more = result["pagination"]["has_next"]
                page += 1
            
            return all_clients

        def get_client_statistics(self) -> Dict:
            """Get client statistics"""
            all_clients = self.get_all_clients()
            
            stats = {
                "total_clients": len(all_clients),
                "active_clients": len([c for c in all_clients if c["status"] == "active"]),
                "inactive_clients": len([c for c in all_clients if c["status"] == "inactive"]),
                "pending_clients": len([c for c in all_clients if c["status"] == "pending"]),
