---
title: "Send Email"
api: "POST /org/mail/send"
description: "Send email through the organization's mail system"
---

Send email messages through your organization's mail system with support for templates, attachments, and advanced delivery options. This endpoint provides comprehensive email functionality for notifications, communications, and automated messaging.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for email management and communication within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="to" type="array" required>
  List of recipient email addresses
  
  **Example**: ["user@example.com", "admin@example.com"]
  
  **Constraints**: 
  - Must be valid email addresses
  - Maximum 100 recipients per email
  - Each email must be properly formatted
</ParamField>

<ParamField body="cc" type="array" required="false">
  List of CC (carbon copy) email addresses
  
  **Example**: ["manager@example.com"]
  
  **Constraints**: 
  - Must be valid email addresses
  - Maximum 50 CC recipients
  - Optional field
</ParamField>

<ParamField body="bcc" type="array" required="false">
  List of BCC (blind carbon copy) email addresses
  
  **Example**: ["archive@example.com"]
  
  **Constraints**: 
  - Must be valid email addresses
  - Maximum 50 BCC recipients
  - Optional field
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line
  
  **Example**: "Welcome to Our Platform"
  
  **Constraints**: 
  - Maximum length: 200 characters
  - Cannot be empty
  - Should be descriptive and clear
</ParamField>

<ParamField body="body" type="string" required>
  Email body content
  
  **Example**: "Welcome to our platform! We're excited to have you on board."
  
  **Constraints**: 
  - Can be plain text or HTML
  - Maximum length: 1MB
  - HTML content is supported
</ParamField>

<ParamField body="html_body" type="string" required="false">
  HTML version of the email body
  
  **Example**: "<h1>Welcome!</h1><p>Welcome to our platform!</p>"
  
  **Constraints**: 
  - Must be valid HTML
  - Maximum length: 1MB
  - If provided, will be used instead of plain text body
</ParamField>

<ParamField body="from" type="string" required="false">
  Sender email address
  
  **Example**: "noreply@example.com"
  
  **Default**: Organization's default sender address
  
  **Constraints**: 
  - Must be a valid email address
  - Must be from an authorized domain
  - If not provided, uses organization default
</ParamField>

<ParamField body="reply_to" type="string" required="false">
  Reply-to email address
  
  **Example**: "support@example.com"
  
  **Constraints**: 
  - Must be a valid email address
  - If not provided, uses sender address
</ParamField>

<ParamField body="template_id" type="string" required="false">
  ID of the email template to use
  
  **Example**: "welcome_template_123"
  
  **Constraints**: 
  - Must be a valid template ID
  - Template must exist in the organization
  - If provided, template variables will be used
</ParamField>

<ParamField body="template_variables" type="object" required="false">
  Variables to replace in the email template
  
  **Example**:
  ```json
  {
    "user_name": "John Doe",
    "company_name": "Acme Corp",
    "activation_link": "https://example.com/activate/123"
  }
  ```
  
  **Constraints**: 
  - Must match template variable names
  - Values will be inserted into template placeholders
</ParamField>

<ParamField body="attachments" type="array" required="false">
  List of file attachments
  
  **Example**:
  ```json
  [
    {
      "filename": "document.pdf",
      "content": "base64_encoded_content",
      "content_type": "application/pdf"
    }
  ]
  ```
  
  **Constraints**: 
  - Maximum 10 attachments per email
  - Each attachment maximum 25MB
  - Content must be base64 encoded
</ParamField>

<ParamField body="priority" type="string" required="false">
  Email priority level
  
  **Options**: "low", "normal", "high", "urgent"
  
  **Example**: "normal"
  
  **Default**: "normal"
  
  **Constraints**: 
  - Must be one of the specified options
  - Affects delivery priority
</ParamField>

<ParamField body="scheduled_at" type="string" required="false">
  ISO 8601 timestamp for scheduled delivery
  
  **Example**: "2024-01-15T14:30:00Z"
  
  **Constraints**: 
  - Must be in the future
  - Cannot be more than 30 days in the future
  - If not provided, email is sent immediately
</ParamField>

<ParamField body="tracking" type="object" required="false">
  Email tracking configuration
  
  **Properties**:
  - `opens` (boolean): Track email opens
  - `clicks` (boolean): Track link clicks
  - `delivery` (boolean): Track delivery status
  
  **Example**:
  ```json
  {
    "opens": true,
    "clicks": true,
    "delivery": true
  }
  ```
</ParamField>

<ParamField body="metadata" type="object" required="false">
  Additional metadata for the email
  
  **Example**:
  ```json
  {
    "campaign_id": "welcome_campaign_2024",
    "user_segment": "new_users",
    "source": "registration_flow"
  }
  ```
</ParamField>

package main

import (
    "bytes"
    "encoding/base64"
    "encoding/json"
    "fmt"
    "io/ioutil"
    "net/http"
)

type SendEmailRequest struct {
    To                []string               `json:"to"`
    CC                []string               `json:"cc,omitempty"`
    BCC               []string               `json:"bcc,omitempty"`
    Subject           string                 `json:"subject"`
    Body              string                 `json:"body,omitempty"`
    HTMLBody          string                 `json:"html_body,omitempty"`
    From              string                 `json:"from,omitempty"`
    ReplyTo           string                 `json:"reply_to,omitempty"`
    TemplateID        string                 `json:"template_id,omitempty"`
    TemplateVariables map[string]interface{} `json:"template_variables,omitempty"`
    Attachments       []Attachment           `json:"attachments,omitempty"`
    Priority          string                 `json:"priority,omitempty"`
    ScheduledAt       string                 `json:"scheduled_at,omitempty"`
    Tracking          *TrackingConfig        `json:"tracking,omitempty"`
    Metadata          map[string]interface{} `json:"metadata,omitempty"`
}

type Attachment struct {
    Filename    string `json:"filename"`
    Content     string `json:"content"`
    ContentType string `json:"content_type"`
}

type TrackingConfig struct {
    Opens    bool `json:"opens"`
    Clicks   bool `json:"clicks"`
    Delivery bool `json:"delivery"`
}

func main() {
    // Read and encode attachment
    fileContent, _ := ioutil.ReadFile("welcome_guide.pdf")
    attachmentContent := base64.StdEncoding.EncodeToString(fileContent)
    
    payload := SendEmailRequest{
        To:      []string{"user@example.com", "admin@example.com"},
        CC:      []string{"manager@example.com"},
        BCC:     []string{"archive@example.com"},
        Subject: "Welcome to Our Platform",
        HTMLBody: "<h1>Welcome!</h1><p>Welcome to our platform! We are excited to have you on board.</p><p>Best regards,<br>The Team</p>",
        From:    "noreply@example.com",
        ReplyTo: "support@example.com",
        TemplateID: "welcome_template_123",
        TemplateVariables: map[string]interface{}{
            "user_name":      "John Doe",
            "company_name":   "Acme Corp",
            "activation_link": "https://example.com/activate/123",
        },
        Attachments: []Attachment{
            {
                Filename:    "welcome_guide.pdf",
                Content:     attachmentContent,
                ContentType: "application/pdf",
            },
        },
        Priority: "normal",
        Tracking: &TrackingConfig{
            Opens:    true,
            Clicks:   true,
            Delivery: true,
        },
        Metadata: map[string]interface{}{
            "campaign_id":   "welcome_campaign_2024",
            "user_segment":  "new_users",
            "source":        "registration_flow",
        },
    }
    
    jsonData, _ := json.Marshal(payload)
    
    req, _ := http.NewRequest("POST", "https://api.example.com/org/mail/send", bytes.NewBuffer(jsonData))
    req.Header.Set("Authorization", "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...")
    req.Header.Set("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
    
    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("%+v\n", result)
}

            """Create attachment from file"""
