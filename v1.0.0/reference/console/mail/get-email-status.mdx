---
title: "Get Email Status"
api: "GET /org/mail/status/{messageId}"
description: "Check the delivery status and tracking information for an email"
---

Retrieve detailed delivery status and tracking information for a specific email message. This endpoint provides comprehensive information about email delivery, opens, clicks, and other engagement metrics.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for email tracking and status monitoring within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="messageId" type="string" required>
  Unique identifier of the email message to check
  
  **Example**: "msg_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid message ID
  - Message must exist in your organization
  - You must have permission to view this message
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Email Status Types" icon="info">
    Email status options:
    
    - **sent**: Email has been sent but not yet delivered
    - **delivered**: Email has been successfully delivered
    - **opened**: Email has been opened by recipient
    - **clicked**: Email has been clicked by recipient
    - **bounced**: Email delivery failed (bounced back)
    - **failed**: Email sending failed
    - **scheduled**: Email is scheduled for future delivery
  </Accordion>
  
  <Accordion title="Tracking Metrics" icon="chart">
    Available metrics:
    
    - **Delivery Rate**: Percentage of successfully delivered emails
    - **Open Rate**: Percentage of emails that were opened
    - **Click Rate**: Percentage of emails that had clicks
    - **Bounce Rate**: Percentage of emails that bounced
    - **Engagement**: Overall engagement metrics
  </Accordion>
  
  <Accordion title="Recipient Details" icon="users">
    Per-recipient information:
    
    - **Delivery Status**: Individual delivery status for each recipient
    - **Open Tracking**: When and how many times each recipient opened
    - **Click Tracking**: Which links were clicked and when
    - **Bounce Information**: Reason for bounces and failures
  </Accordion>
  
  <Accordion title="Click Tracking" icon="mouse-pointer">
    Click tracking features:
    
    - **URL Tracking**: Track clicks on specific URLs
    - **Click Counts**: Total and unique click counts
    - **Timing**: First and last click timestamps
    - **Engagement**: Detailed click engagement metrics
  </Accordion>
</AccordionGroup>

    ```javascript
    class EmailStatusService {
      constructor(apiClient) {

          }

          console.log(`Email Status: ${result.data.status}`);

          console.log(`Click Rate: ${result.data.engagement_stats.click_rate}%`);
          
          return result;

          console.error('Error getting email status:', error);
          throw error;
        }
      }
      
      async getDeliveryStatus(messageId) {
        const status = await this.getEmailStatus(messageId);
        return status.data.delivery_stats;
      }
      
      async getEngagementStats(messageId) {
        const status = await this.getEmailStatus(messageId);
        return status.data.engagement_stats;
      }
      
      async getRecipientDetails(messageId) {
        const status = await this.getEmailStatus(messageId);
        return status.data.recipient_details;
      }
      
      async getClickDetails(messageId) {
        const status = await this.getEmailStatus(messageId);
        return status.data.click_details;
      }
      
      async isEmailDelivered(messageId) {
        const status = await this.getEmailStatus(messageId);
        return status.data.status === 'delivered';
      }
      
      async getOpenRate(messageId) {
        const stats = await this.getEngagementStats(messageId);
        return stats.open_rate;
      }
      
      async getClickRate(messageId) {
        const stats = await this.getEngagementStats(messageId);
        return stats.click_rate;
      }
      
      async getBounceRate(messageId) {
        const delivery = await this.getDeliveryStatus(messageId);
        return (delivery.bounced / delivery.total_recipients) * 100;
      }
      
      async getMostClickedUrl(messageId) {
        const clicks = await this.getClickDetails(messageId);
        if (clicks.length === 0) return null;
        
        return clicks.reduce((max, click) => 
          click.click_count > max.click_count ? click : max
        );
      }
      
      async getEngagementSummary(messageId) {
        const status = await this.getEmailStatus(messageId);
        const delivery = status.data.delivery_stats;
        const engagement = status.data.engagement_stats;
    ```

    ```python
    import requests
    from typing import Dict, List, Optional
    
    class EmailStatusManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_email_status(self, message_id: str) -> Dict:
            """Get email status and tracking information"""
            try:
                response = self.api_client.get(f'/org/mail/status/{message_id}')
                response.raise_for_status()
                
                result = response.json()
                print(f"Email Status: {result['data']['status']}")
                print(f"Delivery Rate: {result['data']['delivery_stats']['delivered']}/{result['data']['delivery_stats']['total_recipients']}")
                print(f"Open Rate: {result['data']['engagement_stats']['open_rate']}%")
                print(f"Click Rate: {result['data']['engagement_stats']['click_rate']}%")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting email status: {e}")
                raise
        
        def get_delivery_status(self, message_id: str) -> Dict:
            """Get delivery statistics"""
            status = self.get_email_status(message_id)
            return status["data"]["delivery_stats"]
        
        def get_engagement_stats(self, message_id: str) -> Dict:
            """Get engagement statistics"""
            status = self.get_email_status(message_id)
            return status["data"]["engagement_stats"]
        
        def get_recipient_details(self, message_id: str) -> List[Dict]:
            """Get detailed recipient information"""
            status = self.get_email_status(message_id)
            return status["data"]["recipient_details"]
        
        def get_click_details(self, message_id: str) -> List[Dict]:
            """Get click tracking details"""
            status = self.get_email_status(message_id)
            return status["data"]["click_details"]
        
        def is_email_delivered(self, message_id: str) -> bool:
            """Check if email is delivered"""
            status = self.get_email_status(message_id)
            return status["data"]["status"] == "delivered"
        
        def get_open_rate(self, message_id: str) -> float:
            """Get email open rate"""
            stats = self.get_engagement_stats(message_id)
            return stats["open_rate"]
        
        def get_click_rate(self, message_id: str) -> float:
            """Get email click rate"""
            stats = self.get_engagement_stats(message_id)
            return stats["click_rate"]
        
        def get_bounce_rate(self, message_id: str) -> float:
            """Get email bounce rate"""
            delivery = self.get_delivery_status(message_id)
            return (delivery["bounced"] / delivery["total_recipients"]) * 100
        
        def get_most_clicked_url(self, message_id: str) -> Optional[Dict]:
            """Get the most clicked URL"""
            clicks = self.get_click_details(message_id)
            if not clicks:
                return None
            
            return max(clicks, key=lambda x: x["click_count"])
        
        def get_engagement_summary(self, message_id: str) -> Dict:
            """Get comprehensive engagement summary"""
            status = self.get_email_status(message_id)
            delivery = status["data"]["delivery_stats"]
            engagement = status["data"]["engagement_stats"]
            
            return {
                "message_id": message_id,
                "status": status["data"]["status"],
                "delivery_rate": (delivery["delivered"] / delivery["total_recipients"]) * 100,
                "open_rate": engagement["open_rate"],
                "click_rate": engagement["click_rate"],
                "bounce_rate": (delivery["bounced"] / delivery["total_recipients"]) * 100,
                "total_recipients": delivery["total_recipients"],
                "delivered": delivery["delivered"],
                "opened": engagement["unique_opens"],
                "clicked": engagement["unique_clicks"]
            }
        
        def get_failed_recipients(self, message_id: str) -> List[Dict]:
            """Get list of failed recipients"""
            recipients = self.get_recipient_details(message_id)
            return [r for r in recipients if r["status"] in ["bounced", "failed"]]
        
        def get_engaged_recipients(self, message_id: str) -> List[Dict]:
            """Get list of engaged recipients (opened or clicked)"""
            recipients = self.get_recipient_details(message_id)
            return [r for r in recipients if r["opened_count"] > 0 or r["clicked_count"] > 0]
        
        def get_click_through_recipients(self, message_id: str) -> List[Dict]:
            """Get list of recipients who clicked links"""
            recipients = self.get_recipient_details(message_id)
            return [r for r in recipients if r["clicked_count"] > 0]
        
        def get_email_performance_score(self, message_id: str) -> float:
            """Calculate overall email performance score"""
            summary = self.get_engagement_summary(message_id)
            
            # Weighted score based on delivery, open, and click rates
            delivery_weight = 0.3
            open_weight = 0.4
            click_weight = 0.3
            
            score = (
                summary["delivery_rate"] * delivery_weight +
                summary["open_rate"] * open_weight +
                summary["click_rate"] * click_weight
            )
            
            return round(score, 2)
        
        def get_email_timeline(self, message_id: str) -> List[Dict]:
            """Get chronological timeline of email events"""
            status = self.get_email_status(message_id)
            timeline = []
            
            # Add creation event
            timeline.append({
                "event": "created",
                "timestamp": status["data"]["created_at"],
                "description": "Email created"
            })
            
            # Add sent event
            if status["data"]["sent_at"]:
                timeline.append({
                    "event": "sent",
                    "timestamp": status["data"]["sent_at"],
                    "description": "Email sent"
                })
            
            # Add delivery event
            if status["data"]["delivered_at"]:
                timeline.append({
                    "event": "delivered",
                    "timestamp": status["data"]["delivered_at"],
                    "description": "Email delivered"
                })
            
            # Add recipient events
            for recipient in status["data"]["recipient_details"]:
                if recipient["opened_at"]:
                    timeline.append({
                        "event": "opened",
                        "timestamp": recipient["opened_at"],
                        "description": f"Opened by {recipient['email']}"
                    })
                
                if recipient["clicked_at"]:
                    timeline.append({
                        "event": "clicked",
                        "timestamp": recipient["clicked_at"],
                        "description": f"Clicked by {recipient['email']}"
                    })
            
            # Sort by timestamp
            timeline.sort(key=lambda x: x["timestamp"])
            return timeline
    ```
