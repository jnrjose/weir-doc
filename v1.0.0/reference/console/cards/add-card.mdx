---
title: "Add Card"
api: "POST /org/cards/add"
description: "Add a new payment card to the organization"
---

Add a new payment card to your organization for processing payments and managing billing. This endpoint allows you to securely add cards with different types and configurations.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for secure card management and payment processing within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="card_number" type="string" required>
  The card number to add
  
  **Example**: "4242424242424242"
  
  **Constraints**: 
  - Must be a valid card number
  - Length varies by card type (13-19 digits)
  - Must pass Luhn algorithm validation
  - Will be tokenized for security
</ParamField>

<ParamField body="exp_month" type="integer" required>
  Expiration month of the card
  
  **Example**: 12
  
  **Constraints**: 
  - Must be between 1 and 12
  - Represents the month (1 = January, 12 = December)
</ParamField>

<ParamField body="exp_year" type="integer" required>
  Expiration year of the card
  
  **Example**: 2025
  
  **Constraints**: 
  - Must be a 4-digit year
  - Must be in the future
  - Cannot be more than 10 years in the future
</ParamField>

<ParamField body="cvc" type="string" required>
  Card verification code (CVC/CVV)
  
  **Example**: "123"
  
  **Constraints**: 
  - Must be 3-4 digits
  - 3 digits for Visa, Mastercard, Discover
  - 4 digits for American Express
  - Will be used for verification only
</ParamField>

<ParamField body="name" type="string" required="false">
  Name for the card (for identification purposes)
  
  **Example**: "Corporate Credit Card"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Optional but recommended for organization
  - Cannot contain special characters except spaces, hyphens, and underscores
</ParamField>

<ParamField body="teamId" type="string" required="false">
  ID of the team to associate with this card
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID within your organization
  - Team must exist and be accessible
  - If not provided, card will be associated with the user's default team
</ParamField>

<ParamField body="is_default" type="boolean" required="false">
  Whether this should be the default card for the organization
  
  **Example**: true
  
  **Default**: false
  
  **Note**: If set to true, this card will become the default payment method
</ParamField>

<ParamField body="cardholder_name" type="string" required="false">
  Name of the cardholder
  
  **Example**: "John Smith"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Optional but recommended for verification
  - Should match the name on the card
</ParamField>

<ParamField body="billing_address" type="object" required="false">
  Billing address for the card
  
  **Properties**:
  - `line1` (string): First line of address
  - `line2` (string): Second line of address (optional)
  - `city` (string): City
  - `state` (string): State or province
  - `postal_code` (string): Postal or ZIP code
  - `country` (string): Country code (ISO 3166-1 alpha-2)
  
  **Example**:
  ```json
  {
    "line1": "123 Main Street",
    "line2": "Suite 100",
    "city": "San Francisco",
    "state": "CA",
    "postal_code": "94105",
    "country": "US"
  }
  ```
</ParamField>

<ParamField body="metadata" type="object" required="false">
  Additional metadata for the card
  
  **Example**:
  ```json
  {
    "department": "Engineering",
    "purpose": "Development expenses",
    "approval_required": true,
    "spending_limit": 5000
  }
  ```
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Card Security" icon="shield">
    Security features:
    
    - **PCI Compliance**: All card data is handled according to PCI DSS standards
    - **Tokenization**: Card numbers are tokenized and never stored in plain text
    - **Encryption**: All card data is encrypted in transit and at rest
    - **CVC Verification**: CVC codes are verified but not stored
  </Accordion>
  
  <Accordion title="Card Verification" icon="check">
    Verification process:
    
    - **CVC Verification**: Card verification code is validated
    - **Address Verification**: Billing address is verified (if provided)
    - **Card Number Validation**: Luhn algorithm validation
    - **Expiry Validation**: Expiration date is checked
  </Accordion>
  
  <Accordion title="Supported Card Types" icon="credit-card">
    Supported cards:
    
    - **Visa**: All Visa cards
    - **Mastercard**: All Mastercard cards
    - **American Express**: All Amex cards

    - **Other**: Other card brands
  </Accordion>
  
  <Accordion title="Required Permissions" icon="users">

        const errors = [];
        
        // Validate card number
        if (!cardData.card_number || !this.isValidCardNumber(cardData.card_number)) {
          errors.push('Invalid card number');
        }
        
        // Validate expiration
        if (!cardData.exp_month || cardData.exp_month < 1 || cardData.exp_month > 12) {
          errors.push('Invalid expiration month');
        }
        
        if (!cardData.exp_year || cardData.exp_year < new Date().getFullYear()) {
          errors.push('Invalid expiration year');
        }
        
        // Validate CVC
        if (!cardData.cvc || !/^\d{3,4}$/.test(cardData.cvc)) {
          errors.push('Invalid CVC');

      isValidCardNumber(cardNumber) {
        // Remove spaces and dashes
        const cleaned = cardNumber.replace(/[\s-]/g, '');
        
        // Check if it's all digits
        if (!/^\d+$/.test(cleaned)) {
          return false;
        }
        
        // Check length
        if (cleaned.length < 13 || cleaned.length > 19) {
          return false;
        }
        
        // Luhn algorithm validation
        let sum = 0;
        let isEven = false;
        
        for (let i = cleaned.length - 1; i >= 0; i--) {
          let digit = parseInt(cleaned[i]);
          
          if (isEven) {
            digit *= 2;
            if (digit > 9) {
              digit -= 9;
            }
          }
          
          sum += digit;
          isEven = !isEven;
        }
        
        return sum % 10 === 0;
      }

        def validate_card_data(self, card_data: Dict) -> List[str]:
            """Validate card data before submission"""
            errors = []
            
            # Validate card number
            if not card_data.get('card_number') or not self.is_valid_card_number(card_data['card_number']):
                errors.append('Invalid card number')
            
            # Validate expiration month
            exp_month = card_data.get('exp_month')
            if not exp_month or exp_month < 1 or exp_month > 12:
                errors.append('Invalid expiration month')
            
            # Validate expiration year
            exp_year = card_data.get('exp_year')
            if not exp_year or exp_year < 2024:  # Assuming current year is 2024
                errors.append('Invalid expiration year')
            
            # Validate CVC
            cvc = card_data.get('cvc')
            if not cvc or not re.match(r'^\d{3,4}$', cvc):
                errors.append('Invalid CVC')
            
            return errors
        
        def is_valid_card_number(self, card_number: str) -> bool:
            """Validate card number using Luhn algorithm"""
            # Remove spaces and dashes
            cleaned = re.sub(r'[\s-]', '', card_number)
            
            # Check if it's all digits
            if not re.match(r'^\d+$', cleaned):
                return False
            
            # Check length
            if len(cleaned) < 13 or len(cleaned) > 19:
                return False
            
            # Luhn algorithm validation
            total = 0
            is_even = False
            
            for digit in reversed(cleaned):
                digit = int(digit)
                
                if is_even:
                    digit *= 2
                    if digit > 9:
                        digit -= 9
                
                total += digit
                is_even = not is_even
            
            return total % 10 == 0
        
        def get_card_brand(self, card_number: str) -> str:
            """Determine card brand from card number"""
            cleaned = re.sub(r'[\s-]', '', card_number)
            
            if re.match(r'^4', cleaned):
                return 'visa'
            elif re.match(r'^5[1-5]', cleaned):
                return 'mastercard'
            elif re.match(r'^3[47]', cleaned):
                return 'amex'
            elif re.match(r'^6(?:011|5)', cleaned):
                return 'discover'
            else:
                return 'other'
