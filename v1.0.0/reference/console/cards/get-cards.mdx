---
title: "Get Cards"
api: "GET /org/cards"
description: "Retrieve list of cards in the organization"
---

Retrieve a comprehensive list of all cards within your organization, including their details, configurations, and status. This endpoint provides detailed information about card management and payment processing.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for card management and payment oversight within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of cards to return per page
  
  **Example**: "20"
  
  **Default**: "20"
  
  **Constraints**: 
  - Must be between 1 and 100
  - Recommended: 20-50 for optimal performance
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter cards by status
  
  **Options**: "active", "inactive", "expired", "suspended", "pending"
  
  **Example**: "active"
  
  **Default**: "active"
  
  **Note**: If not specified, returns only active cards
</ParamField>

<ParamField query="type" type="string" required="false">
  Filter cards by type
  
  **Options**: "credit", "debit", "prepaid", "virtual", "corporate"
  
  **Example**: "credit"
  
  **Note**: If not specified, returns all card types
</ParamField>

<ParamField query="brand" type="string" required="false">
  Filter cards by brand
  
  **Options**: "visa", "mastercard", "amex", "discover", "other"
  
  **Example**: "visa"
  
  **Note**: If not specified, returns all card brands
</ParamField>

<ParamField query="teamId" type="string" required="false">
  Filter cards by team ID
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
  - You must have access to the team
</ParamField>

<ParamField query="search" type="string" required="false">
  Search cards by last four digits or cardholder name
  
  **Example**: "1234"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches last four digits and cardholder name
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort cards by specified field
  
  **Options**: "name", "type", "brand", "status", "created_at", "updated_at", "expires_at"
  
  **Example**: "expires_at"
  
  **Default**: "created_at"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "desc"
</ParamField>

<ParamField query="expires_soon" type="string" required="false">
  Filter cards that expire within specified days
  
  **Example**: "30"
  
  **Constraints**: 
  - Must be a positive integer
  - Returns cards expiring within the specified number of days
</ParamField>

<ParamField query="is_default" type="string" required="false">
  Filter cards by default status
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Note**: If not specified, returns cards regardless of default status
</ParamField>

    Card status options:
    
    - **active**: Card is active and can be used
    - **inactive**: Card is disabled and cannot be used
    - **expired**: Card has expired and cannot be used
    - **suspended**: Card access is temporarily suspended
    - **pending**: Card is being processed or verified
  </Accordion>

    - **PCI Compliance**: All card data is handled according to PCI DSS standards

    - **Access Control**: Card access is restricted based on user permissions

        def get_card_statistics(self) -> Dict:
            """Get card statistics"""

            stats = {
                "total_cards": len(all_cards),
                "active_cards": len([c for c in all_cards if c["status"] == "active"]),
                "inactive_cards": len([c for c in all_cards if c["status"] == "inactive"]),
                "expired_cards": len([c for c in all_cards if c["status"] == "expired"]),
                "suspended_cards": len([c for c in all_cards if c["status"] == "suspended"]),
                "pending_cards": len([c for c in all_cards if c["status"] == "pending"]),
                "default_cards": len([c for c in all_cards if c["is_default"]]),
                "cards_by_type": {},
                "cards_by_brand": {},
                "cards_by_team": {}
            }
            
            # Count by type
            for card in all_cards:
                card_type = card["type"]
                if card_type not in stats["cards_by_type"]:
                    stats["cards_by_type"][card_type] = 0
                stats["cards_by_type"][card_type] += 1
            
            # Count by brand
            for card in all_cards:
                brand = card["brand"]
                if brand not in stats["cards_by_brand"]:
                    stats["cards_by_brand"][brand] = 0
                stats["cards_by_brand"][brand] += 1
            
            # Count by team
            for card in all_cards:
                team_name = card.get("team_name", "Unknown")
                if team_name not in stats["cards_by_team"]:
                    stats["cards_by_team"][team_name] = 0
                stats["cards_by_team"][team_name] += 1
            
            return stats
        
        def get_card_by_last_four(self, last_four: str) -> Optional[Dict]:
            """Find a specific card by last four digits"""
