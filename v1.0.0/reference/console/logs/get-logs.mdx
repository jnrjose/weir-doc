---
title: "Get Logs"
api: "GET /org/logs"
description: "Retrieve system logs and audit trail for the organization"
---

Retrieve comprehensive system logs, audit trails, and activity records for your organization. This endpoint provides detailed logging information for monitoring, debugging, and compliance purposes.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for log management and system monitoring within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of logs to return per page
  
  **Example**: "50"
  
  **Default**: "50"
  
  **Constraints**: 
  - Must be between 1 and 1000
  - Recommended: 50-100 for optimal performance
</ParamField>

<ParamField query="level" type="string" required="false">
  Filter logs by severity level
  
  **Options**: "debug", "info", "warn", "error", "fatal"
  
  **Example**: "error"
  
  **Default**: "info"
  
  **Note**: If not specified, returns logs of all levels
</ParamField>

<ParamField query="category" type="string" required="false">
  Filter logs by category
  
  **Options**: "auth", "api", "system", "security", "audit", "performance", "database", "email", "payment", "user"
  
  **Example**: "security"
  
  **Note**: If not specified, returns logs from all categories
</ParamField>

<ParamField query="source" type="string" required="false">
  Filter logs by source component
  
  **Example**: "api-gateway"
  
  **Constraints**: 
  - Must be a valid source identifier
  - Common sources: api-gateway, auth-service, user-service, payment-service
</ParamField>

<ParamField query="user_id" type="string" required="false">
  Filter logs by user ID
  
  **Example**: "user_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid user ID
  - User must exist in your organization
</ParamField>

<ParamField query="team_id" type="string" required="false">
  Filter logs by team ID
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
</ParamField>

<ParamField query="action" type="string" required="false">
  Filter logs by action performed
  
  **Example**: "login"
  
  **Common Actions**: login, logout, create, update, delete, view, export, import, send, receive
</ParamField>

<ParamField query="resource" type="string" required="false">
  Filter logs by resource type
  
  **Example**: "user"
  
  **Common Resources**: user, team, organization, platform, client, talent, pax, card, email, log
</ParamField>

<ParamField query="start_date" type="string" required="false">
  Start date for log filtering (ISO 8601 format)
  
  **Example**: "2024-01-01T00:00:00Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be more than 90 days in the past
  - If not provided, defaults to 7 days ago
</ParamField>

<ParamField query="end_date" type="string" required="false">
  End date for log filtering (ISO 8601 format)
  
  **Example**: "2024-01-15T23:59:59Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be in the future
  - If not provided, defaults to current time
</ParamField>

<ParamField query="search" type="string" required="false">
  Search logs by message content
  
  **Example**: "authentication failed"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches log messages and metadata
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort logs by specified field
  
  **Options**: "timestamp", "level", "category", "source", "user_id", "action", "resource"
  
  **Example**: "timestamp"
  
  **Default**: "timestamp"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "desc"
</ParamField>

<ParamField query="include_metadata" type="string" required="false">
  Whether to include detailed metadata in response
  
  **Options**: "true", "false"
  
  **Example**: "true"
  
  **Default**: "false"
  
  **Note**: Setting to true will include additional context and metadata
</ParamField>

<ParamField query="format" type="string" required="false">
  Response format for logs
  
  **Options**: "json", "csv", "text"
  
  **Example**: "json"
  
  **Default**: "json"
  
  **Note**: CSV and text formats are useful for export and analysis
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Log Levels" icon="info">
    Log severity levels:
    
    - **debug**: Detailed information for debugging
    - **info**: General information about system operation
    - **warn**: Warning messages for potential issues
    - **error**: Error messages for failed operations
    - **fatal**: Critical errors that may cause system failure
  </Accordion>
  
  <Accordion title="Log Categories" icon="folder">
    Available categories:
    
    - **auth**: Authentication and authorization events
    - **api**: API requests and responses
    - **system**: System-level events and operations
    - **security**: Security-related events and alerts
    - **audit**: Audit trail and compliance events
    - **performance**: Performance metrics and monitoring
    - **database**: Database operations and queries
    - **email**: Email sending and delivery events
    - **payment**: Payment processing events
    - **user**: User-related activities and changes
  </Accordion>
  
  <Accordion title="Retention Policy" icon="clock">
    Log retention:
    
    - **Debug/Info**: 30 days
    - **Warn/Error**: 90 days
    - **Fatal**: 1 year
    - **Security/Audit**: 2 years
    - **Compliance**: 7 years (if applicable)
  </Accordion>
  
  <Accordion title="Export Formats" icon="download">

    - **JSON**: Structured data for programmatic access
    - **CSV**: Tabular format for spreadsheet analysis
    - **Text**: Plain text format for log analysis tools
    - **Syslog**: Standard syslog format for SIEM integration
  </Accordion>

      constructor(apiClient) {
        this.apiClient = apiClient;

      async getLogs(options = {}) {
        try {
          const params = new URLSearchParams();
          
          // Add query parameters
          if (options.page) params.append('page', options.page);
          if (options.limit) params.append('limit', options.limit);
          if (options.level) params.append('level', options.level);
          if (options.category) params.append('category', options.category);
          if (options.source) params.append('source', options.source);
          if (options.userId) params.append('user_id', options.userId);
          if (options.teamId) params.append('team_id', options.teamId);
          if (options.action) params.append('action', options.action);
          if (options.resource) params.append('resource', options.resource);
          if (options.startDate) params.append('start_date', options.startDate);
          if (options.endDate) params.append('end_date', options.endDate);
          if (options.search) params.append('search', options.search);
          if (options.sortBy) params.append('sort_by', options.sortBy);
          if (options.sortOrder) params.append('sort_order', options.sortOrder);
          if (options.includeMetadata) params.append('include_metadata', options.includeMetadata);
          if (options.format) params.append('format', options.format);
          
          const response = await this.apiClient.makeRequest(
            `/org/logs?${params.toString()}`
          );
          
          if (!response.ok) {
            throw new Error('Failed to get logs');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error getting logs:', error);
          throw error;
        }
      }
      
      async getErrorLogs(days = 7) {
        const endDate = new Date();
        const startDate = new Date(endDate.getTime() - (days * 24 * 60 * 60 * 1000));
        
        return this.getLogs({
          level: 'error',
          startDate: startDate.toISOString(),
          endDate: endDate.toISOString(),
          sortBy: 'timestamp',
          sortOrder: 'desc'
        });
      }
      
      async getSecurityLogs(days = 7) {
        const endDate = new Date();
        const startDate = new Date(endDate.getTime() - (days * 24 * 60 * 60 * 1000));

          sortBy: 'timestamp',
          sortOrder: 'desc',
          includeMetadata: true
        });
      }

        const endDate = new Date();

        def get_logs(self, 
                    page: int = 1,
                    limit: int = 50,
                    level: Optional[str] = None,
                    category: Optional[str] = None,
                    source: Optional[str] = None,
                    user_id: Optional[str] = None,
                    team_id: Optional[str] = None,
                    action: Optional[str] = None,
                    resource: Optional[str] = None,
                    start_date: Optional[str] = None,

                    search: Optional[str] = None,
                    sort_by: str = "timestamp",
                    sort_order: str = "desc",
                    include_metadata: bool = False,
                    format: str = "json") -> Dict:
            """Get logs with optional filtering and pagination"""
            try:
                params = {
                    "page": page,
                    "limit": limit,
                    "sort_by": sort_by,
                    "sort_order": sort_order,
                    "include_metadata": str(include_metadata).lower(),
                    "format": format
                }
                
                if level:
                    params["level"] = level
                if category:
                    params["category"] = category
                if source:
                    params["source"] = source
                if user_id:
                    params["user_id"] = user_id
                if team_id:
                    params["team_id"] = team_id
                if action:
                    params["action"] = action
                if resource:
                    params["resource"] = resource
                if start_date:
                    params["start_date"] = start_date
                if end_date:
                    params["end_date"] = end_date
                if search:
                    params["search"] = search
                
                response = self.api_client.get('/org/logs', params=params)
                response.raise_for_status()
                
                return response.json()
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting logs: {e}")
                raise

            trends = {
