---
title: "Export Logs"
api: "POST /org/logs/export"
description: "Export logs in various formats for analysis and compliance"
---

Export system logs in multiple formats for analysis, compliance, and archival purposes. This endpoint supports various export formats and filtering options to meet different use cases.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for log export and compliance reporting within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="format" type="string" required>
  Export format for the logs
  
  **Options**: "json", "csv", "txt", "syslog", "xlsx"
  
  **Example**: "csv"
  
  **Constraints**: 
  - Must be one of the supported formats
  - Each format has different field limitations
</ParamField>

<ParamField body="start_date" type="string" required>
  Start date for log export (ISO 8601 format)
  
  **Example**: "2024-01-01T00:00:00Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be more than 90 days in the past
  - Required for all exports
</ParamField>

<ParamField body="end_date" type="string" required>
  End date for log export (ISO 8601 format)
  
  **Example**: "2024-01-15T23:59:59Z"
  
  **Constraints**: 
  - Must be in ISO 8601 format
  - Cannot be in the future
  - Required for all exports
</ParamField>

<ParamField body="level" type="string" required="false">
  Filter logs by severity level
  
  **Options**: "debug", "info", "warn", "error", "fatal"
  
  **Example**: "error"
  
  **Note**: If not specified, exports logs of all levels
</ParamField>

<ParamField body="category" type="string" required="false">
  Filter logs by category
  
  **Options**: "auth", "api", "system", "security", "audit", "performance", "database", "email", "payment", "user"
  
  **Example**: "security"
  
  **Note**: If not specified, exports logs from all categories
</ParamField>

<ParamField body="source" type="string" required="false">
  Filter logs by source component
  
  **Example**: "api-gateway"
  
  **Constraints**: 
  - Must be a valid source identifier
  - Common sources: api-gateway, auth-service, user-service, payment-service
</ParamField>

<ParamField body="user_id" type="string" required="false">
  Filter logs by user ID
  
  **Example**: "user_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid user ID
  - User must exist in your organization
</ParamField>

<ParamField body="team_id" type="string" required="false">
  Filter logs by team ID
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
</ParamField>

<ParamField body="action" type="string" required="false">
  Filter logs by action performed
  
  **Example**: "login"
  
  **Common Actions**: login, logout, create, update, delete, view, export, import, send, receive
</ParamField>

<ParamField body="resource" type="string" required="false">
  Filter logs by resource type
  
  **Example**: "user"
  
  **Common Resources**: user, team, organization, platform, client, talent, pax, card, email, log
</ParamField>

<ParamField body="search" type="string" required="false">
  Search logs by message content
  
  **Example**: "authentication failed"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches log messages and metadata
</ParamField>

<ParamField body="include_metadata" type="boolean" required="false">
  Whether to include detailed metadata in export
  
  **Example**: true
  
  **Default**: false
  
  **Note**: Setting to true will include additional context and metadata
</ParamField>

<ParamField body="max_records" type="integer" required="false">
  Maximum number of records to export
  
  **Example**: 10000
  
  **Default**: 50000
  
  **Constraints**: 
  - Must be between 1 and 100000
  - Large exports may take longer to process
</ParamField>

<ParamField body="compression" type="string" required="false">
  Compression format for the export file
  
  **Options**: "none", "gzip", "zip"
  
  **Example**: "gzip"
  
  **Default**: "none"
  
  **Note**: Compression reduces file size but increases processing time
</ParamField>

<ParamField body="fields" type="array" required="false">
  Specific fields to include in the export
  
  **Example**: ["timestamp", "level", "message", "user_id", "action"]
  
  **Note**: If not specified, includes all available fields
</ParamField>

<ParamField body="sort_by" type="string" required="false">
  Sort logs by specified field
  
  **Options**: "timestamp", "level", "category", "source", "user_id", "action", "resource"
  
  **Example**: "timestamp"
  
  **Default**: "timestamp"
</ParamField>

<ParamField body="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "desc"
</ParamField>

<ParamField body="export_name" type="string" required="false">
  Custom name for the export file
  
  **Example**: "security_audit_2024_01"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Cannot contain special characters except hyphens and underscores
  - If not provided, auto-generated based on filters and date range
</ParamField>

<ParamField body="notify_on_completion" type="boolean" required="false">
  Whether to send notification when export is complete
  
  **Example**: true
  
  **Default**: false
  
  **Note**: Notifications are sent to the requesting user's email
</ParamField>

    class LogExporter:
