---
title: "Create Platform"
api: "POST /org/create/platform"
description: "Create a new platform within the organization"
---

Create a new platform within your organization for managing specific services, applications, or integrations. This endpoint allows you to set up platforms with different types and configurations.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for platform management and service configuration within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  Name of the platform to create
  
  **Example**: "Production API"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must be unique within the organization
  - Cannot contain special characters except spaces, hyphens, and underscores
</ParamField>

<ParamField body="teamId" type="string" required="false">
  ID of the team to associate with this platform
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID within your organization
  - Team must exist and be accessible
  - If not provided, platform will be associated with the user's default team
</ParamField>

<ParamField body="description" type="string" required="false">
  Description of the platform's purpose and functionality
  
  **Example**: "Main production API for handling customer requests"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional but recommended for documentation
</ParamField>

<ParamField body="type" type="string" required>
  Type of platform being created
  
  **Options**: 
  - `Forum/Community`: Community forum or discussion platform
  - `Social Media`: Social media platform or network
  - `E-commerce`: Online shopping or marketplace platform
  - `Content Management`: CMS or content publishing platform
  - `API Service`: RESTful API or web service platform
  - `Mobile App`: Mobile application platform
  - `Web Application`: Web-based application platform
  - `Other`: Any other type of platform
  
  **Example**: "API Service"
</ParamField>

<ParamField body="domain" type="string" required="false">
  Primary domain or URL for the platform
  
  **Example**: "api.example.com"
  
  **Constraints**: 
  - Must be a valid domain format
  - Optional but recommended for web-based platforms
  - Will be used for platform identification and routing
</ParamField>

<ParamField body="settings" type="object" required="false">
  Platform-specific settings and configurations
  
  **Properties**:
  - `environment` (string): Environment type (development, staging, production)
  - `region` (string): Geographic region for deployment
  - `scaling` (object): Auto-scaling configuration
  - `monitoring` (object): Monitoring and alerting settings
  - `security` (object): Security and access control settings
  
  **Example**:
  ```json
  {
    "environment": "production",
    "region": "us-east-1",
    "scaling": {
      "min_instances": 2,
      "max_instances": 10,
      "auto_scale": true
    },
    "monitoring": {
      "enabled": true,
      "alerts": true,
      "metrics": ["cpu", "memory", "response_time"]
    },
    "security": {
      "ssl_enabled": true,
      "rate_limiting": true,
      "authentication_required": true
    }
  }
  ```
</ParamField>

<ParamField body="tags" type="array" required="false">
  Tags for categorizing and organizing the platform
  
  **Example**: ["production", "api", "customer-facing"]
  
  **Constraints**: 
  - Maximum 10 tags per platform
  - Each tag maximum 50 characters
  - Tags are case-insensitive
</ParamField>

        def validate_platform_data(self, platform_data: Dict) -> bool:
            """Validate platform data before creation"""

            for field in required_fields:
                if field not in platform_data:
                    print(f"Missing required field: {field}")
                    return False
            
            # Validate platform type
            valid_types = [
                'Forum/Community', 'Social Media', 'E-commerce',

            if platform_data['type'] not in valid_types:

                return False

            if len(platform_data['name']) < 2 or len(platform_data['name']) > 100:

                return False
