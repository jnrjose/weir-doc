---
title: "Verify Platform"
api: "GET /org/verify/platform/{platformId}"
description: "Verify platform configuration and accessibility"
---

Verify a platform's configuration, accessibility, and compliance with platform requirements. This endpoint performs comprehensive checks to ensure the platform is properly configured and functioning correctly.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for platform verification and compliance checking within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="platformId" type="string" required>
  Unique identifier of the platform to verify
  
  **Example**: "platform_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid platform ID
  - Platform must exist in your organization
  - You must have permission to verify this platform
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Verification Checks" icon="check">
    What gets verified:
    
    - **Domain Verification**: Domain accessibility and response time
    - **SSL Verification**: SSL certificate validity and configuration
    - **API Verification**: API endpoint accessibility and response codes
    - **Compliance Verification**: GDPR compliance and security headers
    - **Performance Verification**: Load time, uptime, and error rates
  </Accordion>
  
  <Accordion title="Verification Status" icon="info">
    Status options:
    
    - **verified**: All checks passed successfully
    - **failed**: One or more critical checks failed
    - **pending**: Verification is in progress
    - **partial**: Some checks passed, others failed or are pending
  </Accordion>
  
  <Accordion title="Issue Severity" icon="exclamation-triangle">
    Issue severity levels:
    
    - **critical**: Issues that prevent platform functionality
    - **high**: Issues that significantly impact platform performance
    - **medium**: Issues that may affect user experience
    - **low**: Minor issues or warnings
  </Accordion>
  
  <Accordion title="Verification Score" icon="star">
    Scoring system:
    
    - **90-100**: Excellent platform configuration
    - **80-89**: Good platform configuration with minor issues
    - **70-79**: Acceptable platform configuration with some issues
    - **60-69**: Poor platform configuration with significant issues
    - **Below 60**: Critical issues that need immediate attention
  </Accordion>
</AccordionGroup>

    import requests
    from typing import Dict, List, Optional
    
    class PlatformVerificationManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def verify_platform(self, platform_id: str) -> Dict:
            """Verify platform configuration and accessibility"""
            try:
                response = self.api_client.get(f'/org/verify/platform/{platform_id}')
                response.raise_for_status()
                
                result = response.json()
                print(f"Platform verification completed: {result['data']['verification_status']}")
                print(f"Overall score: {result['data']['verification_summary']['overall_score']}")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error verifying platform: {e}")
                raise
        
        def get_verification_status(self, platform_id: str) -> str:
            """Get platform verification status"""
            result = self.verify_platform(platform_id)
            return result["data"]["verification_status"]
        
        def get_verification_score(self, platform_id: str) -> float:
            """Get platform verification score"""
            result = self.verify_platform(platform_id)
            return result["data"]["verification_summary"]["overall_score"]
        
        def get_verification_issues(self, platform_id: str) -> List[Dict]:
