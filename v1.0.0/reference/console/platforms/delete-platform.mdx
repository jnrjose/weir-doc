---
title: "Delete Platform"
api: "DELETE /org/platform/{platformId}"
description: "Delete a platform from the organization"
---

Permanently delete a platform and all its associated data from your organization. This action cannot be undone and will remove all platform configurations, settings, and associated resources.

<Warning>
  **Destructive Action**
  
  This operation permanently deletes the platform and all associated data. This action cannot be undone. Make sure you have backed up any important data before proceeding.
</Warning>

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for platform management and cleanup within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="platformId" type="string" required>
  Unique identifier of the platform to delete
  
  **Example**: "platform_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid platform ID
  - Platform must exist in your organization
  - You must have permission to delete this platform
</ParamField>

## Request

<ParamField body="confirmation" type="string" required>
  Confirmation text to verify the deletion intent
  
  **Example**: "DELETE_PLATFORM"
  
  **Constraints**: 
  - Must be exactly "DELETE_PLATFORM" (case-sensitive)
  - This is a safety measure to prevent accidental deletions
</ParamField>

<ParamField body="reason" type="string" required="false">
  Reason for deleting the platform
  
  **Example**: "Platform is no longer needed after migration"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional but recommended for audit purposes
</ParamField>

<ParamField body="backup_data" type="boolean" required="false">
  Whether to create a backup before deletion
  
  **Example**: true
  
  **Default**: false
  
  **Note**: If true, a backup will be created before deletion
</ParamField>

<ParamField body="transfer_resources" type="object" required="false">
  Configuration for transferring platform resources to another platform
  
  **Properties**:
  - `target_platform_id` (string): ID of the platform to transfer resources to
  - `transfer_domain` (boolean): Whether to transfer domain configuration
  - `transfer_settings` (boolean): Whether to transfer platform settings
  - `transfer_data` (boolean): Whether to transfer platform data
  
  **Example**:
  ```json
  {
    "target_platform_id": "platform_0987654321fedcba",
    "transfer_domain": true,
    "transfer_settings": true,
    "transfer_data": false
  }
  ```
</ParamField>

<ParamField body="notify_team" type="boolean" required="false">
  Whether to notify team members about the platform deletion
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, all team members will receive a notification
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Deletion Process" icon="trash">
    What happens when a platform is deleted:
    
    - **Platform Removal**: Platform is permanently removed from the organization
    - **Resource Cleanup**: Platform resources and configurations are deleted
    - **Data Backup**: Optional backup is created before deletion
    - **Resource Transfer**: Resources can be transferred to another platform
    - **Team Notification**: Team members are notified of the deletion
    - **Audit Log**: Deletion is logged for audit purposes
  </Accordion>
  
  <Accordion title="Resource Transfer" icon="exchange">
    Resource transfer options:
    
    - **Domain**: Transfer domain configuration to another platform
    - **Settings**: Transfer platform settings and configurations
    - **Data**: Transfer platform data and files
    - **Integrations**: Transfer active integrations
  </Accordion>
  
  <Accordion title="Required Permissions" icon="shield">
    Permissions needed to delete platforms:
    
    - **Organization Admin**: Can delete any platform in the organization
    - **Platform Owner**: Can delete platforms they own
    - **Team Admin**: Can delete platforms in their teams (with restrictions)
  </Accordion>
  
  <Accordion title="Safety Measures" icon="lock">
    Safety features:
    
    - **Confirmation Required**: Must provide "DELETE_PLATFORM" confirmation
    - **Dependency Check**: System checks for active dependencies
    - **Backup Option**: Optional backup before deletion
    - **Transfer Options**: Resources can be transferred instead of deleted
    - **Audit Trail**: All deletions are logged and tracked
  </Accordion>
</AccordionGroup>

                          reason: str = "Platform deletion requested",
                          backup_data: bool = False,
                          transfer_resources: Optional[Dict] = None,
                          notify_team: bool = True) -> Dict:
            """Delete a platform with optional resource transfer"""
            try:
                payload = {
                    "confirmation": "DELETE_PLATFORM",
                    "reason": reason,
                    "backup_data": backup_data,
                    "notify_team": notify_team
                }
                
                if transfer_resources:
                    payload["transfer_resources"] = transfer_resources
                
                response = self.api_client.delete(f'/org/platform/{platform_id}', json=payload)
                response.raise_for_status()
                
                result = response.json()
