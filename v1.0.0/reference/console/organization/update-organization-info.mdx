---
title: "Update Organization Information"
api: "PATCH /org/information"
description: "Update organization details and settings"
---

Update your organization's information, including basic details, contact information, address, and configuration settings. This endpoint allows you to modify various aspects of your organization profile.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for organization management and profile updates within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="basicInfo" type="object" required="false">
  Basic organization information
  
  **Properties**:
  - `website` (string): Organization's website URL
  - `industry` (string): Industry category (TECHNOLOGY, HEALTHCARE, FINANCE, EDUCATION, OTHER)
  - `companySize` (string): Company size (SMALL, MEDIUM, LARGE, ENTERPRISE)
  - `founded` (string): Year the organization was founded
  - `description` (string): Description of the organization
  
  **Example**:
  ```json
  {
    "website": "https://www.acmecorp.com",
    "industry": "TECHNOLOGY",
    "companySize": "MEDIUM",
    "founded": "2010",
    "description": "A leading technology company specializing in innovative software solutions"
  }
  ```
</ParamField>

<ParamField body="address" type="object" required="false">
  Organization's physical address
  
  **Properties**:
  - `address1` (string): Primary address line
  - `address2` (string): Secondary address line (optional)
  - `city` (string): City name
  - `state` (string): State or province
  - `postalCode` (string): Postal or ZIP code
  - `country` (string): Country name
  
  **Example**:
  ```json
  {
    "address1": "123 Technology Drive",
    "address2": "Suite 100",
    "city": "San Francisco",
    "state": "California",
    "postalCode": "94105",
    "country": "United States"
  }
  ```
</ParamField>

<ParamField body="contact" type="object" required="false">
  Organization's contact information
  
  **Properties**:
  - `phone` (string): Primary phone number
  - `email` (string): Primary contact email address
  
  **Example**:
  ```json
  {
    "phone": "+1-555-123-4567",
    "email": "contact@acmecorp.com"
  }
  ```
</ParamField>

<ParamField body="settings" type="object" required="false">
  Organization settings and preferences
  
  **Properties**:
  - `timezone` (string): Organization's timezone
  - `currency` (string): Default currency for billing
  - `language` (string): Default language for the organization
  - `notifications` (object): Notification preferences
  
  **Example**:
  ```json
  {
    "timezone": "America/Los_Angeles",
    "currency": "USD",
    "language": "en",
    "notifications": {
      "email": true,
      "sms": false,
      "push": true
    }
  }
  ```
</ParamField>

package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

type UpdateOrganizationRequest struct {
    BasicInfo *BasicInfo `json:"basicInfo,omitempty"`
    Address   *Address   `json:"address,omitempty"`
    Contact   *Contact   `json:"contact,omitempty"`
    Settings  *Settings  `json:"settings,omitempty"`
}

type BasicInfo struct {
    Website     string `json:"website,omitempty"`
    Industry    string `json:"industry,omitempty"`
    CompanySize string `json:"companySize,omitempty"`
    Founded     string `json:"founded,omitempty"`
    Description string `json:"description,omitempty"`
}

type Address struct {
    Address1   string `json:"address1,omitempty"`
    Address2   string `json:"address2,omitempty"`
    City       string `json:"city,omitempty"`
    State      string `json:"state,omitempty"`
    PostalCode string `json:"postalCode,omitempty"`
    Country    string `json:"country,omitempty"`
}

type Contact struct {
    Phone string `json:"phone,omitempty"`
    Email string `json:"email,omitempty"`
}

type Settings struct {
    Timezone      string                 `json:"timezone,omitempty"`
    Currency      string                 `json:"currency,omitempty"`
    Language      string                 `json:"language,omitempty"`
    Notifications map[string]interface{} `json:"notifications,omitempty"`
}

func main() {
    payload := UpdateOrganizationRequest{
        BasicInfo: &BasicInfo{
            Website:     "https://www.acmecorp.com",
            Industry:    "TECHNOLOGY",
            CompanySize: "MEDIUM",
            Founded:     "2010",
            Description: "A leading technology company specializing in innovative software solutions",
        },
        Address: &Address{
            Address1:   "123 Technology Drive",
            Address2:   "Suite 100",
            City:       "San Francisco",
            State:      "California",
            PostalCode: "94105",
            Country:    "United States",
        },
        Contact: &Contact{
            Phone: "+1-555-123-4567",
            Email: "contact@acmecorp.com",
        },
        Settings: &Settings{
            Timezone: "America/Los_Angeles",
            Currency: "USD",
            Language: "en",
            Notifications: map[string]interface{}{
                "email": true,
                "sms":   false,
                "push":  true,
            },
        },
    }
    
    jsonData, _ := json.Marshal(payload)
    
    req, _ := http.NewRequest("PATCH", "https://api.example.com/org/information", bytes.NewBuffer(jsonData))
    req.Header.Set("Authorization", "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...")
    req.Header.Set("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
    
    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("%+v\n", result)
}

## Usage Notes

<AccordionGroup>
  <Accordion title="Partial Updates" icon="edit">
    Update flexibility:
    
    - **Selective Updates**: You can update only specific sections
    - **Partial Data**: Include only the fields you want to change
    - **Nested Objects**: Update nested objects like address or settings
    - **Validation**: Each field is validated independently
  </Accordion>
  
  <Accordion title="Industry Categories" icon="industry">
    Valid industry options:
    
    - **TECHNOLOGY**: Software, hardware, IT services
    - **HEALTHCARE**: Medical, pharmaceutical, health services
    - **FINANCE**: Banking, insurance, financial services
    - **EDUCATION**: Schools, universities, training
    - **OTHER**: Any other industry category
  </Accordion>
  
  <Accordion title="Company Sizes" icon="users">
    Valid company size options:
    
    - **SMALL**: 1-50 employees
    - **MEDIUM**: 51-500 employees
    - **LARGE**: 501-5000 employees
    - **ENTERPRISE**: 5000+ employees
  </Accordion>
  
  <Accordion title="Required Permissions" icon="shield">
    Permissions needed:
    
    - **Organization Admin**: Can update all organization information
    - **Organization Owner**: Can update all organization information
    - **Team Admin**: Can update basic information only
  </Accordion>
