---
title: "Register (Mobile)"
api: "POST /auth/m/register"
description: "Register a new user account (mobile/web)"
---

Register a new user account for mobile or web applications. This endpoint creates a new user account with the provided information and returns authentication tokens for immediate use.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and does not require authentication. It's designed for user registration in mobile and web applications.
</Note>

## Request

<ParamField body="fullname" type="string" required>
  Full name of the user
  
  **Example**: "John Doe"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must contain only letters, spaces, hyphens, and apostrophes
</ParamField>

<ParamField body="email" type="string" required>
  Email address for the account
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: 
  - Must be a valid email address
  - Must be unique across the platform
  - Maximum length: 255 characters
</ParamField>

<ParamField body="password" type="string" required>
  Password for the account
  
  **Example**: "SecurePassword123!"
  
  **Constraints**: 
  - Minimum length: 8 characters
  - Must contain at least one uppercase letter
  - Must contain at least one lowercase letter
  - Must contain at least one number
  - Must contain at least one special character
</ParamField>

<ParamField body="phone" type="string" required="false">
  Phone number for the account
  
  **Example**: "+1234567890"
  
  **Constraints**: 
  - Must be a valid phone number
  - International format preferred
</ParamField>

<ParamField body="organization_name" type="string" required="false">
  Name of the organization (if creating new organization)
  
  **Example**: "Acme Corporation"
  
  **Constraints**: 
  - Maximum length: 100 characters
  - Must be unique if provided
</ParamField>

<ParamField body="invite_code" type="string" required="false">
  Invitation code to join existing organization
  
  **Example**: "INVITE123456"
  
  **Constraints**: 
  - Must be a valid invitation code
  - Must not be expired
</ParamField>

<ParamField body="terms_accepted" type="boolean" required>
  Whether the user accepts the terms of service
  
  **Example**: true
  
  **Constraints**: 
  - Must be true to proceed with registration
</ParamField>

<ParamField body="marketing_consent" type="boolean" required="false">
  Whether the user consents to marketing communications
  
  **Example**: false
  
  **Default**: false
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Registration Flow" icon="user-plus">
    Registration process:
    
    1. User provides required information
    2. System validates input data
    3. User account is created
    4. Organization is created (if specified)
    5. Authentication tokens are generated
    6. Email verification is sent (if required)
  </Accordion>
  
  <Accordion title="Password Requirements" icon="lock">
    Password must contain:
    
    - At least 8 characters
    - One uppercase letter
    - One lowercase letter
    - One number
    - One special character
  </Accordion>
  
  <Accordion title="Organization Creation" icon="building">
    Organization options:
    
    - Create new organization with provided name
    - Join existing organization with invite code
    - Register without organization (personal account)
  </Accordion>
  
  <Accordion title="Email Verification" icon="mail">
    Email verification:
    
    - Required for most accounts
    - Verification email sent automatically
    - Account limited until verification complete
    - Resend verification available
  </Accordion>
</AccordionGroup>

## Code Examples

<AccordionGroup>
  <Accordion title="Mobile App Registration" icon="smartphone">
    ```javascript
class AuthService {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async registerUser(userData) {
    try {
      const response = await this.apiClient.makeRequest('/auth/m/register', {
        method: 'POST',
        body: JSON.stringify({
          fullname: userData.fullname,
          email: userData.email,
          password: userData.password,
          phone: userData.phone,
          organization_name: userData.organizationName,
          terms_accepted: true,
          marketing_consent: userData.marketingConsent || false
        })
      });
      
      if (!response.ok) {
        const error = await response.json();
        throw new Error(error.message || 'Registration failed');
      }
      
      const result = await response.json();
      
      // Store tokens securely
      await this.storeTokens(result.data.access_token, result.data.refresh_token);
      
      return result;
      
    } catch (error) {
      console.error('Registration error:', error);
      throw error;
    }
  }
  
  async storeTokens(accessToken, refreshToken) {
    // Store tokens in secure storage
    await SecureStore.setItemAsync('access_token', accessToken);
    await SecureStore.setItemAsync('refresh_token', refreshToken);
  }
}
```
