---
title: "Create Team"
api: "POST /org/create/team"
description: "Create a new team within the organization"
---

Create a new team within your organization. Teams are used to organize users and manage permissions for different projects or departments.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for organization management and team administration.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  The name of the team to create
  
  **Example**: "Development Team"
  
  **Constraints**: 
  - Minimum length: 1 character
  - Maximum length: 100 characters
  - Must be unique within the organization
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the team was created successfully
</ResponseField>

<ResponseField name="data" type="object">
  Contains the created team information
</ResponseField>

<ResponseField name="data.team_id" type="string">
  Unique identifier for the created team
</ResponseField>

<ResponseField name="data.name" type="string">
  The name of the created team
</ResponseField>

<ResponseField name="data.created_at" type="string">
  ISO 8601 timestamp when the team was created
</ResponseField>

<ResponseField name="data.status" type="string">
  Current status of the team (e.g., "active", "inactive")
</ResponseField>

<ResponseField name="data.member_count" type="integer">
  Number of members in the team (initially 0)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Team Naming" icon="tag">
    - Team names must be unique within your organization
    - Names are case-sensitive
    - Avoid using special characters that might cause issues
    - Consider using descriptive names that clearly identify the team's purpose
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    - You must have team creation permissions in your organization
    - Only organization administrators and team managers can create teams
    - Check your user role and permissions before attempting to create teams
  </Accordion>
  
  <Accordion title="Team Management" icon="users">
    After creating a team, you can:
    - Add members using the invite team member endpoint
    - Update team settings and permissions
    - Delete the team if no longer needed
    - View team members and their roles
  </Accordion>
  
  <Accordion title="Rate Limiting" icon="clock">
    Team creation is subject to rate limiting:
    - Maximum 10 teams per hour per organization
    - Check response headers for current rate limit status
    - Implement exponential backoff for retry logic
  </Accordion>
</AccordionGroup>

{`class TeamManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async createTeam(name) {
    try {
      const response = await this.apiClient.makeRequest('/org/create/team', {
        method: 'POST',
        body: JSON.stringify({ name })
      });
      
      if (response.ok) {
        const data = await response.json();
        console.log(\`Team "\${name}" created successfully with ID: \${data.data.team_id}\`);

      } else {
        const error = await response.json();

      console.error('Error creating team:', error.message);
      throw error;
    }
  }
  
  async createMultipleTeams(teamNames) {
    const results = [];
    
    for (const name of teamNames) {
      try {
        const team = await this.createTeam(name);
        results.push({ success: true, team });
      } catch (error) {
        results.push({ success: false, name, error: error.message });
      }
    }
    
    return results;
  }
}
