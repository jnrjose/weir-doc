---
title: "Get Talent Profile"
api: "GET /org/talent/{talentId}"
description: "Retrieve detailed information for a specific talent profile"
---

Retrieve comprehensive detailed information for a specific talent profile within your organization. This endpoint provides in-depth information about a talent's skills, experience, portfolio, and performance metrics.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for detailed talent profile viewing and management within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="talentId" type="string" required>
  Unique identifier of the talent profile to retrieve
  
  **Example**: "talent_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid talent ID
  - Talent profile must exist in your organization
  - You must have permission to view this talent profile
</ParamField>

    import requests
    from typing import Dict, List, Optional
    
    class TalentProfileManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_talent_profile(self, talent_id: str) -> Dict:
            """Get detailed talent profile information"""
            try:
                response = self.api_client.get(f'/org/talent/{talent_id}')
                response.raise_for_status()
                
                result = response.json()
                print(f"Talent profile retrieved: {result['data']['name']}")
                print(f"Rating: {result['data']['rating']}/5 ({result['data']['rating_count']} reviews)")
                
                return result

                print(f"Error getting talent profile: {e}")
