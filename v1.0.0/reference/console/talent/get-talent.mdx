---
title: "Get Talent"
api: "GET /org/talent"
description: "Retrieve talent information and profiles"
---

Retrieve comprehensive talent information and profiles within your organization. This endpoint provides detailed information about talent management, profiles, and associated data.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for talent management and profile oversight within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of talent profiles to return per page
  
  **Example**: "20"
  
  **Default**: "20"
  
  **Constraints**: 
  - Must be between 1 and 100
  - Recommended: 20-50 for optimal performance
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter talent by status
  
  **Options**: "active", "inactive", "pending", "suspended", "archived"
  
  **Example**: "active"
  
  **Default**: "active"
  
  **Note**: If not specified, returns only active talent profiles
</ParamField>

<ParamField query="category" type="string" required="false">
  Filter talent by category
  
  **Options**: "developer", "designer", "marketer", "manager", "analyst", "other"
  
  **Example**: "developer"
  
  **Note**: If not specified, returns all talent categories
</ParamField>

<ParamField query="skill_level" type="string" required="false">
  Filter talent by skill level
  
  **Options**: "junior", "mid", "senior", "lead", "expert"
  
  **Example**: "senior"
  
  **Note**: If not specified, returns all skill levels
</ParamField>

<ParamField query="teamId" type="string" required="false">
  Filter talent by team ID
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
  - You must have access to the team
</ParamField>

<ParamField query="search" type="string" required="false">
  Search talent by name, skills, or description
  
  **Example**: "react"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches name, skills, and description fields
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort talent by specified field
  
  **Options**: "name", "category", "skill_level", "created_at", "updated_at", "rating"
  
  **Example**: "rating"
  
  **Default**: "name"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "asc"
</ParamField>

<ParamField query="tags" type="string" required="false">
  Filter talent by tags (comma-separated)
  
  **Example**: "frontend,react,typescript"
  
  **Constraints**: 
  - Multiple tags separated by commas
  - Case-insensitive matching
  - Returns talent that has any of the specified tags
</ParamField>

<ParamField query="availability" type="string" required="false">
  Filter talent by availability
  
  **Options**: "available", "busy", "unavailable"
  
  **Example**: "available"
  
  **Note**: If not specified, returns talent regardless of availability
</ParamField>

    class TalentManagementService {
      constructor(apiClient) {
        this.apiClient = apiClient;

      async getTalent(options = {}) {
        try {
          const params = new URLSearchParams();
          
          // Add query parameters
          if (options.page) params.append('page', options.page);
          if (options.limit) params.append('limit', options.limit);
          if (options.status) params.append('status', options.status);
          if (options.category) params.append('category', options.category);
          if (options.skillLevel) params.append('skill_level', options.skillLevel);
          if (options.teamId) params.append('teamId', options.teamId);
          if (options.search) params.append('search', options.search);
          if (options.sortBy) params.append('sort_by', options.sortBy);
          if (options.sortOrder) params.append('sort_order', options.sortOrder);
          if (options.tags) params.append('tags', options.tags);
          if (options.availability) params.append('availability', options.availability);
          
          const response = await this.apiClient.makeRequest(
            `/org/talent?${params.toString()}`
          );
          
          if (!response.ok) {
            throw new Error('Failed to get talent profiles');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error getting talent profiles:', error);
          throw error;
        }
      }

    import requests
    from typing import Dict, List, Optional
    
    class TalentManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_talent(self, 
                      page: int = 1,
                      limit: int = 20,
                      status: str = "active",
                      category: Optional[str] = None,
                      skill_level: Optional[str] = None,
                      team_id: Optional[str] = None,
                      search: Optional[str] = None,
                      sort_by: str = "name",
                      sort_order: str = "asc",
                      tags: Optional[List[str]] = None,
                      availability: Optional[str] = None) -> Dict:
            """Get talent profiles with optional filtering and pagination"""
            try:
                params = {
                    "page": page,
                    "limit": limit,
                    "status": status,
                    "sort_by": sort_by,
                    "sort_order": sort_order
                }
                
                if category:
                    params["category"] = category
                if skill_level:
                    params["skill_level"] = skill_level
                if team_id:
                    params["teamId"] = team_id
                if search:
                    params["search"] = search
                if tags:
                    params["tags"] = ",".join(tags)
                if availability:
                    params["availability"] = availability
                
                response = self.api_client.get('/org/talent', params=params)
                response.raise_for_status()
                
                return response.json()
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting talent profiles: {e}")
                raise
        
        def get_all_talent(self) -> List[Dict]:
