---
title: "Update Organization Information"
api: "PATCH /org/information"
description: "Update organization details and settings"
---

Update organization information including basic details, contact information, address, and configuration settings. This endpoint allows you to modify all aspects of your organization's profile and settings.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for organization management and settings updates.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="basicInfo" type="object" required="false">
  Basic organization information
  
  **Properties**:
  - `website` (string): Organization website URL
  - `industry` (string): Industry classification
  - `description` (string): Organization description
  - `size` (string): Organization size category
</ParamField>

<ParamField body="contactInfo" type="object" required="false">
  Contact information
  
  **Properties**:
  - `phone` (string): Primary phone number
  - `email` (string): Contact email address
  - `support_email` (string): Support email address
</ParamField>

<ParamField body="address" type="object" required="false">
  Organization address
  
  **Properties**:
  - `street` (string): Street address
  - `city` (string): City
  - `state` (string): State or province
  - `country` (string): Country
  - `postal_code` (string): Postal or ZIP code
</ParamField>

<ParamField body="settings" type="object" required="false">
  Organization settings
  
  **Properties**:
  - `timezone` (string): Default timezone
  - `currency` (string): Default currency
  - `language` (string): Default language
  - `date_format` (string): Date format preference
</ParamField>

<ParamField body="billing" type="object" required="false">
  Billing information
  
  **Properties**:
  - `billing_email` (string): Billing email address
  - `billing_address` (object): Billing address
  - `payment_method` (string): Preferred payment method
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Partial Updates" icon="edit">
    Update behavior:
    
    - Only provided fields are updated
    - Missing fields remain unchanged
    - Nested objects are merged, not replaced
    - Empty strings clear the field value
  </Accordion>
  
  <Accordion title="Validation Rules" icon="check">
    Field validation:
    
    - Email addresses must be valid format
    - Phone numbers must be valid format
    - URLs must be valid format
    - Required fields cannot be empty
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    Required permissions:
    
    - Organization admin role
    - Or specific update permissions
    - Billing updates require billing admin role
  </Accordion>
  
  <Accordion title="Audit Trail" icon="history">

    - All changes are logged

    - Change history is available
    - Audit logs include user and timestamp

import requests

class OrganizationManager:
    def __init__(self, api_client):
        self.api_client = api_client
    
    def update_organization_settings(self, settings):
        """Update organization settings"""
        try:
            payload = {
                "settings": {
                    "timezone": settings.get("timezone"),
                    "currency": settings.get("currency"),
                    "language": settings.get("language"),
                    "date_format": settings.get("date_format")
                }
            }
            
            response = self.api_client.patch('/org/information', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to update organization settings: {e}")
            raise
    
    def update_billing_info(self, billing_info):
        """Update organization billing information"""
        try:
            payload = {
                "billing": {
                    "billing_email": billing_info.get("billing_email"),
                    "payment_method": billing_info.get("payment_method")
                }
            }
            
            response = self.api_client.patch('/org/information', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to update billing info: {e}")
            raise
