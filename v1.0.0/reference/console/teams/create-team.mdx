---
title: "Create Team"
api: "POST /org/create/team"
description: "Create a new team within the organization"
---

Create a new team within your organization with specified settings and configurations. This endpoint allows you to set up teams for different projects, departments, or functional groups.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team management and organization.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  Name of the team
  
  **Example**: "Development Team"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must be unique within the organization
</ParamField>

<ParamField body="description" type="string" required="false">
  Description of the team's purpose and responsibilities
  
  **Example**: "Responsible for developing and maintaining the core platform"
  
  **Constraints**: 
  - Maximum length: 500 characters
</ParamField>

<ParamField body="team_type" type="string" required="false">
  Type of team being created
  
  **Options**: "development", "design", "marketing", "sales", "support", "management", "other"
  
  **Default**: "other"
  
  **Example**: "development"
</ParamField>

<ParamField body="settings" type="object" required="false">
  Team-specific settings and configurations
  
  **Properties**:
  - `visibility` (string): Team visibility level ("public", "private", "restricted")
  - `auto_approve_members` (boolean): Whether to auto-approve new member requests
  - `allow_self_join` (boolean): Whether members can join without invitation
  - `max_members` (integer): Maximum number of team members
</ParamField>

<ParamField body="permissions" type="array" required="false">
  Default permissions for team members
  
  **Example**: ["read:projects", "write:tasks", "manage:members"]
  
  **Available Permissions**:
  - `read:projects` - View team projects
  - `write:projects` - Create and edit projects
  - `read:tasks` - View team tasks
  - `write:tasks` - Create and edit tasks
  - `manage:members` - Invite and remove members
  - `manage:settings` - Modify team settings
</ParamField>

  <Accordion title="Team Types" icon="users">
    Available team types:
    
    - **development**: Software development teams
    - **design**: Design and UX teams
    - **marketing**: Marketing and growth teams
    - **sales**: Sales and business development
    - **support**: Customer support teams
    - **management**: Management and leadership
    - **other**: Custom team types

  <Accordion title="Team Visibility" icon="eye">
    Visibility levels:
    
    - **public**: Visible to all organization members
    - **private**: Visible only to team members
    - **restricted**: Visible to team members and invited users
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    Team permission system:
    
    - Permissions are inherited by all team members
    - Can be overridden for individual members
    - New permissions can be added after team creation
    - Permissions are role-based and hierarchical
  </Accordion>
  
  <Accordion title="Team Limits" icon="info">
    Organization limits:
    
    - Maximum teams per organization: 50
    - Maximum members per team: 100
    - Team name must be unique within organization
    - Team creator automatically becomes team admin
  </Accordion>
</AccordionGroup>

import requests

class TeamManager:
    def __init__(self, api_client):
        self.api_client = api_client
    
    def create_team(self, name, description=None, team_type="other", **settings):
        """Create a new team"""
        try:
            payload = {
                "name": name,
                "description": description,
                "team_type": team_type,
                "settings": {
                    "visibility": settings.get("visibility", "private"),
                    "auto_approve_members": settings.get("auto_approve_members", False),
                    "allow_self_join": settings.get("allow_self_join", False),
                    "max_members": settings.get("max_members", 50)
                },
                "permissions": settings.get("permissions", [])
            }
            
            response = self.api_client.post('/org/create/team', json=payload)
            response.raise_for_status()
            
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Failed to create team: {e}")
            raise
    
    def create_project_team(self, project_name, team_size=10):
        """Create a team for a specific project"""
        return self.create_team(
            name=f"{project_name} Team",
            description=f"Development team for {project_name} project",
            team_type="development",
            visibility="private",
            max_members=team_size,
            permissions=[
                "read:projects",
                "write:projects",
                "read:tasks",
                "write:tasks",
                "manage:members"
            ]
        )
