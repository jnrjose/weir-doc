---
title: "Create Team"
api: "POST /org/create/team"
description: "Create a new team within the organization"
---

Create a new team within your organization with specified settings and configurations. This endpoint allows you to set up teams for different projects, departments, or functional groups.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team management and organization within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Request

<ParamField body="name" type="string" required>
  Name of the team
  
  **Example**: "Development Team"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Maximum length: 100 characters
  - Must be unique within the organization
  - Cannot contain special characters except spaces, hyphens, and underscores
</ParamField>

<ParamField body="description" type="string" required="false">
  Description of the team's purpose and responsibilities
  
  **Example**: "Responsible for developing and maintaining the core platform"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional field
</ParamField>

<ParamField body="team_type" type="string" required="false">
  Type of team being created
  
  **Options**: "development", "design", "marketing", "sales", "support", "management", "other"
  
  **Default**: "other"
  
  **Example**: "development"
</ParamField>

<ParamField body="settings" type="object" required="false">
  Additional team settings and configurations
  
  **Properties**:
  - `allow_self_registration` (boolean): Allow team members to self-register
  - `require_approval` (boolean): Require approval for new members
  - `max_members` (integer): Maximum number of team members
  - `default_role` (string): Default role for new members
  
  **Example**:
  ```json
  {
    "allow_self_registration": false,
    "require_approval": true,
    "max_members": 50,
    "default_role": "Organization_User"
  }
  ```
</ParamField>

    Available team types:
    
    - **development**: Software development teams
    - **design**: UI/UX and design teams
    - **marketing**: Marketing and communications teams
    - **sales**: Sales and business development teams
    - **support**: Customer support teams
    - **management**: Management and leadership teams
    - **other**: General purpose teams
  </Accordion>
  
  <Accordion title="Team Settings" icon="cog">
    Team configuration options:
    
    - **Self Registration**: Allow members to join without invitation
    - **Approval Required**: Require admin approval for new members
    - **Member Limits**: Set maximum number of team members
    - **Default Roles**: Assign default role to new members
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    Required permissions:
    
    - **Team Creator**: Can create new teams
    - **Organization Admin**: Full team management access
    - **Team Admin**: Can create teams within their scope
  </Accordion>
  
  <Accordion title="Best Practices" icon="lightbulb">

    - Use descriptive team names
    - Set appropriate member limits
    - Configure approval workflows
    - Assign appropriate default roles
    - Document team purpose in description

    ```python
    import requests
    from typing import Dict, Optional
    
    class TeamManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def create_team(self, 
                       name: str,
                       description: Optional[str] = None,
                       team_type: str = "other",
                       settings: Optional[Dict] = None) -> Dict:
            """Create a new team"""
            try:
                payload = {
                    "name": name,
                    "description": description,
                    "team_type": team_type,
                    "settings": settings or {}
                }
                
                response = self.api_client.post('/org/create/team', json=payload)
                response.raise_for_status()
                
                result = response.json()
                print(f"Team created: {result['data']['name']} (ID: {result['data']['team_id']})")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error creating team: {e}")
                raise
        
        def create_development_team(self, name: str, description: str, max_members: int = 25) -> Dict:
            """Create a development team with standard settings"""
            settings = {
                "allow_self_registration": False,
                "require_approval": True,
                "max_members": max_members,
                "default_role": "Organization_User"
            }
            
            return self.create_team(
                name=name,
                description=description,
                team_type="development",
                settings=settings
            )
        
        def create_support_team(self, name: str, description: str) -> Dict:
            """Create a support team with open registration"""
            settings = {
                "allow_self_registration": True,
                "require_approval": False,
                "max_members": 20,
                "default_role": "Organization_User"
            }
            
            return self.create_team(
                name=name,
                description=description,
                team_type="support",
                settings=settings
            )
    
    # Usage example
    team_manager = TeamManager(api_client)
    
    # Create different types of teams
    dev_team = team_manager.create_development_team(
        name="Backend Development",
        description="Handles backend services and API development"
    )
    
    support_team = team_manager.create_support_team(
        name="Customer Support",
        description="Provides customer support and assistance"
    )
    ```
