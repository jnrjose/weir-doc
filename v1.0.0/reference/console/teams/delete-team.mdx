---
title: "Delete Team"
api: "DELETE /org/team/{teamId}"
description: "Delete a team from the organization"
---

Permanently delete a team and all its associated data from your organization. This action cannot be undone and will remove all team members, resources, and configurations.

<Warning>
  **Destructive Action**
  
  This operation permanently deletes the team and all associated data. This action cannot be undone. Make sure you have backed up any important data before proceeding.
</Warning>

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team management and organization cleanup within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="teamId" type="string" required>
  Unique identifier of the team to delete
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
  - You must have permission to delete this team
</ParamField>

## Request

<ParamField body="confirmation" type="string" required>
  Confirmation text to verify the deletion intent
  
  **Example**: "DELETE_TEAM"
  
  **Constraints**: 
  - Must be exactly "DELETE_TEAM" (case-sensitive)
  - This is a safety measure to prevent accidental deletions
</ParamField>

<ParamField body="reason" type="string" required="false">
  Reason for deleting the team
  
  **Example**: "Team is no longer needed after project completion"
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional but recommended for audit purposes
</ParamField>

<ParamField body="transfer_resources" type="object" required="false">
  Configuration for transferring team resources to another team
  
  **Properties**:
  - `target_team_id` (string): ID of the team to transfer resources to
  - `transfer_members` (boolean): Whether to transfer team members
  - `transfer_data` (boolean): Whether to transfer team data and files
  - `transfer_permissions` (boolean): Whether to transfer permission settings
  
  **Example**:
  ```json
  {
    "target_team_id": "team_0987654321fedcba",
    "transfer_members": true,
    "transfer_data": true,
    "transfer_permissions": false
  }
  ```
</ParamField>

<ParamField body="notify_members" type="boolean" required="false">
  Whether to notify team members about the team deletion
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If true, all team members will receive an email notification
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Deletion Process" icon="trash">
    What happens when a team is deleted:
    
    - **Team Removal**: Team is permanently removed from the organization
    - **Member Handling**: Members are either transferred or removed based on configuration
    - **Data Cleanup**: Team data and resources are deleted or transferred
    - **Notification**: Team members are notified of the deletion (if enabled)
    - **Audit Log**: Deletion is logged for audit purposes
  </Accordion>
  
  <Accordion title="Resource Transfer" icon="exchange">
    Resource transfer options:
    
    - **Members**: Transfer team members to another team
    - **Data**: Transfer team files, documents, and data
    - **Permissions**: Transfer permission settings and configurations
    - **Projects**: Transfer ongoing projects and tasks
  </Accordion>
  
  <Accordion title="Required Permissions" icon="shield">
    Permissions needed to delete teams:
    
    - **Organization Admin**: Can delete any team in the organization
    - **Team Owner**: Can delete teams they own
    - **Team Admin**: Can delete teams they administer (with restrictions)
  </Accordion>
  
  <Accordion title="Safety Measures" icon="lock">
    Safety features:
    
    - **Confirmation Required**: Must provide "DELETE_TEAM" confirmation
    - **Dependency Check**: System checks for active dependencies
    - **Transfer Options**: Resources can be transferred instead of deleted
    - **Audit Trail**: All deletions are logged and tracked
  </Accordion>
</AccordionGroup>

          }
          
          const result = await response.json();
          
          // Log deletion
          console.log(`Team ${teamId} deleted successfully`);
          
          return result;
          
        } catch (error) {
          console.error('Error deleting team:', error);
          throw error;
        }
      }

            transfer_data: true,
            transfer_permissions: false
          },
          notifyMembers: true
        });
      }
      
      async deleteTeamPermanently(teamId, reason) {
        return this.deleteTeam(teamId, {
          reason: reason,
          notifyMembers: true
        });

        return this.deleteTeam(teamId, {
          reason: reason,

        });
