---
title: "Invite Team Member"
api: "POST /org/invite/team/member/{teamId}"
description: "Invite a new member to join a team within the organization"
---

Invite a new member to join a specific team. This endpoint allows you to add new members to existing teams with appropriate roles and permissions.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team management and member administration.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="teamId" type="string" required>
  The unique identifier of the team to invite the member to
</ParamField>

## Request

<ParamField body="firstname" type="string" required>
  The first name of the person being invited
  
  **Example**: "John"
</ParamField>

<ParamField body="lastname" type="string" required>
  The last name of the person being invited
  
  **Example**: "Doe"
</ParamField>

<ParamField body="email" type="string" required>
  The email address of the person being invited
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: Must be a valid email format
</ParamField>

<ParamField body="role" type="string" required>
  The role to assign to the invited member
  
  **Options**:
  - `Organization_User` - Standard organization user
  - `Team_Admin` - Team administrator with elevated permissions
  - `Viewer` - Read-only access to team resources
  
  **Example**: "Organization_User"
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the invitation was sent successfully
</ResponseField>

<ResponseField name="data" type="object">
  Contains the invitation details
</ResponseField>

<ResponseField name="data.invitation_id" type="string">
  Unique identifier for the invitation
</ResponseField>

<ResponseField name="data.email" type="string">
  Email address of the invited member
</ResponseField>

<ResponseField name="data.role" type="string">
  Role assigned to the invited member
</ResponseField>

<ResponseField name="data.team_id" type="string">
  ID of the team the member was invited to
</ResponseField>

<ResponseField name="data.status" type="string">
  Status of the invitation (pending, sent, accepted, expired)
</ResponseField>

<ResponseField name="data.expires_at" type="string">
  ISO 8601 timestamp when the invitation expires
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Invitation Process" icon="envelope">
    When you invite a team member:
    
    1. An invitation email is sent to the specified email address
    2. The invitation includes a secure link to accept the invitation
    3. The invited person must accept the invitation to join the team
    4. Invitations expire after 7 days if not accepted
  </Accordion>
  
  <Accordion title="Role Permissions" icon="shield">
    Different roles have different permissions:
    
    - **Organization_User**: Standard access to team resources
    - **Team_Admin**: Can manage team settings and invite other members
    - **Viewer**: Read-only access to team resources
  </Accordion>
  
  <Accordion title="Permissions Required" icon="key">
    To invite team members, you need:
    
    - Team management permissions
    - Organization user or admin role
    - Access to the specific team
  </Accordion>
  
  <Accordion title="Invitation Limits" icon="clock">
    There are limits on invitations:
    
    - Maximum 50 pending invitations per team
    - Maximum 5 invitations per hour per user
    - Invitations expire after 7 days
  </Accordion>
</AccordionGroup>

{`class TeamInvitationManager {
  constructor(apiClient) {

{`class InvitationValidator {
  validateInvitationData(memberData) {
    const errors = [];
    
    // Validate email format
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    if (!emailRegex.test(memberData.email)) {
      errors.push('Invalid email format');
    }
    
    // Validate required fields
    if (!memberData.firstname || memberData.firstname.trim().length === 0) {
      errors.push('First name is required');
    }
    
    if (!memberData.lastname || memberData.lastname.trim().length === 0) {
      errors.push('Last name is required');
    }
    
    // Validate role
    const validRoles = ['Organization_User', 'Team_Admin', 'Viewer'];
    if (!validRoles.includes(memberData.role)) {
      errors.push('Invalid role specified');
    }
    
    return {
      isValid: errors.length === 0,
      errors
    };
  }
  
  async inviteMemberWithValidation(teamId, memberData) {
    const validation = this.validateInvitationData(memberData);
    
    if (!validation.isValid) {
      throw new Error(\`Validation failed: \${validation.errors.join(', ')}\`);
    }
    
    const response = await this.apiClient.makeRequest(\`/org/invite/team/member/\${teamId}\`, {
      method: 'POST',
      body: JSON.stringify(memberData)
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(\`Invitation failed: \${error.error.message}\`);
    }
    
    return await response.json();
  }
}
