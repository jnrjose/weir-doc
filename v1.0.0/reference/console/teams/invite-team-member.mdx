---
title: "Invite Team Member"
api: "POST /org/invite/team/member/{teamId}"
description: "Invite a new member to join a team"
---

Invite a new member to join an existing team within your organization. This endpoint allows you to send invitations to potential team members via email with specified roles and permissions.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team management and member invitation within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="teamId" type="string" required>
  Unique identifier of the team to invite the member to
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
  - You must have permission to invite members to this team
</ParamField>

## Request

<ParamField body="firstname" type="string" required>
  First name of the person to invite
  
  **Example**: "John"
  
  **Constraints**: 
  - Minimum length: 1 character
  - Maximum length: 50 characters
  - Cannot contain special characters except hyphens and apostrophes
</ParamField>

<ParamField body="lastname" type="string" required>
  Last name of the person to invite
  
  **Example**: "Doe"
  
  **Constraints**: 
  - Minimum length: 1 character
  - Maximum length: 50 characters
  - Cannot contain special characters except hyphens and apostrophes
</ParamField>

<ParamField body="email" type="string" required>
  Email address of the person to invite
  
  **Example**: "john.doe@example.com"
  
  **Constraints**: 
  - Must be a valid email address format
  - Must be unique within the organization
  - Cannot be an existing user's email
</ParamField>

<ParamField body="role" type="string" required>
  Role to assign to the invited member
  
  **Options**: 
  - `Organization_User`: Standard organization member with basic permissions
  - `Team_Admin`: Team administrator with team management permissions
  - `Viewer`: Read-only access to team resources
  
  **Example**: "Organization_User"
  
  **Default**: "Organization_User"
</ParamField>

<ParamField body="message" type="string" required="false">
  Personal message to include in the invitation email
  
  **Example**: "Welcome to our development team! We're excited to have you join us."
  
  **Constraints**: 
  - Maximum length: 500 characters
  - Optional field
</ParamField>

<ParamField body="send_email" type="boolean" required="false">
  Whether to send an email invitation immediately
  
  **Example**: true
  
  **Default**: true
  
  **Note**: If false, the invitation will be created but no email will be sent
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the invitation was sent successfully
</ResponseField>

<ResponseField name="data" type="object">
  Contains the invitation information
</ResponseField>

<ResponseField name="data.invitation_id" type="string">
  Unique identifier for the invitation
</ResponseField>

<ResponseField name="data.team_id" type="string">
  ID of the team the person was invited to
</ResponseField>

<ResponseField name="data.invitee_email" type="string">
  Email address of the invited person
</ResponseField>

<ResponseField name="data.role" type="string">
  Role assigned to the invited member
</ResponseField>

<ResponseField name="data.status" type="string">
  Status of the invitation (pending, accepted, declined, expired)
</ResponseField>

<ResponseField name="data.invited_by" type="string">
  User ID of the person who sent the invitation
</ResponseField>

<ResponseField name="data.invited_at" type="string">
  ISO 8601 timestamp when the invitation was sent
</ResponseField>

<ResponseField name="data.expires_at" type="string">
  ISO 8601 timestamp when the invitation expires
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Team Roles" icon="users">
    Available team roles:
    
    - **Organization_User**: Standard member with basic team access
    - **Team_Admin**: Can manage team members and settings
    - **Viewer**: Read-only access to team resources and data
  </Accordion>
  
  <Accordion title="Invitation Process" icon="mail">
    How invitations work:
    
    - **Email Sent**: Invitation email sent to the specified address
    - **Invitation Link**: Contains secure token for accepting invitation
    - **Expiration**: Invitations expire after 7 days
    - **Status Tracking**: Monitor invitation status (pending, accepted, declined)
  </Accordion>
  
  <Accordion title="Permissions Required" icon="shield">
    Required permissions:
    
    - **Team Admin**: Can invite members to their teams
    - **Organization Admin**: Can invite members to any team
    - **Team Creator**: Can invite members to teams they created
  </Accordion>
  
  <Accordion title="Best Practices" icon="lightbulb">
    Invitation best practices:
    
    - **Personal Messages**: Include welcoming personal messages
    - **Role Selection**: Choose appropriate roles for team members
    - **Email Verification**: Ensure email addresses are correct
    - **Follow-up**: Track invitation status and follow up if needed
  </Accordion>

    ```python
    import requests
    from typing import Dict, Optional
    
    class TeamInvitationManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def invite_team_member(self, 
                              team_id: str,
                              firstname: str,
                              lastname: str,
                              email: str,
                              role: str = "Organization_User",
                              message: Optional[str] = None,
                              send_email: bool = True) -> Dict:
            """Invite a new member to a team"""
            try:
                payload = {
                    "firstname": firstname,
                    "lastname": lastname,
                    "email": email,
                    "role": role,
                    "send_email": send_email
                }
                
                if message:
                    payload["message"] = message
                
                response = self.api_client.post(f'/org/invite/team/member/{team_id}', json=payload)
                response.raise_for_status()
                
                result = response.json()
                print(f"Invitation sent to {email} for team {team_id}")
                
                return result
                
            except requests.exceptions.RequestException as e:
                print(f"Error inviting team member: {e}")
                raise
        
        def invite_developer(self, team_id: str, email: str, firstname: str, lastname: str) -> Dict:
            """Invite a developer to the team"""
            return self.invite_team_member(
                team_id=team_id,
                firstname=firstname,
                lastname=lastname,
                email=email,
                role="Organization_User",
                message="Welcome to our development team! We are excited to have you join us."
            )
        
        def invite_team_admin(self, team_id: str, email: str, firstname: str, lastname: str) -> Dict:
            """Invite a team administrator"""
            return self.invite_team_member(
                team_id=team_id,
                firstname=firstname,
                lastname=lastname,
                email=email,
                role="Team_Admin",
                message="You have been invited as a team administrator. Welcome to the team!"
            )
        
        def invite_viewer(self, team_id: str, email: str, firstname: str, lastname: str) -> Dict:
            """Invite a viewer to the team"""
            return self.invite_team_member(
                team_id=team_id,
                firstname=firstname,
                lastname=lastname,
                email=email,
                role="Viewer",
                message="You have been granted read-only access to our team resources."
            )
        
        def bulk_invite_developers(self, team_id: str, developers: list) -> list:
            """Invite multiple developers to a team"""
            results = []
            for dev in developers:
                try:
                    result = self.invite_developer(
                        team_id=team_id,
                        email=dev['email'],
                        firstname=dev['firstname'],
                        lastname=dev['lastname']
                    )
                    results.append({"success": True, "data": result, "developer": dev})
                except Exception as e:
                    results.append({"success": False, "error": str(e), "developer": dev})
            
            return results
    ```
