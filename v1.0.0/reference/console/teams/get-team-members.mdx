---
title: "Get Team Members"
api: "GET /org/team/members/{teamId}"
description: "Retrieve list of members in a specific team"
---

Retrieve a comprehensive list of all members in a specific team, including their roles, status, and membership details. This endpoint provides detailed information about team composition and member permissions.

<Note>
  **Console API Endpoint**
  
  This endpoint is part of the Console API category and requires Bearer Token authentication. It's designed for team management and member oversight within the Weir AI platform.
</Note>

## Authentication

This endpoint requires Bearer Token authentication. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your_jwt_token>
```

## Path Parameters

<ParamField path="teamId" type="string" required>
  Unique identifier of the team to retrieve members for
  
  **Example**: "team_1234567890abcdef"
  
  **Constraints**: 
  - Must be a valid team ID
  - Team must exist in your organization
  - You must have permission to view team members
</ParamField>

## Query Parameters

<ParamField query="page" type="string" required="false">
  Page number for pagination
  
  **Example**: "1"
  
  **Default**: "1"
  
  **Constraints**: 
  - Must be a positive integer
  - Minimum value: 1
</ParamField>

<ParamField query="limit" type="string" required="false">
  Number of members to return per page
  
  **Example**: "20"
  
  **Default**: "20"
  
  **Constraints**: 
  - Must be between 1 and 100
  - Recommended: 20-50 for optimal performance
</ParamField>

<ParamField query="role" type="string" required="false">
  Filter members by role
  
  **Options**: "Organization_User", "Team_Admin", "Viewer"
  
  **Example**: "Team_Admin"
  
  **Note**: If not specified, returns all members regardless of role
</ParamField>

<ParamField query="status" type="string" required="false">
  Filter members by status
  
  **Options**: "active", "pending", "suspended", "inactive"
  
  **Example**: "active"
  
  **Default**: "active"
  
  **Note**: If not specified, returns only active members
</ParamField>

<ParamField query="search" type="string" required="false">
  Search members by name or email
  
  **Example**: "john"
  
  **Constraints**: 
  - Minimum length: 2 characters
  - Case-insensitive search
  - Searches both first name, last name, and email
</ParamField>

<ParamField query="sort_by" type="string" required="false">
  Sort members by specified field
  
  **Options**: "name", "email", "role", "joined_at", "last_active"
  
  **Example**: "joined_at"
  
  **Default**: "name"
</ParamField>

<ParamField query="sort_order" type="string" required="false">
  Sort order for the results
  
  **Options**: "asc", "desc"
  
  **Example**: "desc"
  
  **Default**: "asc"
</ParamField>

## Usage Notes

<AccordionGroup>
  <Accordion title="Member Roles" icon="users">
    Team member roles:
    
    - **Team_Admin**: Full team management permissions
    - **Organization_User**: Standard team member with read/write access
    - **Viewer**: Read-only access to team resources
  </Accordion>
  
  <Accordion title="Member Status" icon="info">
    Member status options:
    
    - **active**: Member is active and can access team resources
    - **pending**: Member has been invited but hasn't accepted yet
    - **suspended**: Member access is temporarily suspended
    - **inactive**: Member is no longer active in the team
  </Accordion>
  
  <Accordion title="Permissions" icon="shield">
    Member permissions:
    
    - **team:read**: Can view team resources and data
    - **team:write**: Can create and modify team resources
    - **team:manage_members**: Can invite and manage team members
    - **team:manage_settings**: Can modify team settings and configuration
  </Accordion>
  
  <Accordion title="Pagination" icon="list">
    Pagination best practices:
    
    - **Page Size**: Use 20-50 items per page for optimal performance
    - **Sorting**: Sort by relevant fields (name, joined_at, last_active)
    - **Filtering**: Use role and status filters to narrow results
    - **Search**: Use search parameter for finding specific members
  </Accordion>
</AccordionGroup>

    ```javascript
      async getTeamMembers(teamId, options = {}) {

          const params = new URLSearchParams();
          
          // Add query parameters
          if (options.page) params.append('page', options.page);
          if (options.limit) params.append('limit', options.limit);
          if (options.role) params.append('role', options.role);
          if (options.status) params.append('status', options.status);
          if (options.search) params.append('search', options.search);
          if (options.sortBy) params.append('sort_by', options.sortBy);
          if (options.sortOrder) params.append('sort_order', options.sortOrder);
          
          const response = await this.apiClient.makeRequest(
            `/org/team/members/${teamId}?${params.toString()}`
          );
          
          if (!response.ok) {
            throw new Error('Failed to get team members');
          }
          
          return await response.json();
          
        } catch (error) {
          console.error('Error getting team members:', error);
          throw error;
        }

      async getAllTeamMembers(teamId) {
        const allMembers = [];
        let page = 1;
        let hasMore = true;
        
        while (hasMore) {
          const result = await this.getTeamMembers(teamId, {
            page: page,
            limit: 50
          });
          
          allMembers.push(...result.data);
          hasMore = result.pagination.has_next;
          page++;
        }
        
        return allMembers;
      }

        return this.getTeamMembers(teamId, {
          status: 'active',
          sortBy: 'name',
          sortOrder: 'asc'
        });

        return this.getTeamMembers(teamId, {

          status: 'active'

          sortBy: 'joined_at',

          limit: limit
    ```

    ```python
    import requests
    from typing import Dict, List, Optional
    
    class TeamMemberManager:
        def __init__(self, api_client):
            self.api_client = api_client
        
        def get_team_members(self, 
                           team_id: str,
                           page: int = 1,
                           limit: int = 20,
                           role: Optional[str] = None,
                           status: str = "active",
                           search: Optional[str] = None,
                           sort_by: str = "name",
                           sort_order: str = "asc") -> Dict:
            """Get team members with optional filtering and pagination"""
            try:
                params = {
                    "page": page,
                    "limit": limit,
                    "status": status,
                    "sort_by": sort_by,
                    "sort_order": sort_order
                }
                
                if role:
                    params["role"] = role
                if search:
                    params["search"] = search
                
                response = self.api_client.get(f'/org/team/members/{team_id}', params=params)
                response.raise_for_status()
                
                return response.json()
                
            except requests.exceptions.RequestException as e:
                print(f"Error getting team members: {e}")
                raise
        
        def get_all_team_members(self, team_id: str) -> List[Dict]:
            """Get all team members across all pages"""
            all_members = []
            page = 1
            has_more = True
            
            while has_more:
                result = self.get_team_members(team_id, page=page, limit=50)
                all_members.extend(result["data"])
                has_more = result["pagination"]["has_next"]
                page += 1
            
            return all_members
        
        def get_active_members(self, team_id: str) -> Dict:
            """Get all active team members"""
            return self.get_team_members(
                team_id=team_id,
                status="active",
                sort_by="name",
                sort_order="asc"
            )
        
        def get_team_admins(self, team_id: str) -> Dict:
            """Get all team administrators"""
            return self.get_team_members(
                team_id=team_id,
                role="Team_Admin",
                status="active"
            )
        
        def search_members(self, team_id: str, search_term: str) -> Dict:
            """Search team members by name or email"""
            return self.get_team_members(
                team_id=team_id,
                search=search_term,
                status="active"
            )
        
        def get_recent_members(self, team_id: str, limit: int = 10) -> Dict:
            """Get recently joined team members"""
            return self.get_team_members(
                team_id=team_id,
                status="active",
                sort_by="joined_at",
                sort_order="desc",
                limit=limit
            )
        
        def get_member_by_email(self, team_id: str, email: str) -> Optional[Dict]:
            """Find a specific team member by email"""
            result = self.search_members(team_id, email)
            for member in result["data"]:
                if member["email"].lower() == email.lower():
                    return member
            return None
        
        def get_member_statistics(self, team_id: str) -> Dict:
            """Get team member statistics"""
            all_members = self.get_all_team_members(team_id)
            
            stats = {
                "total_members": len(all_members),
                "active_members": len([m for m in all_members if m["status"] == "active"]),
                "pending_members": len([m for m in all_members if m["status"] == "pending"]),
                "suspended_members": len([m for m in all_members if m["status"] == "suspended"]),
                "team_admins": len([m for m in all_members if m["role"] == "Team_Admin"]),
                "organization_users": len([m for m in all_members if m["role"] == "Organization_User"]),
                "viewers": len([m for m in all_members if m["role"] == "Viewer"])
            }
            
            return stats
    ```
