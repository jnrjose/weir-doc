This guide covers everything you need to know about integrating with Weir AI External APIs. These APIs are designed for third-party applications, external services, and public integrations.

## Overview

External APIs provide a simplified interface for external applications to access Weir AI capabilities. They use Basic Authentication and are designed for public consumption.

<CardGroup cols={2}>
  <Card title="Authentication" icon="key">

    **Use Case**: Third-party applications, external services
  </Card>
  <Card title="Base URL" icon="server">
    **URL**: `https://external.example.com`
    
    **Protocol**: HTTPS only
    
    **Rate Limit**: 1000 requests/hour
  </Card>
</CardGroup>

## Getting Started

### Step 1: Obtain Credentials

You'll need Basic Authentication credentials (username and password) for external API access.

<Note>
  **Credential Management**
  
  Store your credentials securely using environment variables or secure credential stores. Never hardcode credentials in your application code.
</Note>

### Step 2: Set Up Authentication

```javascript Basic Authentication Setup
{`// Encode credentials for Basic Auth
const credentials = btoa('username:password');

// Use in API requests
const response = await fetch('https://external.example.com/auth/token', {
  method: 'POST',
  headers: {
    'Authorization': \`Basic \${credentials}\`,
    'Content-Type': 'application/json'
  }
});`}
```

### Step 3: Make Your First API Call

```javascript Generate Access Token
{`async function generateAccessToken() {
  const credentials = btoa('username:password');
  
  try {
    const response = await fetch('https://external.example.com/auth/token', {
      method: 'POST',
      headers: {
        'Authorization': \`Basic \${credentials}\`,
        'Content-Type': 'application/json'
      }
    });
    
    if (!response.ok) {
      throw new Error(\`HTTP error! status: \${response.status}\`);
    }
    
    const data = await response.json();
    console.log('Access token:', data.data.access_token);
    return data.data.access_token;
    
  } catch (error) {
    console.error('Error generating access token:', error);
    throw error;
  }
}`}
```

## Integration Patterns

### Pattern 1: Simple Token Generation

For applications that need occasional access to Weir AI services:

```javascript Simple Integration
{`class SimpleWeirClient {
  constructor(username, password) {
    this.username = username;
    this.password = password;
    this.credentials = btoa(\`\${username}:\${password}\`);
  }
  
  async getAccessToken() {
    const response = await fetch('https://external.example.com/auth/token', {
      method: 'POST',
      headers: {
        'Authorization': \`Basic \${this.credentials}\`,
        'Content-Type': 'application/json'
      }
    });
    
    if (!response.ok) {
      throw new Error(\`Failed to get access token: \${response.status}\`);
    }
    
    const data = await response.json();
    return data.data.access_token;
  }
  
  async makeAuthenticatedRequest(endpoint, options = {}) {
    const token = await this.getAccessToken();
    
    return fetch(\`https://external.example.com\${endpoint}\`, {
      ...options,
      headers: {
        'Authorization': \`Bearer \${token}\`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
  }
}

// Usage
const client = new SimpleWeirClient('username', 'password');
const response = await client.makeAuthenticatedRequest('/some-endpoint');`}
```

### Pattern 2: Cached Token Management

For applications that make frequent API calls:

```javascript Cached Token Integration
{`class CachedWeirClient {
  constructor(username, password) {
    this.username = username;
    this.password = password;
    this.credentials = btoa(\`\${username}:\${password}\`);
    this.accessToken = null;
    this.tokenExpiry = null;
  }
  
  async getValidToken() {
    // Check if current token is still valid
    if (this.accessToken && this.tokenExpiry > Date.now()) {
      return this.accessToken;
    }
    
    // Generate new token
    return await this.generateNewToken();
  }
  
  async generateNewToken() {
    const response = await fetch('https://external.example.com/auth/token', {
      method: 'POST',
      headers: {
        'Authorization': \`Basic \${this.credentials}\`,
        'Content-Type': 'application/json'
      }
    });
    
    if (!response.ok) {
      throw new Error(\`Failed to generate token: \${response.status}\`);
    }
    
    const data = await response.json();
    this.accessToken = data.data.access_token;
    this.tokenExpiry = Date.now() + (data.data.expires_in * 1000);
    
    return this.accessToken;
  }
  
  async makeRequest(endpoint, options = {}) {
    const token = await this.getValidToken();
    
    return fetch(\`https://external.example.com\${endpoint}\`, {
      ...options,
      headers: {
        'Authorization': \`Bearer \${token}\`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
  }
}`}
```

## Error Handling

### Common Error Scenarios

<AccordionGroup>
  <Accordion title="Authentication Errors" icon="exclamation-triangle">
    **401 Unauthorized**
    
    - Invalid credentials
    - Expired credentials
    - Malformed authorization header
    
    **Solution**: Verify credentials and authorization header format
  </Accordion>
  
  <Accordion title="Rate Limiting" icon="clock">
    **429 Too Many Requests**
    
    - Exceeded rate limit (1000 requests/hour)
    - Check `Retry-After` header for retry timing
    
    **Solution**: Implement exponential backoff and respect rate limits
  </Accordion>
  
  <Accordion title="Network Errors" icon="wifi">
    **Network Issues**
    
    - Connection timeouts
    - DNS resolution failures
    - SSL certificate issues
    
    **Solution**: Implement retry logic with exponential backoff
  </Accordion>
</AccordionGroup>

### Robust Error Handling

```javascript Comprehensive Error Handling
{`class RobustWeirClient {
  constructor(username, password, options = {}) {
    this.username = username;
    this.password = password;
    this.credentials = btoa(\`\${username}:\${password}\`);
    this.maxRetries = options.maxRetries || 3;
    this.retryDelay = options.retryDelay || 1000;
  }
  
  async makeRequestWithRetry(endpoint, options = {}) {
    let lastError;
    
    for (let attempt = 1; attempt <= this.maxRetries; attempt++) {
      try {
        const response = await this.makeRequest(endpoint, options);
        
        // Handle rate limiting
        if (response.status === 429) {
          const retryAfter = response.headers.get('Retry-After');
          const delay = retryAfter ? parseInt(retryAfter) * 1000 : this.retryDelay * attempt;
          
          console.log(\`Rate limited. Waiting \${delay}ms before retry \${attempt}\`);
          await this.sleep(delay);
          continue;
        }
        
        // Handle authentication errors
        if (response.status === 401) {
          throw new Error('Authentication failed. Please check your credentials.');
        }
        
        // Handle other client errors
        if (response.status >= 400 && response.status < 500) {
          const errorData = await response.json().catch(() => ({}));
          throw new Error(\`Client error \${response.status}: \${errorData.message || 'Unknown error'}\`);
        }
        
        // Handle server errors
        if (response.status >= 500) {
          if (attempt === this.maxRetries) {
            throw new Error(\`Server error \${response.status} after \${this.maxRetries} attempts\`);
          }
          
          console.log(\`Server error \${response.status}. Retrying in \${this.retryDelay * attempt}ms...\`);
          await this.sleep(this.retryDelay * attempt);
          continue;
        }
        
        return response;
        
      } catch (error) {
        lastError = error;
        
        if (attempt === this.maxRetries) {
          break;
        }
        
        console.log(\`Attempt \${attempt} failed: \${error.message}. Retrying...\`);
        await this.sleep(this.retryDelay * attempt);
      }
    }
    
    throw new Error(\`Request failed after \${this.maxRetries} attempts: \${lastError.message}\`);
  }
  
  async sleep(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
  
  async makeRequest(endpoint, options = {}) {
    const token = await this.getValidToken();
    
    return fetch(\`https://external.example.com\${endpoint}\`, {
      ...options,
      headers: {
        'Authorization': \`Bearer \${token}\`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
  }
  
  async getValidToken() {
    // Implementation from previous example
    // ... token management logic
  }
}`}
```

## Security Best Practices

### Credential Security

<Steps>
  <Step title="Environment Variables" icon="code">
    Store credentials in environment variables, never in code:
    
    ```bash
    export WEIR_USERNAME=your_username
    export WEIR_PASSWORD=your_password
    ```
  </Step>
  <Step title="Secure Storage" icon="vault">
    Use secure credential stores in production:
    - AWS Secrets Manager
    - HashiCorp Vault
    - Azure Key Vault
    - Google Secret Manager
  </Step>
  <Step title="Credential Rotation" icon="refresh">
    Regularly rotate credentials and implement automated rotation where possible.
  </Step>
  <Step title="Network Security" icon="lock">
    Always use HTTPS and validate SSL certificates.
  </Step>
</Steps>

## Monitoring and Logging

### Request Logging

```javascript Request Logging
{`class LoggingWeirClient {
  constructor(username, password, logger) {
    this.username = username;
    this.password = password;
    this.credentials = btoa(\`\${username}:\${password}\`);
    this.logger = logger;
  }
  
  async makeRequest(endpoint, options = {}) {
    const startTime = Date.now();
    const requestId = this.generateRequestId();
    
    this.logger.info('Making Weir API request', {
      requestId,
      endpoint,
      method: options.method || 'GET'
    });
    
    try {
      const response = await this.makeActualRequest(endpoint, options);
      const duration = Date.now() - startTime;
      
      this.logger.info('Weir API request completed', {
        requestId,
        endpoint,
        status: response.status,
        duration
      });
      
      return response;
      
    } catch (error) {
      const duration = Date.now() - startTime;
      
      this.logger.error('Weir API request failed', {
        requestId,
        endpoint,
        error: error.message,
        duration
      });
      
      throw error;
    }
  }
  
  generateRequestId() {
    return Math.random().toString(36).substr(2, 9);
  }
}`}
```

### Performance Monitoring

```javascript Performance Monitoring
{`class MonitoredWeirClient {
  constructor(username, password, metrics) {
    this.username = username;
    this.password = password;
    this.credentials = btoa(\`\${username}:\${password}\`);
    this.metrics = metrics;
  }
  
  async makeRequest(endpoint, options = {}) {
    const timer = this.metrics.startTimer('weir_api_request_duration', {
      endpoint: endpoint.replace(/\/[^\/]+$/, '/:id'), // Normalize endpoint
      method: options.method || 'GET'
    });
    
    try {
      const response = await this.makeActualRequest(endpoint, options);
      
      this.metrics.increment('weir_api_requests_total', {
        endpoint: endpoint.replace(/\/[^\/]+$/, '/:id'),
        method: options.method || 'GET',
        status: response.status
      });
      
      return response;
      
    } catch (error) {
      this.metrics.increment('weir_api_requests_failed_total', {
        endpoint: endpoint.replace(/\/[^\/]+$/, '/:id'),
        method: options.method || 'GET',
        error_type: error.constructor.name
      });
      
      throw error;
      
    } finally {
      timer();
    }
  }
}`}
```

global.fetch = jest.fn();

describe('WeirClient', () => {
