## Choose Your API Category

Weir AI API v1.0.0 offers different API categories for different use cases:

<AccordionGroup>
  <Accordion title="External APIs" icon="globe" defaultOpen={true}>
    **Best for**: Third-party integrations, public applications, external services
    
    **Authentication**: Basic Authentication or Bearer Token
    
    **Key Endpoints**:
    - `POST /auth/token` - Generate access tokens
    
    **Use Case**: If you're building an external application that needs to integrate with Weir AI
  </Accordion>
  
  <Accordion title="Console APIs" icon="desktop">
    **Best for**: Organization management, team administration, platform management
    
    **Authentication**: Bearer Token (JWT)
    
    **Key Endpoints**:
    - `POST /auth/m/register` - Register new users
    - `GET /org/teams` - Manage teams
    - `POST /org/create/platform` - Create platforms
    
    **Use Case**: If you're building internal management tools or admin dashboards
  </Accordion>
  
  <Accordion title="Admin APIs" icon="user-shield">
    **Best for**: System administration, platform monitoring, content management
    
    **Authentication**: Bearer Token (JWT)
    
    **Key Endpoints**:
    - `POST /auth/login` - Admin login
    - `GET /admin/organizations` - Manage organizations
    - `POST /logs/log` - Create log entries
    
    **Use Case**: If you're building system administration tools or monitoring dashboards
  </Accordion>
</AccordionGroup>

## Step 1: Get Your API Credentials

### For External APIs
You'll need basic authentication credentials (username/password) or an API key.

### For Console/Admin APIs
You'll need a Bearer token (JWT). This is typically obtained through:
- Admin login: `POST /auth/login`
- User registration: `POST /auth/m/register`
- Token refresh: `POST /auth/refresh/token`

## Step 3: Make Your First API Call

Let's start with a simple example. We'll use the External API to generate an access token:

### Using cURL

```bash
{`curl -X POST "https://external.example.com/auth/token" \\
  -H "Authorization: Basic <YOUR_BASIC_AUTH_CREDENTIALS>" \\
  -H "Content-Type: application/json"`}
```

### Using JavaScript (Node.js)

```javascript
{`const response = await fetch('https://external.example.com/auth/token', {
  method: 'POST',
  headers: {
    'Authorization': 'Basic <YOUR_BASIC_AUTH_CREDENTIALS>',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);`}
```

### Using Python

```python
{`import requests

response = requests.post(
    'https://external.example.com/auth/token',
    headers={
        'Authorization': 'Basic <YOUR_BASIC_AUTH_CREDENTIALS>',
        'Content-Type': 'application/json'
    }
)

print(response.json())`}
```

## Step 4: Test with Console APIs

Once you have a Bearer token, let's try a Console API endpoint:

### Get Organization Information

```bash
{`curl -X GET "https://api.example.com/org/information" \\
  -H "Authorization: Bearer <YOUR_BEARER_TOKEN>" \\
  -H "Content-Type: application/json"`}
```

### Create a Team

```bash
{`curl -X POST "https://api.example.com/org/create/team" \\
  -H "Authorization: Bearer <YOUR_BEARER_TOKEN>" \\
  -H "Content-Type: application/json" \\
  -d '{
    "name": "My Development Team"
  }'`}
```

## Error Handling

Understanding API responses is crucial for robust integrations:

<CardGroup cols={2}>
  <Card title="Success Responses" icon="check-circle">
    - **200 OK**: Request successful
    - **201 Created**: Resource created successfully
    - **202 Accepted**: Request accepted for processing
  </Card>
  <Card title="Client Errors" icon="exclamation-triangle">
    - **400 Bad Request**: Invalid request data
    - **401 Unauthorized**: Authentication required
    - **403 Forbidden**: Access denied
    - **404 Not Found**: Resource not found
  </Card>
  <Card title="Server Errors" icon="server">
    - **500 Internal Server Error**: Server error
    - **502 Bad Gateway**: Gateway error
    - **503 Service Unavailable**: Service temporarily unavailable
  </Card>
  <Card title="Rate Limiting" icon="clock">
    - **429 Too Many Requests**: Rate limit exceeded
    - Check response headers for retry information
  </Card>
</CardGroup>
