## API Categories Overview

The Weir AI API v1.0.0 is organized into distinct categories, each serving specific use cases:

<AccordionGroup>
  <Accordion title="External APIs" icon="globe" defaultOpen={true}>
    **Purpose**: Public-facing APIs for external integrations and third-party applications.
    
    **Key Features**:
    - Access token generation for external applications
    - Basic authentication support
    - Designed for public consumption and integration
    
    **Use Cases**: Third-party integrations, public applications, external service providers
  </Accordion>
  
  <Accordion title="Console APIs" icon="desktop">
    **Purpose**: Management interfaces for organization administrators and platform owners.
    
    **Key Features**:
    - Team and organization management
    - Platform and client management
    - Talent roster and license management
    - User registration and authentication
    
    **Use Cases**: Internal dashboards, admin panels, organization management tools
  </Accordion>
  
  <Accordion title="Admin APIs" icon="user-shield">
    **Purpose**: System administration and platform-wide management capabilities.
    
    **Key Features**:
    - System-wide user management
    - Platform monitoring and control
    - Mail template management
    - Pod management and orchestration
    - Comprehensive logging and analytics
    
    **Use Cases**: Platform administration, system monitoring, content management
  </Accordion>
</AccordionGroup>
