## What is Weir?

Weir is a comprehensive NIL (Name, Image, Likeness) detection and identity verification platform that helps organizations:

- **Detect unauthorized use** of celebrity images and likenesses
- **Verify identity** through advanced facial recognition and analysis
- **Manage talent rosters** and licensing agreements
- **Monitor platforms** for potential violations
- **Provide analytics** and reporting on NIL usage

## Key Features

<Callout type="info">

## API Overview

The Weir API is organized into several main categories:

### **External APIs**
For third-party integrations and external applications that need to interact with Weir's core services.

### **Console APIs**
For Weir's internal console and dashboard applications, providing full platform management capabilities.

### **Admin APIs**
For administrative functions, system management, and platform-wide operations.

### **Organization APIs**
For managing organizations, teams, clients, platforms, and talent rosters.

### **Authentication APIs**
Comprehensive authentication system supporting multiple methods and use cases.

## Getting Started

1. **Create an Account**: Sign up for a Weir account and obtain your API credentials
2. **Choose Your Integration**: Select the appropriate API category for your use case
3. **Authenticate**: Use your API keys or tokens to authenticate requests
4. **Make Your First Request**: Start with simple endpoints to understand the API structure
5. **Explore Features**: Use the playground to experiment with different endpoints and parameters
