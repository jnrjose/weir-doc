## Authentication Methods

The playground supports multiple authentication methods:

### 1. API Key Authentication
For external integrations and third-party applications:

```bash
# Generate access token
curl -X POST "https://api-dev.weir.ai/auth/token" \
  -u "your-client-id:your-secret-key"
```

### 2. Bearer Token Authentication
For user-facing applications and web dashboards:

```bash
# Use access token
curl -X GET "https://api-dev.weir.ai/org/information" \
  -H "Authorization: Bearer your-access-token"
```

### 3. Console Authentication
For internal console applications:

```bash
# Console API with special header
curl -X GET "https://api-dev.weir.ai/org/teams" \
  -H "Authorization: Bearer your-console-token" \
  -H "x-source: console"
```

## Best Practices

### 1. Test Authentication First
Always start by testing your authentication method before making other API calls to ensure your credentials are working correctly.

### 2. Use Appropriate Endpoints
Choose the right API category for your use case:
- **External APIs** for third-party integrations and external applications
- **Console APIs** for internal dashboard applications and administrative tools
- **Admin APIs** for system-wide administrative functions

### 3. Handle Errors Gracefully
Implement proper error handling in your applications based on the playground examples and error scenarios.

### 4. Respect Rate Limits
Use the playground to understand rate limits and implement appropriate throttling and retry logic in your applications.
