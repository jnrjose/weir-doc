# Authentication APIs

Comprehensive authentication system supporting multiple methods and use cases for user registration, login, token management, and password recovery.

## Overview

Authentication APIs provide functionality for:
- User registration and account creation
- User login and authentication
- Token generation and refresh
- Password reset and recovery
- Account validation and verification
- Session management

## Authentication Methods

### 1. API Key Authentication
For external integrations and third-party applications:

```bash
curl -X POST "https://api-dev.weir.ai/auth/token" \
  -u "your-client-id:your-secret-key"
```

### 2. User Authentication
For user-facing applications and web dashboards:

```bash
curl -X POST "https://api-dev.weir.ai/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username": "user@example.com", "password": "password"}'
```

### 3. Console Authentication
For internal console applications:

```bash
curl -X GET "https://api-dev.weir.ai/org/teams" \
  -H "Authorization: Bearer your-console-token" \
  -H "x-source: console"
```

## Rate Limits

Authentication APIs have the following rate limits:
- **100 requests per minute** per IP address
- **1,000 requests per hour** per user
- **10 concurrent requests** maximum

<Callout type="warning">
Rate limits are enforced per IP address and user to prevent abuse and ensure system stability.
</Callout>

## Common Use Cases

### 1. User Registration Flow
```javascript
async function registerUser(userData) {
  try {
    // Step 1: Register user
    const registerResponse = await fetch('https://api-dev.weir.ai/auth/register', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(userData)
    });
    
    const registerData = await registerResponse.json();
    
    if (!registerData.success) {
      throw new Error(registerData.error.message);
    }
    
    // Step 2: Validate registration (if OTP required)
    if (registerData.data.requiresValidation) {
      const validateResponse = await fetch('https://api-dev.weir.ai/auth/validate/registration', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          otpSession: registerData.data.otpSession,
          otp: userData.otp
        })
      });
      
      const validateData = await validateResponse.json();
      
      if (!validateData.success) {
        throw new Error(validateData.error.message);
      }
    }
    
    return registerData.data;
  } catch (error) {
    console.error('User registration failed:', error);
    throw error;
  }
}
```

### 2. User Login Flow
```javascript
async function loginUser(credentials) {
  try {
    const response = await fetch('https://api-dev.weir.ai/auth/login', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(credentials)
    });
    
    if (!response.ok) {
      throw new Error(`Login failed: ${response.status}`);
    }
    
    const data = await response.json();
    
    if (!data.success) {
      throw new Error(data.error.message);
    }
    
    // Store tokens securely
    localStorage.setItem('accessToken', data.data.accessToken);
    localStorage.setItem('refreshToken', data.data.refreshToken);
    
    return data.data;
  } catch (error) {
    console.error('Login failed:', error);
    throw error;
  }
}
```

### 3. Token Management
```javascript
class TokenManager {
  constructor() {
    this.accessToken = localStorage.getItem('accessToken');
    this.refreshToken = localStorage.getItem('refreshToken');
  }
  
  async getValidToken() {
    if (!this.accessToken || this.isTokenExpired()) {
      await this.refreshAccessToken();
    }
    return this.accessToken;
  }
  
  async refreshAccessToken() {
    if (!this.refreshToken) {
      throw new Error('No refresh token available');
    }
    
    try {
      const response = await fetch('https://api-dev.weir.ai/auth/refresh/token', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          refreshToken: this.refreshToken
        })
      });
      
      if (!response.ok) {
        throw new Error('Token refresh failed');
      }
      
      const data = await response.json();
      
      if (!data.success) {
        throw new Error(data.error.message);
      }
      
      this.accessToken = data.data.accessToken;
      this.refreshToken = data.data.refreshToken;
      
      // Store new tokens
      localStorage.setItem('accessToken', this.accessToken);
      localStorage.setItem('refreshToken', this.refreshToken);
      
      return this.accessToken;
    } catch (error) {
      console.error('Token refresh failed:', error);
      // Clear invalid tokens
      this.clearTokens();
      throw error;
    }
  }
  
  isTokenExpired() {
    if (!this.accessToken) return true;
    
    try {
      const payload = JSON.parse(atob(this.accessToken.split('.')[1]));
      return Date.now() >= payload.exp * 1000;
    } catch (error) {
      return true;
    }
  }
  
  clearTokens() {
    this.accessToken = null;
    this.refreshToken = null;
    localStorage.removeItem('accessToken');
    localStorage.removeItem('refreshToken');
  }
}
```

## Error Handling

Authentication APIs return specific error codes:

| Code | Description | Solution |
|------|-------------|----------|
| `INVALID_CREDENTIALS` | Wrong username/password | Verify credentials |
| `ACCOUNT_NOT_FOUND` | User account doesn't exist | Check username/email |
| `ACCOUNT_LOCKED` | Account is temporarily locked | Contact support |
| `TOKEN_EXPIRED` | Access token has expired | Refresh the token |
| `INVALID_TOKEN` | Malformed or invalid token | Re-authenticate |
| `RATE_LIMIT_EXCEEDED` | Too many authentication attempts | Wait before retrying |

## Best Practices

### 1. Secure Token Storage
```javascript
// Store tokens securely
const secureStorage = {
  setToken: (token) => {
    // Use secure storage mechanism
    sessionStorage.setItem('weir_token', token);
  },
  
  getToken: () => {
    return sessionStorage.getItem('weir_token');
  },
  
  clearToken: () => {
    sessionStorage.removeItem('weir_token');
  }
};
```

### 2. Implement Automatic Token Refresh
```javascript
// Automatically refresh tokens before they expire
setInterval(async () => {
  if (tokenManager.isTokenExpired()) {
    try {
      await tokenManager.refreshAccessToken();
    } catch (error) {
      console.error('Token refresh failed:', error);
      // Redirect to login
      window.location.href = '/login';
    }
  }
}, 300000); // Check every 5 minutes
```

### 3. Handle Authentication Errors
```javascript
async function makeAuthenticatedRequest(url, options = {}) {
  try {
    const token = await tokenManager.getValidToken();
    
    const response = await fetch(url, {
      ...options,
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
    
    if (response.status === 401) {
      // Token expired, try to refresh
      try {
        await tokenManager.refreshAccessToken();
        // Retry the request
        return makeAuthenticatedRequest(url, options);
      } catch (error) {
        // Refresh failed, redirect to login
        window.location.href = '/login';
        throw error;
      }
    }
    
    return response;
  } catch (error) {
    console.error('Authenticated request failed:', error);
    throw error;
  }
}
```

## Security Considerations

<Callout type="warning">
**Important Security Notes:**

- Store tokens securely and never expose them in client-side code
- Implement proper session management and logout functionality
- Use HTTPS for all authentication requests
- Implement rate limiting to prevent brute force attacks
- Regularly rotate API keys and tokens
- Monitor authentication attempts for suspicious activity
</Callout>
