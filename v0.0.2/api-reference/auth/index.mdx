# Authentication APIs

Comprehensive authentication system supporting multiple methods and use cases for user registration, login, token management, and password recovery.

## Overview

Authentication APIs provide functionality for:
- User registration and account creation
- User login and authentication
- Token generation and refresh
- Password reset and recovery
- Account validation and verification
- Session management

## Available Endpoints

### External Authentication
- **Generate Access Token** - Create access tokens for external API authentication

### User Authentication
- **Login** - Authenticate users and generate access tokens
- **Logout** - End user sessions and invalidate tokens
- **Register** - Create new user accounts
- **Register (Mobile)** - Mobile-specific registration

### Token Management
- **Refresh Token** - Refresh expired access tokens
- **Validate Registration** - Validate email addresses after registration
- **Resend Registration OTP** - Resend verification codes

### Admin Authentication
- **Authenticate Admin** - Admin-level authentication
- **Create Admin** - Create new admin accounts

## Authentication Methods

### 1. API Key Authentication
For external integrations and third-party applications:

```bash
curl -X POST "https://api-dev.weir.ai/auth/token" \
  -u "your-client-id:your-secret-key"
```

### 2. User Authentication
For user-facing applications and web dashboards:

```bash
curl -X POST "https://api-dev.weir.ai/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username": "user@example.com", "password": "password"}'
```

### 3. Console Authentication
For internal console applications:

```bash
curl -X GET "https://api-dev.weir.ai/org/teams" \
  -H "Authorization: Bearer your-console-token" \
  -H "x-source: console"
```
