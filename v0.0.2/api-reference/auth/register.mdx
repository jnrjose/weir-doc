# User Registration

Register new users and create accounts within the Weir platform. This endpoint supports both individual user registration and organization creation during the registration process.

## Request

<RequestExample>
```bash
curl -X POST "https://api-dev.weir.ai/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "fullname": "John Doe",
    "email": "john@example.com",
    "password": "SecurePassword123!",
    "organization": {
      "name": "Example Corp",
      "type": "Platform",
      "description": "A business platform for NIL management"
    }
  }'
```

## Authentication

This endpoint does not require authentication. It is used to create new user accounts.

## Error Codes

| Code | Description | HTTP Status | Solution |
|------|-------------|-------------|----------|
| `EMAIL_ALREADY_EXISTS` | Email address is already registered | 409 | Use a different email or try logging in |
| `INVALID_EMAIL_FORMAT` | Email format is invalid | 400 | Provide a valid email address |
| `PASSWORD_TOO_WEAK` | Password doesn't meet requirements | 400 | Use a stronger password |
| `INVALID_ORGANIZATION_TYPE` | Organization type is not supported | 400 | Use a valid organization type |
| `ORGANIZATION_NAME_EXISTS` | Organization name is already taken | 409 | Choose a different organization name |
| `INVALID_REQUEST` | Malformed request body | 400 | Check request format and required fields |
| `RATE_LIMIT_EXCEEDED` | Too many registration attempts | 429 | Wait before retrying |
| `TERMS_NOT_ACCEPTED` | Terms and conditions not accepted | 400 | Accept terms and conditions |

## Rate Limits

- **3 registration attempts per hour** per IP address
- **1 registration attempt per day** per email address
- **10 registration attempts per hour** per IP address (burst limit)

<Callout type="warning">
Rate limits are enforced per IP address and email to prevent spam and abuse. Exceeding limits will result in a 429 status code with a `Retry-After` header.
</Callout>

## Validation Requirements

### Email Validation
- Must be a valid email format
- Must be unique across the platform
- Will receive a verification email after registration

### Password Requirements
- Minimum 8 characters
- Must contain at least one uppercase letter
- Must contain at least one lowercase letter
- Must contain at least one number
- Must contain at least one special character (!@#$%^&*)
- Cannot be a common password or dictionary word
- Cannot contain the user's name or email

### Organization Requirements
- Name must be unique across the platform
- Must be between 2 and 100 characters
- Cannot contain special characters except spaces and hyphens
- Type must be one of the supported values

## Usage Examples

### Basic Registration Flow

```javascript
async function registerUser(userData) {
  try {
    const response = await fetch('https://api-dev.weir.ai/auth/register', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(userData)
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const data = await response.json();
    
    if (data.data.requiresValidation) {
      // Show email verification step
      showEmailVerificationStep(data.data.otpSession);
    }
    
    return data.data;
  } catch (error) {
    console.error('Registration failed:', error);
    throw error;
  }
}
```

### Registration with Validation

```javascript
async function registerWithValidation(userData) {
  try {
    // Step 1: Register user
    const registerResponse = await fetch('https://api-dev.weir.ai/auth/register', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(userData)
    });
    
    const registerData = await registerResponse.json();
    
    if (!registerData.success) {
      throw new Error(registerData.error.message);
    }
    
    // Step 2: Validate email if required
    if (registerData.data.requiresValidation) {
      const otp = prompt('Please enter the verification code sent to your email:');
      
      const validateResponse = await fetch('https://api-dev.weir.ai/auth/validate/registration', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          otpSession: registerData.data.otpSession,
          otp: otp
        })
      });
      
      const validateData = await validateResponse.json();
      
      if (!validateData.success) {
        throw new Error(validateData.error.message);
      }
    }
    
    return registerData.data;
  } catch (error) {
    console.error('Registration failed:', error);
    throw error;
  }
}
```

### Registration with Error Handling

```javascript
async function registerWithErrorHandling(userData) {
  try {
    const response = await fetch('https://api-dev.weir.ai/auth/register', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(userData)
    });
    
    const data = await response.json();
    
    if (!data.success) {
      switch (data.error.code) {
        case 'EMAIL_ALREADY_EXISTS':
          throw new Error('An account with this email already exists. Please try logging in instead.');
        case 'PASSWORD_TOO_WEAK':
          throw new Error('Password is too weak. Please use a stronger password.');
        case 'INVALID_EMAIL_FORMAT':
          throw new Error('Please provide a valid email address.');
        case 'ORGANIZATION_NAME_EXISTS':
          throw new Error('Organization name is already taken. Please choose a different name.');
        case 'RATE_LIMIT_EXCEEDED':
          throw new Error('Too many registration attempts. Please wait before trying again.');
        default:
          throw new Error(data.error.message);
      }
    }
    
    return data.data;
  } catch (error) {
    console.error('Registration failed:', error);
    throw error;
  }
}
```

## Best Practices

### 1. Input Validation
```javascript
function validateRegistrationData(data) {
  const errors = [];
  
  // Validate email
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(data.email)) {
    errors.push('Please provide a valid email address');
  }
  
  // Validate password
  if (data.password.length < 8) {
    errors.push('Password must be at least 8 characters long');
  }
  
  if (!/(?=.*[a-z])/.test(data.password)) {
    errors.push('Password must contain at least one lowercase letter');
  }
  
  if (!/(?=.*[A-Z])/.test(data.password)) {
    errors.push('Password must contain at least one uppercase letter');
  }
  
  if (!/(?=.*\d)/.test(data.password)) {
    errors.push('Password must contain at least one number');
  }
  
  if (!/(?=.*[!@#$%^&*])/.test(data.password)) {
    errors.push('Password must contain at least one special character');
  }
  
  // Validate organization name
  if (data.organization.name.length < 2) {
    errors.push('Organization name must be at least 2 characters long');
  }
  
  if (data.organization.name.length > 100) {
    errors.push('Organization name must be less than 100 characters');
  }
  
  return errors;
}
```

### 2. Handle Email Verification
```javascript
class RegistrationManager {
  constructor() {
    this.otpSession = null;
    this.userData = null;
  }
  
  async register(userData) {
    try {
      const response = await fetch('https://api-dev.weir.ai/auth/register', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(userData)
      });
      
      const data = await response.json();
      
      if (!data.success) {
        throw new Error(data.error.message);
      }
      
      this.userData = data.data;
      
      if (data.data.requiresValidation) {
        this.otpSession = data.data.otpSession;
        this.showEmailVerificationStep();
      }
      
      return data.data;
    } catch (error) {
      console.error('Registration failed:', error);
      throw error;
    }
  }
  
  async verifyEmail(otp) {
    if (!this.otpSession) {
      throw new Error('No verification session found');
    }
    
    try {
      const response = await fetch('https://api-dev.weir.ai/auth/validate/registration', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          otpSession: this.otpSession,
          otp: otp
        })
      });
      
      const data = await response.json();
      
      if (!data.success) {
        throw new Error(data.error.message);
      }
      
      return data.data;
    } catch (error) {
      console.error('Email verification failed:', error);
      throw error;
    }
  }
  
  showEmailVerificationStep() {
    // Show email verification UI
    console.log('Please check your email for verification code');
  }
}
```

### 3. Progressive Registration
```javascript
class ProgressiveRegistration {
  constructor() {
    this.currentStep = 1;
    this.userData = {};
  }
  
  async step1(personalInfo) {
    // Validate personal information
    const errors = this.validatePersonalInfo(personalInfo);
    if (errors.length > 0) {
      throw new Error(errors.join(', '));
    }
    
    this.userData = { ...this.userData, ...personalInfo };
    this.currentStep = 2;
    
    return { step: 2, message: 'Personal information validated' };
  }
  
  async step2(organizationInfo) {
    // Validate organization information
    const errors = this.validateOrganizationInfo(organizationInfo);
    if (errors.length > 0) {
      throw new Error(errors.join(', '));
    }
    
    this.userData.organization = organizationInfo;
    this.currentStep = 3;
    
    return { step: 3, message: 'Organization information validated' };
  }
  
  async step3(termsAccepted) {
    if (!termsAccepted) {
      throw new Error('Terms and conditions must be accepted');
    }
    
    // Complete registration
    const result = await this.completeRegistration();
    this.currentStep = 4;
    
    return { step: 4, message: 'Registration completed', data: result };
  }
  
  async completeRegistration() {
    return await registerUser(this.userData);
  }
}
```
