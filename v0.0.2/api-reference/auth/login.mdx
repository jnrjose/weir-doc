# User Login

Authenticate users with their credentials and generate access tokens for API access. This endpoint supports both email and username authentication methods.

## Request

<RequestExample>
```bash
curl -X POST "https://api-dev.weir.ai/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "user@example.com",
    "password": "your-password"
  }'
```

```javascript
const response = await fetch('https://api-dev.weir.ai/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    username: 'user@example.com',
    password: 'your-password'
  })
});

const data = await response.json();
```

```python
import requests

response = requests.post(
    'https://api-dev.weir.ai/auth/login',
    json={
        'username': 'user@example.com',
        'password': 'your-password'
    }
)

data = response.json()
```

```php
<?php

```
</RequestExample>

## Authentication

This endpoint does not require authentication. It is used to obtain authentication tokens.

## Request Body

<RequestField name="username" type="string" required>
  The user's email address or username. Must be a valid email format if using email authentication.
</RequestField>

<RequestField name="password" type="string" required>
  The user's password. Must meet the organization's password requirements.
</RequestField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the login request was successful
</ResponseField>

<ResponseField name="data" type="object">
  The authentication data returned on successful login
</ResponseField>

<ResponseField name="data.accessToken" type="string">
  JWT access token for API authentication. Valid for 1 hour.
</ResponseField>

<ResponseField name="data.refreshToken" type="string">
  JWT refresh token for obtaining new access tokens. Valid for 30 days.
</ResponseField>

<ResponseField name="data.expiresIn" type="integer">
  Access token expiration time in seconds (3600 = 1 hour)
</ResponseField>

<ResponseField name="data.user" type="object">
  User information object
</ResponseField>

<ResponseField name="data.user.id" type="string">
  Unique user identifier
</ResponseField>

<ResponseField name="data.user.email" type="string">
  User's email address
</ResponseField>

<ResponseField name="data.user.role" type="string">
  User's role within the organization (e.g., "Organization_User", "Organization_Admin")
</ResponseField>

<ResponseField name="data.user.organizationId" type="string">
  ID of the user's organization
</ResponseField>

<ResponseField name="data.user.firstName" type="string">
  User's first name
</ResponseField>

<ResponseField name="data.user.lastName" type="string">

</ResponseField>

<ResponseField name="data.user.isEmailVerified" type="boolean">
  Whether the user's email address has been verified
</ResponseField>

<ResponseField name="data.user.lastLoginAt" type="string">
  ISO 8601 timestamp of the user's last login
</ResponseField>

<ResponseField name="message" type="string">

<ResponseField name="timestamp" type="string">

## Error Codes

| Code | Description | HTTP Status | Solution |
|------|-------------|-------------|----------|
| `INVALID_CREDENTIALS` | Wrong username or password | 401 | Verify credentials and try again |
| `ACCOUNT_NOT_FOUND` | User account doesn't exist | 404 | Check username/email spelling |
| `ACCOUNT_LOCKED` | Account is temporarily locked | 423 | Contact support or wait for unlock |
| `ACCOUNT_SUSPENDED` | Account has been suspended | 403 | Contact support for assistance |
| `EMAIL_NOT_VERIFIED` | Email address not verified | 403 | Verify email address first |
| `PASSWORD_EXPIRED` | Password has expired | 401 | Reset password |
| `TOO_MANY_ATTEMPTS` | Too many failed login attempts | 429 | Wait before retrying |
| `INVALID_REQUEST` | Malformed request body | 400 | Check request format and required fields |

## Rate Limits

- **5 requests per minute** per IP address
- **20 requests per hour** per username
- **100 requests per hour** per IP address

<Callout type="warning">
Rate limits are enforced per IP address and username to prevent brute force attacks. Exceeding limits will result in a 429 status code with a `Retry-After` header.
</Callout>

## Security Considerations

### Password Requirements
- Minimum 8 characters
- Must contain at least one uppercase letter
- Must contain at least one lowercase letter
- Must contain at least one number
- Must contain at least one special character
- Cannot be a common password or dictionary word

### Account Lockout Policy
- Account locks after 5 failed login attempts
- Lockout duration: 15 minutes
- Lockout resets after successful login
- Admin can manually unlock accounts

### Session Management
- Access tokens expire after 1 hour
- Refresh tokens expire after 30 days
- Tokens are invalidated on logout
- Multiple concurrent sessions are allowed

## Usage Examples

### Basic Login Flow

```javascript
async function loginUser(username, password) {
  try {
    const response = await fetch('https://api-dev.weir.ai/auth/login', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ username, password })
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const data = await response.json();
    
    // Store tokens securely
    localStorage.setItem('accessToken', data.data.accessToken);
    localStorage.setItem('refreshToken', data.data.refreshToken);
    localStorage.setItem('user', JSON.stringify(data.data.user));
    
    return data.data;
  } catch (error) {
    console.error('Login failed:', error);
    throw error;
  }
}
```

### Login with Error Handling

```javascript
async function loginWithErrorHandling(username, password) {
  try {
    const response = await fetch('https://api-dev.weir.ai/auth/login', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ username, password })
    });
    
    const data = await response.json();
    
    if (!data.success) {
      switch (data.error.code) {
        case 'INVALID_CREDENTIALS':
          throw new Error('Invalid username or password');
        case 'ACCOUNT_LOCKED':
          throw new Error('Account is temporarily locked. Please try again later.');
        case 'ACCOUNT_SUSPENDED':
          throw new Error('Account has been suspended. Please contact support.');
        case 'EMAIL_NOT_VERIFIED':
          throw new Error('Please verify your email address before logging in.');
        case 'TOO_MANY_ATTEMPTS':
          throw new Error('Too many failed attempts. Please wait before trying again.');
        default:
          throw new Error(data.error.message);
      }
    }
    
    return data.data;
  } catch (error) {
    console.error('Login failed:', error);
    throw error;
  }
}
```

### Login with Retry Logic

```javascript
async function loginWithRetry(username, password, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      const response = await fetch('https://api-dev.weir.ai/auth/login', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({ username, password })
      });
      
      if (response.status === 429) {
        const retryAfter = response.headers.get('Retry-After') || 60;
        console.log(`Rate limited. Retrying after ${retryAfter} seconds...`);
        await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
        continue;
      }
      
      const data = await response.json();
      
      if (!data.success) {
        throw new Error(data.error.message);
      }
      
      return data.data;
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await new Promise(resolve => setTimeout(resolve, 1000 * Math.pow(2, i)));
    }
  }
}
```

## Best Practices

### 1. Secure Token Storage
```javascript
// Store tokens securely
const secureStorage = {
  setToken: (token) => {
    // Use secure storage mechanism
    sessionStorage.setItem('weir_token', token);
  },
  
  getToken: () => {
    return sessionStorage.getItem('weir_token');
  },
  
  clearToken: () => {
    sessionStorage.removeItem('weir_token');
  }
};
```

### 2. Implement Automatic Token Refresh
```javascript
// Automatically refresh tokens before they expire
setInterval(async () => {
  if (tokenManager.isTokenExpired()) {
    try {
      await tokenManager.refreshAccessToken();
    } catch (error) {
      console.error('Token refresh failed:', error);
      // Redirect to login
      window.location.href = '/login';
    }
  }
}, 300000); // Check every 5 minutes
```

### 3. Handle Login State
```javascript
class AuthManager {
  constructor() {
    this.isLoggedIn = false;
    this.user = null;
    this.accessToken = null;
    this.refreshToken = null;
  }
  
  async login(username, password) {
    try {
      const data = await loginUser(username, password);
      
      this.isLoggedIn = true;
      this.user = data.user;
      this.accessToken = data.accessToken;
      this.refreshToken = data.refreshToken;
      
      // Emit login event
      this.emit('login', data);
      
      return data;
    } catch (error) {
      this.emit('loginError', error);
      throw error;
    }
  }
  
  logout() {
    this.isLoggedIn = false;
    this.user = null;
    this.accessToken = null;
    this.refreshToken = null;
    
    // Clear stored tokens
    secureStorage.clearToken();
    
    // Emit logout event
    this.emit('logout');
  }
}
```
