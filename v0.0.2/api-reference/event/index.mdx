# Event & Logging APIs

APIs for event tracking, logging, and monitoring within the Weir platform, providing comprehensive visibility into system operations and user activities.

## Overview

Event & Logging APIs provide functionality for:
- Event tracking and logging
- System monitoring and analytics
- Error tracking and debugging
- Performance monitoring
- Audit logging and compliance

## Available Endpoints

### Log Management
- **Create Log Entry** - Create new log entries and events
- **Search Log Entries** - Search and filter log entries
- **Get Log Entries** - Retrieve all log entries

### Event Tracking
- **Track Events** - Record system and user events
- **Monitor Performance** - Track system performance metrics
- **Audit Logging** - Maintain audit trails for compliance

## Authentication

Event & Logging APIs use Bearer token authentication:

```bash
curl -X POST "https://api-dev.weir.ai/logs/log" \
  -H "Authorization: Bearer your-access-token" \
  -H "Content-Type: application/json"
```

## Log Types

### System Logs
- Application errors and exceptions
- System performance metrics
- Infrastructure monitoring data

### User Activity Logs
- User authentication events
- API usage tracking
- Feature access logs

### Security Logs
- Authentication failures
- Authorization violations
- Security-related events

## Search and Filtering

### Query Parameters
- **type** - Filter by log type (INFO, WARNING, ERROR)
- **scheme** - Filter by log scheme
- **searchTerm** - Search within log messages
- **startDate/endDate** - Filter by date range
- **page/limit** - Pagination controls

### Example Search
```bash
curl -X GET "https://api-dev.weir.ai/logs/search?type=ERROR&startDate=2024-01-01&endDate=2024-01-31" \
  -H "Authorization: Bearer your-access-token"
```
