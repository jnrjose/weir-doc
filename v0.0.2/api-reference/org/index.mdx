# Organization APIs

Comprehensive APIs for managing organizations, teams, clients, platforms, and talent rosters within the Weir ecosystem.

## Overview

Organization APIs provide functionality for:
- Organization management and configuration
- Team creation and member management
- Client and platform administration
- Talent roster and license management
- Card and payment management
- Platform verification and monitoring

## Available Endpoints

### Organization Management
- Get Org Info
- Update Org Info
- Get Cards
- Add Card
- Delete Card

### Team Management
- Create Team
- Get Teams
- Invite Team Member
- Get Team Members
- Delete Team

### Platform Management
- Create Platform
- Get Platforms
- Delete Platform
- Verify Platform

### Client Management
- Create Client
- Get Clients
- Refresh Client
- Delete Client

### Talent Management
- Get Agency Talent Roster
- Invite Talent to Agency
- Search for Agency Talent
- Get Talent Licenses
- Create License by Agency

## Authentication

Organization APIs support multiple authentication methods:

### Console Authentication
```bash
curl -X GET "https://api-dev.weir.ai/org/information" \
  -H "Authorization: Bearer your-console-token" \
  -H "x-source: console"
```

### Bearer Token Authentication
```bash
curl -X GET "https://api-dev.weir.ai/org/teams" \
  -H "Authorization: Bearer your-access-token"
```
