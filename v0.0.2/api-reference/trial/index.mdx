# Trial APIs

APIs designed for trial users and testing features, allowing users to explore Weir's capabilities before committing to a full subscription.

## Overview

Trial APIs provide functionality for:
- Trial user registration and authentication
- Testing NIL detection features
- Uploading and analyzing images
- Managing trial users and data
- Exploring platform capabilities

## Authentication

Trial APIs use Bearer token authentication:

```bash
curl -X GET "https://api-dev.weir.ai/trial/users" \
  -H "Authorization: Bearer your-trial-token"
```

## Rate Limits

Trial APIs have the following rate limits:
- **100 requests per hour** per trial user
- **10 requests per minute** burst limit
- **5 concurrent requests** maximum

<Callout type="info">
Trial APIs have lower rate limits to encourage users to upgrade to full subscriptions.
</Callout>

## Common Use Cases

### 1. Trial User Registration
```javascript
async function registerTrialUser(userData) {
  try {
    const response = await fetch('https://api-dev.weir.ai/trial/register', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(userData)
    });
    
    if (!response.ok) {
      throw new Error(`Registration failed: ${response.status}`);
    }
    
    const data = await response.json();
    
    if (!data.success) {
      throw new Error(data.error.message);
    }
    
    return data.data;
  } catch (error) {
    console.error('Trial registration failed:', error);
    throw error;
  }
}
```

### 2. Image Upload and Analysis
```javascript
async function uploadImageForAnalysis(imageFile) {
  try {
    const formData = new FormData();
    formData.append('image', imageFile);
    
    const response = await fetch('https://api-dev.weir.ai/trial/uploadImage', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${trialToken}`
      },
      body: formData
    });
    
    if (!response.ok) {
      throw new Error(`Upload failed: ${response.status}`);
    }
    
    const data = await response.json();
    
    if (!data.success) {
      throw new Error(data.error.message);
    }
    
    return data.data;
  } catch (error) {
    console.error('Image upload failed:', error);
    throw error;
  }
}
```

## Error Handling

Trial APIs return specific error codes:

| Code | Description | Solution |
|------|-------------|----------|
| `TRIAL_LIMIT_EXCEEDED` | Trial usage limit exceeded | Upgrade to full subscription |
| `INVALID_IMAGE_FORMAT` | Unsupported image format | Use supported formats (JPEG, PNG) |
| `IMAGE_TOO_LARGE` | Image file too large | Reduce image size |
| `TRIAL_EXPIRED` | Trial period has expired | Upgrade to full subscription |
| `INSUFFICIENT_CREDITS` | Not enough trial credits | Wait for credit refresh or upgrade |

## Best Practices

### 1. Implement Usage Monitoring
```javascript
class TrialUsageMonitor {
  constructor() {
    this.usage = {
      requests: 0,
      images: 0,
      startTime: Date.now()
    };
  }
  
  trackRequest() {
    this.usage.requests++;
    this.checkLimits();
  }
  
  trackImageUpload() {
    this.usage.images++;
    this.checkLimits();
  }
  
  checkLimits() {
    const hourlyLimit = 100;
    const imageLimit = 50;
    
    if (this.usage.requests >= hourlyLimit) {
      throw new Error('Trial request limit exceeded');
    }
    
    if (this.usage.images >= imageLimit) {
      throw new Error('Trial image upload limit exceeded');
    }
  }
  
  getUsageStats() {
    return {
      ...this.usage,
      timeElapsed: Date.now() - this.usage.startTime
    };
  }
}
```

### 2. Handle Image Validation
```javascript
function validateImageFile(file) {
  const maxSize = 10 * 1024 * 1024; // 10MB
  const allowedTypes = ['image/jpeg', 'image/png', 'image/webp'];
  
  if (file.size > maxSize) {
    throw new Error('Image file too large. Maximum size is 10MB.');
  }
  
  if (!allowedTypes.includes(file.type)) {
    throw new Error('Unsupported image format. Please use JPEG, PNG, or WebP.');
  }
  
  return true;
}
```

### 3. Implement Upgrade Prompts
```javascript
function showUpgradePrompt(reason) {
  const upgradeModal = document.createElement('div');
  upgradeModal.innerHTML = `
    <div class="upgrade-modal">
      <h3>Trial Limit Reached</h3>
      <p>${reason}</p>
      <p>Upgrade to continue using Weir's full features.</p>
      <button onclick="upgradeToFull()">Upgrade Now</button>
      <button onclick="closeModal()">Maybe Later</button>
    </div>
  `;
  
  document.body.appendChild(upgradeModal);
}

function upgradeToFull() {
  window.location.href = '/upgrade';
}
```
