# Trial APIs

APIs designed for trial users and testing features, allowing users to explore Weir's capabilities before committing to a full subscription.

## Overview

Trial APIs provide functionality for:
- Trial user registration and authentication
- Testing NIL detection features
- Uploading and analyzing images
- Managing trial users and data
- Exploring platform capabilities

## Available Endpoints

### Trial Registration
- **Register** - Create new trial accounts
- **Authenticate** - Authenticate trial users

### User Management
- **Get Users** - Retrieve trial users
- **Get User** - Get specific trial user details

### Image Processing
- **Upload Image** - Upload images for analysis
- **Upload Selfie** - Upload selfie images
- **Get Selfie** - Retrieve selfie analysis

### Fake Ad Generation
- **Get Fake Ads** - Retrieve generated fake ads
- **Get Fake Ad** - Get specific fake ad details

## Authentication

Trial APIs use Bearer token authentication:

```bash
curl -X GET "https://api-dev.weir.ai/trial/users" \
  -H "Authorization: Bearer your-trial-token"
```

## Getting Started

1. Register for a trial account
2. Authenticate to get your trial token
3. Upload images for analysis
4. Explore the platform capabilities
5. Upgrade to a full subscription when ready
