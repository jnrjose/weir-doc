# Ad Detection APIs

APIs for NIL (Name, Image, Likeness) detection and identity verification, providing advanced AI-powered analysis of celebrity images and likenesses.

## Overview

Ad Detection APIs provide functionality for:
- NIL detection and analysis
- Identity verification and validation
- Celebrity image recognition
- Unauthorized usage detection
- Content monitoring and analysis

## Authentication

Ad Detection APIs use Bearer token authentication:

```bash
curl -X POST "https://api-dev.weir.ai/ad/validateIdentity" \
  -H "Authorization: Bearer your-access-token" \
  -H "Content-Type: application/json"
```

## Rate Limits

Ad Detection APIs have the following rate limits:
- **500 requests per hour** per API key
- **50 requests per minute** burst limit
- **10 concurrent requests** maximum

## Common Use Cases

### 1. Identity Validation
```javascript
async function validateIdentity(imageData) {
  try {
    const response = await fetch('https://api-dev.weir.ai/ad/validateIdentity', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(imageData)
    });
    
    if (!response.ok) {
      throw new Error(`Validation failed: ${response.status}`);
    }
    
    const data = await response.json();
    
    if (!data.success) {
      throw new Error(data.error.message);
    }
    
    return data.data;
  } catch (error) {
    console.error('Identity validation failed:', error);
    throw error;
  }
}
```

### 2. NIL Detection Analysis
```javascript
async function detectNILViolations(imageUrl) {
  try {
    const response = await fetch('https://api-dev.weir.ai/ad/nilDetection', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        imageUrl: imageUrl,
        analysisType: 'comprehensive'
      })
    });
    
    if (!response.ok) {
      throw new Error(`NIL detection failed: ${response.status}`);
    }
    
    const data = await response.json();
    
    if (!data.success) {
      throw new Error(data.error.message);
    }
    
    return data.data;
  } catch (error) {
    console.error('NIL detection failed:', error);
    throw error;
  }
}
```

### 3. Batch Image Analysis
```javascript
async function analyzeBatchImages(imageUrls) {
  const results = [];
  
  for (const imageUrl of imageUrls) {
    try {
      const result = await detectNILViolations(imageUrl);
      results.push({
        imageUrl,
        result,
        status: 'success'
      });
    } catch (error) {
      results.push({
        imageUrl,
        error: error.message,
        status: 'error'
      });
    }
    
    // Add delay to respect rate limits
    await new Promise(resolve => setTimeout(resolve, 1000));
  }
  
  return results;
}
```

## Error Handling

Ad Detection APIs return specific error codes:

| Code | Description | Solution |
|------|-------------|----------|
| `INVALID_IMAGE_FORMAT` | Unsupported image format | Use supported formats (JPEG, PNG, WebP) |
| `IMAGE_TOO_LARGE` | Image file too large | Reduce image size |
| `ANALYSIS_FAILED` | AI analysis failed | Retry with different image |
| `RATE_LIMIT_EXCEEDED` | Too many analysis requests | Wait before retrying |
| `INSUFFICIENT_CREDITS` | Not enough analysis credits | Check account balance |

## Best Practices

### 1. Image Preprocessing
```javascript
function preprocessImage(file) {
  return new Promise((resolve, reject) => {
    const canvas = document.createElement('canvas');
    const ctx = canvas.getContext('2d');
    const img = new Image();
    
    img.onload = () => {
      // Resize image if too large
      const maxSize = 2048;
      let { width, height } = img;
      
      if (width > maxSize || height > maxSize) {
        const ratio = Math.min(maxSize / width, maxSize / height);
        width *= ratio;
        height *= ratio;
      }
      
      canvas.width = width;
      canvas.height = height;
      
      ctx.drawImage(img, 0, 0, width, height);
      
      canvas.toBlob(resolve, 'image/jpeg', 0.9);
    };
    
    img.onerror = reject;
    img.src = URL.createObjectURL(file);
  });
}
```

### 2. Implement Caching
```javascript
class AdDetectionCache {
  constructor(ttl = 3600000) { // 1 hour
    this.cache = new Map();
    this.ttl = ttl;
  }
  
  getCacheKey(imageUrl, analysisType) {
    return `${imageUrl}_${analysisType}`;
  }
  
  get(imageUrl, analysisType) {
    const key = this.getCacheKey(imageUrl, analysisType);
    const item = this.cache.get(key);
    
    if (item && Date.now() - item.timestamp < this.ttl) {
      return item.data;
    }
    
    this.cache.delete(key);
    return null;
  }
  
  set(imageUrl, analysisType, data) {
    const key = this.getCacheKey(imageUrl, analysisType);
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
  }
}
```

### 3. Handle Analysis Results
```javascript
function processAnalysisResult(result) {
  const {
    confidence,
    celebrity,
    violation,
    recommendations
  } = result;
  
  if (confidence > 0.8) {
    if (violation.detected) {
      return {
        status: 'violation',
        message: `Unauthorized use of ${celebrity.name} detected`,
        confidence,
        recommendations
      };
    } else {
      return {
        status: 'clean',
        message: 'No violations detected',
        confidence
      };
    }
  } else {
    return {
      status: 'uncertain',
      message: 'Analysis inconclusive',
      confidence,
      recommendations: ['Manual review recommended']
    };
  }
}
```
