# Invite Team Member

Invite a new member to an existing team within your organization. The invited user will receive an email invitation and must accept it to join the team.

## Request

<RequestExample>

  -d '{
    "firstname": "John",

    "email": "john.doe@example.com",

## Authentication

This endpoint requires console authentication with the following headers:

- `Authorization: Bearer your-console-token`
- `x-source: console`

## Path Parameters

<RequestField name="teamId" type="string" required>
  The unique identifier of the team to invite the member to. Must be a valid team ID that exists in your organization.
</RequestField>

## Request Body

<RequestField name="firstname" type="string" required>
  The first name of the person being invited. Must be between 1 and 50 characters.
</RequestField>

<RequestField name="lastname" type="string" required>
  The last name of the person being invited. Must be between 1 and 50 characters.
</RequestField>

<RequestField name="email" type="string" required>
  The email address of the person being invited. Must be a valid email format and will be used to send the invitation.
</RequestField>

<RequestField name="role" type="string" required>
  The role to assign to the invited member. Must be one of:
  - `Organization_User` - Standard user with basic permissions
  - `Organization_Admin` - Administrative user with full permissions
  - `Team_Manager` - Team manager with team-specific permissions
  - `Team_Member` - Team member with limited permissions
</RequestField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the invitation request was successful
</ResponseField>

<ResponseField name="data" type="object">
  The invitation data returned on successful invitation
</ResponseField>

<ResponseField name="data.invitationId" type="string">
  Unique identifier for the invitation
</ResponseField>

<ResponseField name="data.teamId" type="string">
  ID of the team the user was invited to
</ResponseField>

<ResponseField name="data.email" type="string">
  Email address of the invited user
</ResponseField>

<ResponseField name="data.role" type="string">
  Role assigned to the invited user
</ResponseField>

<ResponseField name="data.status" type="string">
  Status of the invitation (always "pending" for new invitations)
</ResponseField>

<ResponseField name="data.invitedBy" type="string">
  ID of the user who sent the invitation
</ResponseField>

<ResponseField name="data.invitedAt" type="string">
  ISO 8601 timestamp of when the invitation was sent
</ResponseField>

<ResponseField name="data.expiresAt" type="string">
  ISO 8601 timestamp of when the invitation expires (7 days from invitation)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable message about the operation result
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the response
</ResponseField>

## Error Codes

| Code | Description | HTTP Status | Solution |
|------|-------------|-------------|----------|
| `TEAM_NOT_FOUND` | Team ID doesn't exist | 404 | Verify the team ID is correct |
| `EMAIL_ALREADY_INVITED` | User already invited to team | 409 | Check if invitation is already pending |
| `EMAIL_ALREADY_MEMBER` | User is already a team member | 409 | User is already part of the team |
| `INVALID_EMAIL_FORMAT` | Email format is invalid | 400 | Provide a valid email address |
| `INVALID_ROLE` | Role is not supported | 400 | Use a valid role from the allowed list |
| `INSUFFICIENT_PERMISSIONS` | User lacks permission to invite members | 403 | Check user role and permissions |
| `RATE_LIMIT_EXCEEDED` | Too many invitation requests | 429 | Wait before retrying |
| `INVALID_REQUEST` | Malformed request body | 400 | Check request format and required fields |

## Rate Limits

- **10 invitation requests per hour** per user
- **50 invitation requests per hour** per team
- **100 invitation requests per hour** per organization

<Callout type="warning">
Rate limits are enforced per user, team, and organization. Exceeding limits will result in a 429 status code with a `Retry-After` header.
</Callout>

## Validation Rules

### Email Requirements
- Must be a valid email format
- Must be unique within the team (no duplicate invitations)
- User must not already be a team member

### Name Requirements
- First name: 1-50 characters, letters and spaces only
- Last name: 1-50 characters, letters and spaces only
- Cannot be empty or contain special characters

### Role Requirements
- Must be one of the supported role values
- User must have permission to assign the specified role
- Role must be appropriate for the team context

## Usage Examples

### Basic Team Member Invitation

```javascript
async function inviteTeamMember(teamId, memberData) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/invite/team/member/${teamId}`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(memberData)
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const data = await response.json();
    return data.data;
  } catch (error) {
    console.error('Failed to invite team member:', error);
    throw error;
  }
}

// Usage
inviteTeamMember('team-123', {
  firstname: 'John',
  lastname: 'Doe',
  email: 'john.doe@example.com',
  role: 'Organization_User'
})
  .then(invitation => {
    console.log('Invitation sent:', invitation.invitationId);
  })
  .catch(error => {
    console.error('Invitation failed:', error);
  });
```

### Invitation with Validation

```javascript
function validateInvitationData(data) {
  const errors = [];
  
  // Validate email
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(data.email)) {
    errors.push('Please provide a valid email address');
  }
  
  // Validate names
  if (!data.firstname || data.firstname.trim().length === 0) {
    errors.push('First name is required');
  }
  
  if (!data.lastname || data.lastname.trim().length === 0) {
    errors.push('Last name is required');
  }
  
  // Validate role
  const validRoles = ['Organization_User', 'Organization_Admin', 'Team_Manager', 'Team_Member'];
  if (!validRoles.includes(data.role)) {
    errors.push('Please select a valid role');
  }
  
  return errors;
}

async function inviteTeamMemberWithValidation(teamId, memberData) {
  // Validate input data
  const errors = validateInvitationData(memberData);
  if (errors.length > 0) {
    throw new Error(errors.join(', '));
  }
  
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/invite/team/member/${teamId}`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(memberData)
    });
    
    const data = await response.json();
    
    if (!data.success) {
      throw new Error(data.error.message);
    }
    
    return data.data;
  } catch (error) {
    console.error('Failed to invite team member:', error);
    throw error;
  }
}
```

### Bulk Team Invitations

```javascript
async function inviteMultipleTeamMembers(teamId, members) {
  const results = [];
  const errors = [];
  
  for (const member of members) {
    try {
      const invitation = await inviteTeamMemberWithValidation(teamId, member);
      results.push({
        email: member.email,
        invitation: invitation,
        status: 'success'
      });
    } catch (error) {
      errors.push({
        email: member.email,
        error: error.message,
        status: 'error'
      });
    }
    
    // Add delay to respect rate limits
    await new Promise(resolve => setTimeout(resolve, 1000));
  }
  
  return {
    successful: results,
    failed: errors,
    summary: {
      total: members.length,
      successful: results.length,
      failed: errors.length
    }
  };
}

// Usage
const members = [
  {
    firstname: 'John',
    lastname: 'Doe',
    email: 'john.doe@example.com',
    role: 'Organization_User'
  },
  {
    firstname: 'Jane',
    lastname: 'Smith',
    email: 'jane.smith@example.com',
    role: 'Team_Manager'
  }
];

inviteMultipleTeamMembers('team-123', members)
  .then(result => {
    console.log(`Successfully invited ${result.successful.length} members`);
    console.log(`Failed to invite ${result.failed.length} members`);
  });
```

## Best Practices

### 1. Invitation Management
```javascript
class TeamInvitationManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async inviteMember(teamId, memberData) {
    return await this.apiClient.makeRequest(`/org/invite/team/member/${teamId}`, {
      method: 'POST',
      body: JSON.stringify(memberData)
    });
  }
  
  async getPendingInvitations(teamId) {
    return await this.apiClient.makeRequest(`/org/team/invitations/${teamId}`);
  }
  
  async cancelInvitation(invitationId) {
    return await this.apiClient.makeRequest(`/org/invitation/${invitationId}`, {
      method: 'DELETE'
    });
  }
  
  async resendInvitation(invitationId) {
    return await this.apiClient.makeRequest(`/org/invitation/${invitationId}/resend`, {
      method: 'POST'
    });
  }
}
```

### 2. Role-Based Invitations
```javascript
class RoleBasedInvitation {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async inviteWithRole(teamId, memberData, inviterRole) {
    // Check if inviter has permission to assign the role
    if (!this.canAssignRole(inviterRole, memberData.role)) {
      throw new Error('You do not have permission to assign this role');
    }
    
    return await this.apiClient.makeRequest(`/org/invite/team/member/${teamId}`, {
      method: 'POST',
      body: JSON.stringify(memberData)
    });
  }
  
  canAssignRole(inviterRole, targetRole) {
    const roleHierarchy = {
      'Organization_Admin': ['Organization_User', 'Team_Manager', 'Team_Member'],
      'Team_Manager': ['Team_Member'],
      'Team_Member': [],
      'Organization_User': []
    };
    
    return roleHierarchy[inviterRole]?.includes(targetRole) || false;
  }
}
```

### 3. Invitation Tracking
```javascript
class InvitationTracker {
  constructor() {
    this.pendingInvitations = new Map();
  }
  
  async trackInvitation(teamId, memberData) {
    const invitation = await this.inviteMember(teamId, memberData);
    
    this.pendingInvitations.set(invitation.invitationId, {
      ...invitation,
      teamId,
      memberData,
      status: 'pending'
    });
    
    return invitation;
  }
  
  getPendingInvitations() {
    return Array.from(this.pendingInvitations.values());
  }
  
  removeInvitation(invitationId) {
    this.pendingInvitations.delete(invitationId);
  }
}
```
