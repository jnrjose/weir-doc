# Delete Team

Delete an existing team from your organization. This action is irreversible and will remove the team along with all its members, permissions, and associated data.

<Callout type="warning">
**Warning**: This action is permanent and cannot be undone. All team data, member associations, and permissions will be permanently deleted.
</Callout>

## Authentication

This endpoint requires console authentication with the following headers:

- `Authorization: Bearer your-console-token`
- `x-source: console`

## Path Parameters

<RequestField name="teamId" type="string" required>
  The unique identifier of the team to delete. Must be a valid team ID that exists in your organization.
</RequestField>

## Error Codes

| Code | Description | HTTP Status | Solution |
|------|-------------|-------------|----------|
| `TEAM_NOT_FOUND` | Team ID doesn't exist | 404 | Verify the team ID is correct |
| `INSUFFICIENT_PERMISSIONS` | User lacks permission to delete teams | 403 | Check user role and permissions |
| `TEAM_HAS_ACTIVE_MEMBERS` | Team has active members that need to be removed first | 409 | Remove all members before deleting team |
| `TEAM_HAS_ACTIVE_PROJECTS` | Team has active projects that need to be reassigned | 409 | Reassign or complete projects before deleting |
| `TEAM_IS_SYSTEM_TEAM` | Cannot delete system-required teams | 403 | System teams cannot be deleted |
| `RATE_LIMIT_EXCEEDED` | Too many deletion requests | 429 | Wait before retrying |
| `INVALID_REQUEST` | Malformed request | 400 | Check request format |

## Rate Limits

- **5 team deletion requests per hour** per user
- **20 team deletion requests per hour** per organization
- **50 team deletion requests per hour** per IP address

<Callout type="warning">
Rate limits are stricter for deletion operations to prevent accidental mass deletions. Exceeding limits will result in a 429 status code with a `Retry-After` header.
</Callout>

## Prerequisites

Before deleting a team, ensure:

1. **All members are removed** or reassigned to other teams
2. **All active projects** are completed or reassigned
3. **All permissions** are properly handled
4. **Backup important data** if needed
5. **Notify team members** about the deletion

## Usage Examples

### Basic Team Deletion

```javascript
async function deleteTeam(teamId) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/team/${teamId}`, {
      method: 'DELETE',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console'
      }
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const data = await response.json();
    return data.data;
  } catch (error) {
    console.error('Failed to delete team:', error);
    throw error;
  }
}

// Usage
deleteTeam('team-123')
  .then(result => {
    console.log(`Team "${result.teamName}" deleted successfully`);
    console.log(`Removed ${result.membersRemoved} members`);
  })
  .catch(error => {
    console.error('Failed to delete team:', error);
  });
```

### Safe Team Deletion with Validation

```javascript
async function safeDeleteTeam(teamId) {
  try {
    // Step 1: Get team information
    const teamInfo = await getTeamInfo(teamId);
    
    if (!teamInfo) {
      throw new Error('Team not found');
    }
    
    // Step 2: Check if team has active members
    const members = await getTeamMembers(teamId);
    if (members.length > 0) {
      throw new Error(`Cannot delete team with ${members.length} active members. Please remove all members first.`);
    }
    
    // Step 3: Check if team has active projects
    const projects = await getTeamProjects(teamId);
    if (projects.length > 0) {
      throw new Error(`Cannot delete team with ${projects.length} active projects. Please reassign or complete projects first.`);
    }
    
    // Step 4: Confirm deletion
    const confirmed = confirm(`Are you sure you want to delete team "${teamInfo.name}"? This action cannot be undone.`);
    if (!confirmed) {
      throw new Error('Deletion cancelled by user');
    }
    
    // Step 5: Delete the team
    const result = await deleteTeam(teamId);
    
    return result;
  } catch (error) {
    console.error('Safe team deletion failed:', error);
    throw error;
  }
}
```

### Team Deletion with Error Handling

```javascript
async function deleteTeamWithErrorHandling(teamId) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/team/${teamId}`, {
      method: 'DELETE',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console'
      }
    });
    
    const data = await response.json();
    
    if (!data.success) {
      switch (data.error.code) {
        case 'TEAM_NOT_FOUND':
          throw new Error('Team not found. Please check the team ID.');
        case 'INSUFFICIENT_PERMISSIONS':
          throw new Error('You do not have permission to delete teams.');
        case 'TEAM_HAS_ACTIVE_MEMBERS':
          throw new Error('Cannot delete team with active members. Please remove all members first.');
        case 'TEAM_HAS_ACTIVE_PROJECTS':
          throw new Error('Cannot delete team with active projects. Please reassign projects first.');
        case 'TEAM_IS_SYSTEM_TEAM':
          throw new Error('System teams cannot be deleted.');
        case 'RATE_LIMIT_EXCEEDED':
          throw new Error('Too many deletion requests. Please wait before trying again.');
        default:
          throw new Error(data.error.message);
      }
    }
    
    return data.data;
  } catch (error) {
    console.error('Failed to delete team:', error);
    throw error;
  }
}
```

### Bulk Team Deletion with Confirmation

```javascript
async function bulkDeleteTeams(teamIds) {
  const results = [];
  const errors = [];
  
  for (const teamId of teamIds) {
    try {
      // Get team info for confirmation
      const teamInfo = await getTeamInfo(teamId);
      if (!teamInfo) {
        errors.push({
          teamId,
          error: 'Team not found',
          status: 'error'
        });
        continue;
      }
      
      // Confirm deletion for each team
      const confirmed = confirm(`Delete team "${teamInfo.name}"? This action cannot be undone.`);
      if (!confirmed) {
        errors.push({
          teamId,
          teamName: teamInfo.name,
          error: 'Deletion cancelled by user',
          status: 'cancelled'
        });
        continue;
      }
      
      // Delete the team
      const result = await deleteTeam(teamId);
      results.push({
        teamId,
        teamName: result.teamName,
        result: result,
        status: 'success'
      });
      
      // Add delay between deletions
      await new Promise(resolve => setTimeout(resolve, 2000));
      
    } catch (error) {
      errors.push({
        teamId,
        error: error.message,
        status: 'error'
      });
    }
  }
  
  return {
    successful: results,
    failed: errors,
    summary: {
      total: teamIds.length,
      successful: results.length,
      failed: errors.length,
      cancelled: errors.filter(e => e.status === 'cancelled').length
    }
  };
}
```

## Best Practices

### 1. Team Deletion Workflow
```javascript
class TeamDeletionWorkflow {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async deleteTeam(teamId, options = {}) {
    const steps = [
      () => this.validateTeamExists(teamId),
      () => this.checkTeamMembers(teamId),
      () => this.checkTeamProjects(teamId),
      () => this.confirmDeletion(teamId, options),
      () => this.executeDeletion(teamId),
      () => this.cleanupTeamData(teamId)
    ];
    
    for (const step of steps) {
      try {
        await step();
      } catch (error) {
        throw new Error(`Team deletion failed at step: ${error.message}`);
      }
    }
  }
  
  async validateTeamExists(teamId) {
    const team = await this.apiClient.makeRequest(`/org/team/${teamId}`);
    if (!team) {
      throw new Error('Team not found');
    }
    return team;
  }
  
  async checkTeamMembers(teamId) {
    const members = await this.apiClient.makeRequest(`/org/team/members/${teamId}`);
    if (members.items.length > 0) {
      throw new Error(`Team has ${members.items.length} active members`);
    }
  }
  
  async checkTeamProjects(teamId) {
    // Check for active projects
    const projects = await this.apiClient.makeRequest(`/org/team/projects/${teamId}`);
    if (projects.items.length > 0) {
      throw new Error(`Team has ${projects.items.length} active projects`);
    }
  }
  
  async confirmDeletion(teamId, options) {
    if (options.skipConfirmation) return;
    
    const confirmed = confirm(`Are you sure you want to delete this team?`);
    if (!confirmed) {
      throw new Error('Deletion cancelled by user');
    }
  }
  
  async executeDeletion(teamId) {
    return await this.apiClient.makeRequest(`/org/team/${teamId}`, {
      method: 'DELETE'
    });
  }
  
  async cleanupTeamData(teamId) {
    // Additional cleanup if needed
    console.log(`Cleaning up data for team ${teamId}`);
  }
}
```

### 2. Team Deletion Audit
```javascript
class TeamDeletionAudit {
  constructor() {
    this.deletions = [];
  }
  
  logDeletion(teamId, teamName, deletedBy, details) {
    const deletion = {
      teamId,
      teamName,
      deletedBy,
      deletedAt: new Date().toISOString(),
      details
    };
    
    this.deletions.push(deletion);
    
    // Store in localStorage for persistence
    localStorage.setItem('team_deletions', JSON.stringify(this.deletions));
  }
  
  getDeletions() {
    return this.deletions;
  }
  
  getDeletionsByUser(userId) {
    return this.deletions.filter(d => d.deletedBy === userId);
  }
  
  getRecentDeletions(hours = 24) {
    const cutoff = new Date(Date.now() - hours * 60 * 60 * 1000);
    return this.deletions.filter(d => new Date(d.deletedAt) > cutoff);
  }
}
```

### 3. Team Deletion Safety Checks
```javascript
class TeamDeletionSafety {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async canDeleteTeam(teamId) {
    const checks = await Promise.all([
      this.hasActiveMembers(teamId),
      this.hasActiveProjects(teamId),
      this.isSystemTeam(teamId),
      this.hasPendingInvitations(teamId)
    ]);
    
    return {
      canDelete: checks.every(check => !check),
      issues: checks.filter(check => check),
      teamId
    };
  }
  
  async hasActiveMembers(teamId) {
    const members = await this.apiClient.makeRequest(`/org/team/members/${teamId}`);
    return members.items.length > 0;
  }
  
  async hasActiveProjects(teamId) {
    const projects = await this.apiClient.makeRequest(`/org/team/projects/${teamId}`);
    return projects.items.length > 0;
  }
  
  async isSystemTeam(teamId) {
    const team = await this.apiClient.makeRequest(`/org/team/${teamId}`);
    return team.isSystemTeam || false;
  }
  
  async hasPendingInvitations(teamId) {
    const invitations = await this.apiClient.makeRequest(`/org/team/invitations/${teamId}`);
    return invitations.items.length > 0;
  }
}
```
