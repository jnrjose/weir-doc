# Get Team Members

Retrieve a comprehensive list of all members belonging to a specific team, including their roles, permissions, and activity status. This endpoint supports pagination and filtering for large teams.

## Request

<RequestExample>
```bash cURL
curl -X GET "https://api-dev.weir.ai/org/team/members/team-123?page=1&limit=20" \
  -H "Authorization: Bearer your-console-token" \
  -H "x-source: console"
```

```javascript JavaScript
const response = await fetch('https://api-dev.weir.ai/org/team/members/team-123?page=1&limit=20', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer your-console-token',
    'x-source': 'console'
  }
});

const data = await response.json();
```

## Authentication

This endpoint requires console authentication with the following headers:

- `Authorization: Bearer your-console-token`
- `x-source: console`

## Path Parameters

<RequestField name="teamId" type="string" required>
  The unique identifier of the team to retrieve members for. Must be a valid team ID that exists in your organization.
</RequestField>

## Query Parameters

<RequestField name="page" type="integer" required="false">
  Page number for pagination. Defaults to 1 if not provided.
</RequestField>

<RequestField name="limit" type="integer" required="false">
  Number of members per page. Defaults to 20, maximum is 100.
</RequestField>

<RequestField name="search" type="string" required="false">
  Search term to filter members by name or email. Case-insensitive partial matching.
</RequestField>

<RequestField name="role" type="string" required="false">
  Filter members by role. Options: `Organization_User`, `Organization_Admin`, `Team_Manager`, `Team_Member`.
</RequestField>

<RequestField name="status" type="string" required="false">
  Filter members by status. Options: `active`, `inactive`, `pending`. Defaults to `active`.
</RequestField>

<RequestField name="sort" type="string" required="false">
  Sort order for members. Options: `name`, `email`, `role`, `joinedAt`, `lastActive`. Defaults to `name`.
</RequestField>

<RequestField name="order" type="string" required="false">
  Sort direction. Options: `asc`, `desc`. Defaults to `asc`.
</RequestField>

## Error Codes

| Code | Description | HTTP Status | Solution |
|------|-------------|-------------|----------|
| `TEAM_NOT_FOUND` | Team ID doesn't exist | 404 | Verify the team ID is correct |
| `INSUFFICIENT_PERMISSIONS` | User lacks permission to view team members | 403 | Check user role and permissions |
| `INVALID_PAGE_NUMBER` | Page number is invalid | 400 | Use a valid page number (≥ 1) |
| `INVALID_LIMIT` | Limit is invalid | 400 | Use a valid limit (1-100) |
| `INVALID_ROLE_FILTER` | Role filter is not supported | 400 | Use a valid role from the allowed list |
| `INVALID_STATUS_FILTER` | Status filter is invalid | 400 | Use 'active', 'inactive', or 'pending' |
| `INVALID_SORT_FIELD` | Sort field is not supported | 400 | Use a valid sort field |
| `RATE_LIMIT_EXCEEDED` | Too many requests | 429 | Wait before retrying |

## Rate Limits

- **100 requests per minute** per user
- **500 requests per minute** per organization
- **1000 requests per minute** per IP address

<Callout type="info">
Rate limits are enforced per user, organization, and IP address. Exceeding limits will result in a 429 status code with a `Retry-After` header.
</Callout>

## Usage Examples

### Basic Team Members Retrieval

```javascript
async function getTeamMembers(teamId, page = 1, limit = 20) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/team/members/${teamId}?page=${page}&limit=${limit}`, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console'
      }
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const data = await response.json();
    return data.data;
  } catch (error) {
    console.error('Failed to get team members:', error);
    throw error;
  }
}

// Usage
getTeamMembers('team-123', 1, 20)
  .then(members => {
    console.log(`Team "${members.team.name}" has ${members.items.length} members`);
    members.items.forEach(member => {
      console.log(`- ${member.firstName} ${member.lastName} (${member.role})`);
    });
  })
  .catch(error => {
    console.error('Failed to get team members:', error);
  });
```

### Team Members with Search and Filtering

```javascript
async function searchTeamMembers(teamId, searchTerm, filters = {}) {
  try {
    const params = new URLSearchParams({
      page: filters.page || 1,
      limit: filters.limit || 20,
      search: searchTerm,
      role: filters.role || '',
      status: filters.status || 'active',
      sort: filters.sort || 'name',
      order: filters.order || 'asc'
    });
    
    const response = await fetch(`https://api-dev.weir.ai/org/team/members/${teamId}?${params}`, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console'
      }
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const data = await response.json();
    return data.data;
  } catch (error) {
    console.error('Failed to search team members:', error);
    throw error;
  }
}

// Usage
searchTeamMembers('team-123', 'john', {
  role: 'Team_Manager',
  status: 'active',
  sort: 'lastActiveAt',
  order: 'desc'
})
  .then(members => {
    console.log(`Found ${members.items.length} members matching "john"`);
  });
```

### Load All Team Members with Pagination

```javascript
async function getAllTeamMembers(teamId) {
  const allMembers = [];
  let page = 1;
  let hasMore = true;
  
  while (hasMore) {
    try {
      const response = await getTeamMembers(teamId, page, 100); // Use maximum limit
      allMembers.push(...response.items);
      
      hasMore = response.pagination.hasNext;
      page++;
      
      // Add small delay to respect rate limits
      if (hasMore) {
        await new Promise(resolve => setTimeout(resolve, 100));
      }
    } catch (error) {
      console.error(`Failed to load page ${page}:`, error);
      break;
    }
  }
  
  return allMembers;
}

// Usage
getAllTeamMembers('team-123')
  .then(members => {
    console.log(`Loaded ${members.length} team members total`);
    members.forEach(member => {
      console.log(`- ${member.firstName} ${member.lastName} (${member.role})`);
    });
  });
```

### Team Members with Error Handling

```javascript
async function getTeamMembersWithErrorHandling(teamId, page = 1, limit = 20) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/team/members/${teamId}?page=${page}&limit=${limit}`, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console'
      }
    });
    
    const data = await response.json();
    
    if (!data.success) {
      switch (data.error.code) {
        case 'TEAM_NOT_FOUND':
          throw new Error('Team not found. Please check the team ID.');
        case 'INSUFFICIENT_PERMISSIONS':
          throw new Error('You do not have permission to view team members.');
        case 'INVALID_PAGE_NUMBER':
          throw new Error('Invalid page number. Please use a number greater than 0.');
        case 'INVALID_LIMIT':
          throw new Error('Invalid limit. Please use a number between 1 and 100.');
        case 'RATE_LIMIT_EXCEEDED':
          throw new Error('Too many requests. Please wait before trying again.');
        default:
          throw new Error(data.error.message);
      }
    }
    
    return data.data;
  } catch (error) {
    console.error('Failed to get team members:', error);
    throw error;
  }
}
```

### 1. Team Members Management

```javascript
class TeamMembersManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async getMembers(teamId, options = {}) {
    const params = {
      page: options.page || 1,
      limit: options.limit || 20,
      search: options.search || '',
      role: options.role || '',
      status: options.status || 'active',
```

### 2. Team Members Caching
```javascript
class TeamMembersCache {
  constructor(ttl = 300000) { // 5 minutes default TTL
    this.cache = new Map();
    this.ttl = ttl;
  }
  
  getCacheKey(teamId, params) {
    return `team_members_${teamId}_${JSON.stringify(params)}`;
  }
  
  get(teamId, params) {
    const key = this.getCacheKey(teamId, params);
    const item = this.cache.get(key);
    
    if (item && Date.now() - item.timestamp < this.ttl) {
      return item.data;
    }
    
    this.cache.delete(key);
    return null;
  }
  
  set(teamId, params, data) {
    const key = this.getCacheKey(teamId, params);
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
  }
  
  clear(teamId = null) {
    if (teamId) {
      // Clear cache for specific team
      for (const [key, value] of this.cache.entries()) {
        if (key.includes(`team_members_${teamId}_`)) {
          this.cache.delete(key);
        }
      }
    } else {
      // Clear all cache
      this.cache.clear();
    }
  }
  
  async getMembers(teamId, params, apiClient) {
    const cached = this.get(teamId, params);
    if (cached) {
      return cached;
    }
    
    const data = await apiClient.makeRequest(`/org/team/members/${teamId}?${new URLSearchParams(params)}`);
    this.set(teamId, params, data);
    
    return data;
  }
}
```

### 3. Team Members Analytics
```javascript
class TeamMembersAnalytics {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async getTeamStats(teamId) {
    const members = await this.apiClient.makeRequest(`/org/team/members/${teamId}?limit=1000`);
    
    const stats = {
      total: members.items.length,
      active: members.items.filter(m => m.status === 'active').length,
      inactive: members.items.filter(m => m.status === 'inactive').length,
      pending: members.items.filter(m => m.status === 'pending').length,
      byRole: {},
      verified: members.items.filter(m => m.isEmailVerified).length,
      recentlyActive: members.items.filter(m => {
        const lastActive = new Date(m.lastActiveAt);
        const oneWeekAgo = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000);
        return lastActive > oneWeekAgo;
      }).length
    };
    
    // Count by role
    members.items.forEach(member => {
      stats.byRole[member.role] = (stats.byRole[member.role] || 0) + 1;
    });
    
    return stats;
  }
  
  async getMemberActivity(teamId, memberId) {
    const member = await this.apiClient.makeRequest(`/org/team/member/${teamId}/${memberId}`);
    return {
      id: member.id,
      name: `${member.firstName} ${member.lastName}`,
      lastActive: member.lastActiveAt,
      joinedAt: member.joinedAt,
      daysSinceJoined: Math.floor((Date.now() - new Date(member.joinedAt)) / (1000 * 60 * 60 * 24)),
      daysSinceActive: Math.floor((Date.now() - new Date(member.lastActiveAt)) / (1000 * 60 * 60 * 24))
    };
  }
  
  async getInactiveMembers(teamId, daysInactive = 30) {
    const members = await this.apiClient.makeRequest(`/org/team/members/${teamId}?limit=1000`);
    const cutoffDate = new Date(Date.now() - daysInactive * 24 * 60 * 60 * 1000);
    
    return members.items.filter(member => {
      const lastActive = new Date(member.lastActiveAt);
      return lastActive < cutoffDate && member.status === 'active';
    });
  }
}
```
