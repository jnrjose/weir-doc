# Get Teams

Retrieve a paginated list of all teams within your organization. This endpoint supports filtering, sorting, and pagination to help you manage large numbers of teams efficiently.

## Request

<RequestExample>
```bash cURL
curl -X GET "https://api-dev.weir.ai/org/teams?page=1&limit=20" \
  -H "Authorization: Bearer your-console-token" \
  -H "x-source: console"
```

## Authentication

This endpoint requires console authentication with the following headers:

- `Authorization: Bearer your-console-token`
- `x-source: console`

## Query Parameters

<RequestField name="page" type="integer" required="false">
  Page number for pagination. Defaults to 1 if not provided.
</RequestField>

<RequestField name="limit" type="integer" required="false">
  Number of teams per page. Defaults to 20, maximum is 100.
</RequestField>

<RequestField name="search" type="string" required="false">
  Search term to filter teams by name. Case-insensitive partial matching.
</RequestField>

<RequestField name="sort" type="string" required="false">
  Sort order for teams. Options: `name`, `createdAt`, `memberCount`. Defaults to `name`.
</RequestField>

<RequestField name="order" type="string" required="false">
  Sort direction. Options: `asc`, `desc`. Defaults to `asc`.
</RequestField>

<RequestField name="status" type="string" required="false">
  Filter teams by status. Options: `active`, `inactive`. Defaults to `active`.
</RequestField>

## Error Codes

| Code | Description | HTTP Status | Solution |
|------|-------------|-------------|----------|
| `INSUFFICIENT_PERMISSIONS` | User lacks permission to view teams | 403 | Check user role and permissions |
| `INVALID_PAGE_NUMBER` | Page number is invalid | 400 | Use a valid page number (≥ 1) |
| `INVALID_LIMIT` | Limit is invalid | 400 | Use a valid limit (1-100) |
| `INVALID_SORT_FIELD` | Sort field is not supported | 400 | Use a valid sort field |
| `INVALID_SORT_ORDER` | Sort order is invalid | 400 | Use 'asc' or 'desc' |
| `INVALID_STATUS` | Status filter is invalid | 400 | Use 'active' or 'inactive' |
| `RATE_LIMIT_EXCEEDED` | Too many requests | 429 | Wait before retrying |

## Rate Limits

- **100 requests per minute** per user
- **500 requests per minute** per organization
- **1000 requests per minute** per IP address

<Callout type="info">
Rate limits are enforced per user, organization, and IP address. Exceeding limits will result in a 429 status code with a `Retry-After` header.
</Callout>

## Usage Examples

### Basic Teams Retrieval

```javascript
async function getTeams(page = 1, limit = 20) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/teams?page=${page}&limit=${limit}`, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${consoleToken}`,
        'x-source': 'console'
      }

    if (!response.ok) {

      console.log(`- ${team.name} (${team.memberCount} members)`);

  })
  .catch(error => {
    console.error('Failed to get teams:', error);
  });
```

### Load All Teams with Pagination

```javascript
async function getAllTeams() {
  const allTeams = [];
  let page = 1;
  let hasMore = true;
  
  while (hasMore) {
    try {
      const response = await getTeams(page, 100); // Use maximum limit
      allTeams.push(...response.items);
      
      hasMore = response.pagination.hasNext;
      page++;
      
      // Add small delay to respect rate limits
      if (hasMore) {
        await new Promise(resolve => setTimeout(resolve, 100));
      }
    } catch (error) {
      console.error(`Failed to load page ${page}:`, error);
      break;
    }
  }
  
  return allTeams;
}

// Usage
getAllTeams()
  .then(teams => {
    console.log(`Loaded ${teams.length} teams total`);
    teams.forEach(team => {
      console.log(`- ${team.name} (${team.memberCount} members)`);
    });
  });
```

```javascript
async function getTeamsWithErrorHandling(page = 1, limit = 20) {
  try {
    const response = await fetch(`https://api-dev.weir.ai/org/teams?page=${page}&limit=${limit}`, {
```

## Best Practices

### 1. Pagination Management
```javascript
class TeamsPaginationManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.currentPage = 1;
    this.pageSize = 20;
    this.totalPages = 0;
  }
  
  async loadPage(page) {
    const response = await this.apiClient.makeRequest(`/org/teams?page=${page}&limit=${this.pageSize}`);
    this.currentPage = page;
    this.totalPages = response.pagination.pages;
    return response;
  }
  
  async nextPage() {
    if (this.currentPage < this.totalPages) {
      return await this.loadPage(this.currentPage + 1);
    }
    throw new Error('No more pages available');
  }
  
  async previousPage() {
    if (this.currentPage > 1) {
      return await this.loadPage(this.currentPage - 1);
    }
    throw new Error('Already on first page');
  }
  
  hasNext() {
    return this.currentPage < this.totalPages;
  }
  
  hasPrevious() {
    return this.currentPage > 1;
  }
}
```

### 2. Teams Caching
```javascript
class TeamsCache {
  constructor(ttl = 300000) { // 5 minutes default TTL
    this.cache = new Map();
    this.ttl = ttl;
  }
  
  getCacheKey(params) {
    return `teams_${JSON.stringify(params)}`;
  }
  
  get(params) {
    const key = this.getCacheKey(params);
    const item = this.cache.get(key);
    
    if (item && Date.now() - item.timestamp < this.ttl) {
      return item.data;
    }
    
    this.cache.delete(key);
    return null;
  }
  
  set(params, data) {
    const key = this.getCacheKey(params);
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
  }
  
  clear() {
    this.cache.clear();
  }
  
  async getTeams(params, apiClient) {
    const cached = this.get(params);
    if (cached) {
      return cached;
    }
    
    const data = await apiClient.makeRequest(`/org/teams?${new URLSearchParams(params)}`);
    this.set(params, data);
    
    return data;
  }
}
```

### 3. Teams Search and Filtering
```javascript
class TeamsSearchManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.searchHistory = [];
  }
  
  async searchTeams(query, options = {}) {
    const searchParams = {
      search: query,
      page: options.page || 1,
      limit: options.limit || 20,
      sort: options.sort || 'name',
      order: options.order || 'asc',
      status: options.status || 'active'
    };
    
    // Add to search history
    this.searchHistory.push({
      query,
      params: searchParams,
      timestamp: Date.now()
    });
    
    return await this.apiClient.makeRequest(`/org/teams?${new URLSearchParams(searchParams)}`);
  }
  
  getSearchHistory() {
    return this.searchHistory;
  }
  
  clearSearchHistory() {
    this.searchHistory = [];
  }
  
  async getRecentSearches() {
    const recent = this.searchHistory
      .filter(item => Date.now() - item.timestamp < 3600000) // Last hour
      .sort((a, b) => b.timestamp - a.timestamp)
      .slice(0, 10);
    
    return recent.map(item => item.query);
  }
}
```
