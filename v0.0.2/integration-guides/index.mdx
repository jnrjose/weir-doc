## Integration Types

### 1. Real-time Integration
For applications that need immediate NIL detection and identity verification:

- **Use Case**: Live content monitoring, real-time user verification
- **API Category**: External APIs with webhook support
- **Best For**: Social media platforms, content management systems

### 2. Batch Processing Integration
For applications that process large volumes of content:

- **Use Case**: Bulk content analysis, scheduled monitoring
- **API Category**: Console APIs with batch processing
- **Best For**: Content management systems, media libraries

### 3. Administrative Integration
For applications that manage organizations and users:

- **Use Case**: User management, organization administration
- **API Category**: Console APIs and Admin APIs
- **Best For**: Internal dashboards, administrative tools

## Prerequisites

Before starting your integration, ensure you have:

- **Weir Account**: Sign up at [weir.ai](https://weir.ai)
- **API Credentials**: Obtain your Client ID and Secret Key
- **Development Environment**: Set up your development environment
- **Basic Knowledge**: Understanding of HTTP, REST APIs, and your chosen programming language

## Common Integration Patterns

### 1. Authentication Flow
```javascript
// Step 1: Get access token
const tokenResponse = await fetch('https://api-dev.weir.ai/auth/token', {
  method: 'POST',
  headers: {
    'Authorization': 'Basic ' + btoa(`${clientId}:${secretKey}`)
  }
});

const tokenData = await tokenResponse.json();
const accessToken = tokenData.data.accessToken;

// Step 2: Use token for API requests
const apiResponse = await fetch('https://api-dev.weir.ai/org/information', {
  headers: {
    'Authorization': `Bearer ${accessToken}`
  }
});
```

### 2. Error Handling Pattern
```javascript
async function makeWeirRequest(url, options = {}) {
  try {
    const response = await fetch(url, {
      ...options,
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(`Weir API Error: ${error.error.message}`);
    }
    
    return await response.json();
  } catch (error) {
    console.error('Weir API request failed:', error);
    throw error;
  }
}
```

### 3. Rate Limiting Pattern
```javascript
class WeirAPIClient {
  constructor(clientId, secretKey) {
    this.clientId = clientId;
    this.secretKey = secretKey;
    this.rateLimiter = new RateLimiter(1000, 3600000); // 1000 requests per hour
  }
  
  async makeRequest(url, options = {}) {
    await this.rateLimiter.waitForToken();
    
    try {
      return await makeWeirRequest(url, options);
    } catch (error) {
      if (error.message.includes('RATE_LIMIT_EXCEEDED')) {
        await this.rateLimiter.waitForReset();
        return this.makeRequest(url, options);
      }
      throw error;
    }
  }
}
```

## Security Best Practices

<Callout type="warning">
**Security Considerations**: Follow these security best practices for a secure integration.
</Callout>

### 1. Secure Credential Storage
```javascript
// Store credentials securely
const config = {
  clientId: process.env.WEIR_CLIENT_ID,
  secretKey: process.env.WEIR_SECRET_KEY,
  baseUrl: process.env.WEIR_BASE_URL || 'https://api-dev.weir.ai'
};
```

### 2. Token Management
```javascript
class TokenManager {
  constructor() {
    this.accessToken = null;
    this.tokenExpiry = null;
  }
  
  async getValidToken() {
    if (!this.accessToken || this.isTokenExpired()) {
      await this.refreshToken();
    }
    return this.accessToken;
  }
  
  async refreshToken() {
    const response = await fetch(`${config.baseUrl}/auth/token`, {
      method: 'POST',
      headers: {
        'Authorization': 'Basic ' + btoa(`${config.clientId}:${config.secretKey}`)
      }
    });
    
    const data = await response.json();
    this.accessToken = data.data.accessToken;
    this.tokenExpiry = Date.now() + (data.data.expiresIn * 1000);
  }
  
  isTokenExpired() {
    return !this.tokenExpiry || Date.now() >= this.tokenExpiry;
  }
}
```

### 3. Input Validation
```javascript
function validateWeirInput(input) {
  if (!input || typeof input !== 'object') {
    throw new Error('Invalid input: must be an object');
  }
  
  // Validate required fields
  const requiredFields = ['email', 'firstname', 'lastname'];
  for (const field of requiredFields) {
    if (!input[field]) {
      throw new Error(`Missing required field: ${field}`);
    }
  }
  
  // Validate email format
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(input.email)) {
    throw new Error('Invalid email format');
  }
  
  return true;
}
```

## Testing Your Integration

### 1. Unit Testing
```javascript
describe('Weir API Integration', () => {
  test('should authenticate successfully', async () => {
    const token = await weirClient.authenticate();
    expect(token).toBeDefined();
    expect(token.length).toBeGreaterThan(0);
  });
  
  test('should handle authentication errors', async () => {

  });
});
```


## Monitoring and Analytics

### 1. API Usage Monitoring
```javascript
class WeirAPIMonitor {
  constructor() {
    this.metrics = {
      requests: 0,
      errors: 0,
      responseTime: []
    };
  }
  
  async makeRequest(url, options = {}) {
    const startTime = Date.now();
    this.metrics.requests++;
    
    try {
      const response = await fetch(url, options);
      const responseTime = Date.now() - startTime;
      this.metrics.responseTime.push(responseTime);
      
      return response;
    } catch (error) {
      this.metrics.errors++;
      throw error;
    }
  }
  
  getMetrics() {
    return {
      ...this.metrics,
      averageResponseTime: this.metrics.responseTime.reduce((a, b) => a + b, 0) / this.metrics.responseTime.length,
      errorRate: this.metrics.errors / this.metrics.requests
    };
  }
}
```

### 2. Logging
```javascript
class WeirAPILogger {
  logRequest(url, options) {
    console.log(`[Weir API] Request: ${options.method || 'GET'} ${url}`);
  }
  
  logResponse(response, responseTime) {
    console.log(`[Weir API] Response: ${response.status} (${responseTime}ms)`);
  }
  
  logError(error, context) {
    console.error(`[Weir API] Error: ${error.message}`, context);
  }
}
```
