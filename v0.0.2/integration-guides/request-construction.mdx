# Constructing API Requests

Building effective API requests is crucial for successful integration with the Weir platform. This guide covers request construction patterns, best practices, and advanced techniques for optimal API usage.

## Request Structure Overview

Every API request follows a consistent structure with specific components:

```http
POST /api/endpoint HTTP/1.1
Host: api-dev.weir.ai
Authorization: Bearer your-access-token
Content-Type: application/json
x-source: console
x-request-id: req-123456

{
  "field1": "value1",
  "field2": "value2"
}
```

## Request Headers

### Required Headers

Every request must include these headers:

```javascript
const headers = {
  'Authorization': 'Bearer your-access-token',
  'Content-Type': 'application/json'
};
```

### Optional Headers

Additional headers for enhanced functionality:

```javascript
const headers = {
  'Authorization': 'Bearer your-access-token',
  'Content-Type': 'application/json',
  'x-source': 'console',                    // API category
  'x-request-id': 'req-123456',            // Request tracking
  'x-client-version': '1.0.0',             // Client version
  'x-user-agent': 'MyApp/1.0.0',           // Custom user agent
  'Accept': 'application/json',             // Response format
  'Accept-Language': 'en-US,en;q=0.9'      // Language preference
};
```

## URL Construction

### Base URL Structure

```
https://api-dev.weir.ai/    # Development
https://api.weir.ai/        # Production
```

### Path Parameters

Use path parameters for resource identification:

```javascript
// Single resource
const teamId = 'team-123';
const url = `https://api-dev.weir.ai/org/team/${teamId}`;

// Nested resources
const memberId = 'member-456';
const url = `https://api-dev.weir.ai/org/team/${teamId}/member/${memberId}`;
```

### Query Parameters

Use query parameters for filtering, sorting, and pagination:

```javascript
const params = new URLSearchParams({
  page: 1,
  limit: 20,
  search: 'development',
  sort: 'name',
  order: 'asc',
  status: 'active'
});

const url = `https://api-dev.weir.ai/org/teams?${params}`;
```

## Request Body Construction

### JSON Payloads

Most POST, PUT, and PATCH requests use JSON payloads:

```javascript
const requestBody = {
  name: 'Development Team',
  description: 'Software development team',
  settings: {
    notifications: true,
    privacy: 'private'
  }
};

const response = await fetch(url, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer your-token'
  },
  body: JSON.stringify(requestBody)
});
```

### Form Data

For file uploads and form submissions:

```javascript
const formData = new FormData();
formData.append('name', 'Development Team');
formData.append('description', 'Software development team');
formData.append('avatar', fileInput.files[0]);

const response = await fetch(url, {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer your-token'
    // Don't set Content-Type for FormData
  },
  body: formData
});
```

### URL-Encoded Data

For simple form submissions:

```javascript
const formData = new URLSearchParams({
  name: 'Development Team',

const response = await fetch(url, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded',
    'Authorization': 'Bearer your-token'
  },
  body: formData

```

## Error Handling in Requests

### Comprehensive Error Handling

```javascript
class APIRequestBuilder {
  constructor(baseUrl, token) {
    this.baseUrl = baseUrl;
    this.token = token;
  }
  
  async makeRequest(endpoint, options = {}) {
    try {
      const url = `${this.baseUrl}${endpoint}`;
      const config = {
        method: 'GET',
        headers: {
          'Authorization': `Bearer ${this.token}`,
          'Content-Type': 'application/json',
          ...options.headers
        },
        ...options
      };
      
      const response = await fetch(url, config);
      
      if (!response.ok) {
        await this.handleErrorResponse(response);
      }
      
      const data = await response.json();
      
      if (!data.success) {
        throw new Error(data.error.message);
      }
      
      return data.data;
    } catch (error) {
      console.error('API request failed:', error);
      throw error;
    }
  }
  
  async handleErrorResponse(response) {
    const error = await response.json();
    
    switch (response.status) {
      case 400:
        throw new Error(`Bad Request: ${error.error.message}`);
      case 401:
        throw new Error('Unauthorized: Please check your authentication');
      case 403:
        throw new Error('Forbidden: You do not have permission to access this resource');
      case 404:
        throw new Error('Not Found: The requested resource does not exist');
      case 429:
        throw new Error('Rate Limited: Please wait before making more requests');
      case 500:
        throw new Error('Internal Server Error: Please try again later');
      default:
        throw new Error(`Request failed: ${error.error.message}`);
    }
  }
}
```

## Request Validation

### Input Validation

Validate inputs before sending requests:

```javascript
class RequestValidator {
  static validateTeamData(data) {
    const errors = [];
    
    if (!data.name || data.name.trim().length === 0) {
      errors.push('Team name is required');
    }
    
    if (data.name && data.name.length > 100) {
      errors.push('Team name must be less than 100 characters');
    }
    
    if (data.description && data.description.length > 500) {
      errors.push('Description must be less than 500 characters');
    }
    
    return errors;
  }
  
  static validateEmail(email) {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return emailRegex.test(email);
  }
  
  static validatePagination(page, limit) {
    const errors = [];
    
    if (page && (page < 1 || !Number.isInteger(page))) {
      errors.push('Page must be a positive integer');
    }
    
    if (limit && (limit < 1 || limit > 100 || !Number.isInteger(limit))) {
      errors.push('Limit must be between 1 and 100');
    }
    
    return errors;
  }
}
```

### Pre-Request Validation

```javascript
async function createTeam(teamData) {
  // Validate input
  const errors = RequestValidator.validateTeamData(teamData);
  if (errors.length > 0) {
    throw new Error(`Validation failed: ${errors.join(', ')}`);
  }
  
  // Make request
  const response = await fetch('https://api-dev.weir.ai/org/create/team', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer your-token',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(teamData)
  });
  
  return response.json();
}
```

## Request Optimization

### Request Batching

Batch multiple requests for better performance:

```javascript
class RequestBatcher {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.batch = [];
    this.batchTimeout = null;
  }
  
  addRequest(request) {
    this.batch.push(request);
    
    if (this.batchTimeout) {
      clearTimeout(this.batchTimeout);
    }
    
    this.batchTimeout = setTimeout(() => {
      this.processBatch();
    }, 100); // 100ms batch window
  }
  
  async processBatch() {
    if (this.batch.length === 0) return;
    
    const requests = [...this.batch];
    this.batch = [];
    
    // Process requests in parallel
    const results = await Promise.allSettled(
      requests.map(request => this.apiClient.makeRequest(request))
    );
    
    return results;
  }
}
```

### Request Caching

Implement intelligent caching:

```javascript
class RequestCache {
  constructor(ttl = 300000) { // 5 minutes
    this.cache = new Map();
    this.ttl = ttl;
  }
  
  getCacheKey(method, url, body) {
    return `${method}:${url}:${JSON.stringify(body || {})}`;
  }
  
  get(method, url, body) {
    const key = this.getCacheKey(method, url, body);
    const item = this.cache.get(key);
    
    if (item && Date.now() - item.timestamp < this.ttl) {
      return item.data;
    }
    
    this.cache.delete(key);
    return null;
  }
  
  set(method, url, body, data) {
    const key = this.getCacheKey(method, url, body);
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
  }
  
  clear() {
    this.cache.clear();
  }
}
```

## Advanced Request Patterns

### Retry Logic with Exponential Backoff

```javascript
class RetryableRequest {
  constructor(maxRetries = 3, baseDelay = 1000) {
    this.maxRetries = maxRetries;
    this.baseDelay = baseDelay;
  }
  
  async makeRequest(url, options) {
    for (let i = 0; i < this.maxRetries; i++) {
      try {
        const response = await fetch(url, options);
        
        if (response.ok) {
          return response;
        }
        
        if (response.status === 429) {
          const retryAfter = response.headers.get('Retry-After') || Math.pow(2, i);
          await this.delay(retryAfter * 1000);
          continue;
        }
        
        if (response.status >= 500) {
          await this.delay(this.baseDelay * Math.pow(2, i));
          continue;
        }
        
        throw new Error(`Request failed: ${response.status}`);
      } catch (error) {
        if (i === this.maxRetries - 1) {
          throw error;
        }
        
        await this.delay(this.baseDelay * Math.pow(2, i));
      }
    }
  }
  
  delay(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}
```

### Request Interceptors

```javascript
class RequestInterceptor {
  constructor() {
    this.interceptors = {
      request: [],
      response: []
    };
  }
  
  addRequestInterceptor(interceptor) {
    this.interceptors.request.push(interceptor);
  }
  
  addResponseInterceptor(interceptor) {
    this.interceptors.response.push(interceptor);
  }
  
  async processRequest(config) {
    for (const interceptor of this.interceptors.request) {
      config = await interceptor(config);
    }
    return config;
  }
  
  async processResponse(response) {
    for (const interceptor of this.interceptors.response) {
      response = await interceptor(response);
    }
    return response;
  }
}
```

## Testing Requests

### Unit Tests

```javascript
describe('Request Construction', () => {
  test('should construct valid GET request', () => {
    const builder = new APIRequestBuilder('https://api-dev.weir.ai', 'token');
    const request = builder.buildGetRequest('/org/teams', { page: 1, limit: 20 });
    
    expect(request.method).toBe('GET');
    expect(request.url).toBe('https://api-dev.weir.ai/org/teams?page=1&limit=20');
    expect(request.headers.Authorization).toBe('Bearer token');
  });
  
  test('should construct valid POST request', () => {
    const builder = new APIRequestBuilder('https://api-dev.weir.ai', 'token');
    const request = builder.buildPostRequest('/org/create/team', {
      name: 'Test Team'
    });
    
    expect(request.method).toBe('POST');
    expect(request.body).toBe(JSON.stringify({ name: 'Test Team' }));
    expect(request.headers['Content-Type']).toBe('application/json');
  });
});
```

## Best Practices Summary

### 1. Always Validate Inputs
- Validate data before sending requests
- Use appropriate data types and formats
- Implement client-side validation

### 2. Handle Errors Gracefully
- Implement comprehensive error handling
- Provide meaningful error messages
- Log errors for debugging

### 3. Optimize Performance
- Use request caching where appropriate
- Implement request batching for bulk operations
- Use pagination for large datasets

### 4. Secure Your Requests
- Always use HTTPS
- Validate and sanitize inputs
- Implement proper authentication

### 5. Test Thoroughly
- Write unit tests for request construction
- Test error scenarios
- Validate response handling
