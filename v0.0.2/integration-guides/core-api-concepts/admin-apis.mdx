# Admin APIs

Admin APIs provide system-wide administrative functions and platform management capabilities. These APIs are designed for platform administrators, system operators, and internal tools that require elevated privileges and access to global platform data.

## Overview

Admin APIs are used by:
- **Platform administrators** for system management
- **Internal monitoring tools** for system health
- **Support systems** for customer assistance
- **Analytics platforms** for business intelligence
- **System maintenance tools** for platform operations

## Authentication

Admin APIs require **Admin Authentication** with elevated privileges:

### Admin Authentication Flow

```javascript
// 1. Admin login with special credentials
const adminLoginResponse = await fetch('https://api-dev.weir.ai/auth/authenticateAdmin', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    token: 'admin-access-token'
  })
});

const { data } = await adminLoginResponse.json();
const { accessToken, refreshToken } = data;

// 2. Use admin access token for subsequent requests
const organizationsResponse = await fetch('https://api-dev.weir.ai/admin/organizations', {
  headers: {
    'Authorization': `Bearer ${accessToken}`,
    'x-source': 'admin'
  }
});
```

### Admin Token Management

```javascript
class AdminAPIClient {
  constructor(adminToken) {
    this.adminToken = adminToken;
    this.accessToken = null;
    this.refreshToken = null;
  }
  
  async authenticate() {
    const response = await fetch('https://api-dev.weir.ai/auth/authenticateAdmin', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        token: this.adminToken
      })
    });
    
    if (!response.ok) {
      throw new Error('Admin authentication failed');
    }
    
    const { data } = await response.json();
    this.accessToken = data.accessToken;
    this.refreshToken = data.refreshToken;
    
    return data;
  }
  
  async makeRequest(endpoint, options = {}) {
    if (!this.accessToken) {
      await this.authenticate();
    }
    
    const response = await fetch(`https://api-dev.weir.ai${endpoint}`, {
      ...options,
      headers: {
        'Authorization': `Bearer ${this.accessToken}`,
        'x-source': 'admin',
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
    
    if (response.status === 401) {
      await this.authenticate();
      return this.makeRequest(endpoint, options);
    }
    
    return response.json();
  }
}
```

## Request Headers

Admin APIs require specific headers for proper functionality:

```javascript
const headers = {
  'Authorization': 'Bearer admin-access-token',
  'x-source': 'admin',                      // Required for Admin APIs
  'Content-Type': 'application/json',
  'x-admin-role': 'super-admin',           // Admin role level
  'x-request-id': 'admin-req-123456',      // Request tracking
  'x-client-version': 'admin-tool-1.0.0'   // Client version
};
```

## Admin Permissions

Admin APIs operate with different permission levels:

### Super Admin
- Full platform access
- All administrative functions
- System-wide data access
- Platform configuration

### Platform Admin
- Organization management
- User management
- Limited system access
- Support functions

### Support Admin
- User assistance
- Limited data access
- Support-specific functions
- Read-only system access

```javascript
class AdminPermissionManager {
  constructor(adminRole) {
    this.role = adminRole;
    this.permissions = this.getPermissionsForRole(adminRole);
  }
  
  getPermissionsForRole(role) {
    const permissionMap = {
      'super-admin': [
        'manage_organizations',
        'manage_users',
        'manage_platform',
        'view_system_logs',
        'manage_licenses',
        'system_configuration'
      ],
      'platform-admin': [
        'manage_organizations',
        'manage_users',
        'view_system_logs',
        'manage_licenses'
      ],
      'support-admin': [
        'view_users',
        'view_organizations',
        'assist_users'
      ]
    };
    
    return permissionMap[role] || [];
  }
  
  hasPermission(permission) {
    return this.permissions.includes(permission);
  }
  
  checkPermission(permission) {
    if (!this.hasPermission(permission)) {
      throw new Error(`Insufficient admin permissions: ${permission}`);
    }
  }
}
```

## Error Handling

Admin APIs return detailed error information for debugging:

```json
{
  "success": false,
  "error": {
    "code": "ADMIN_PERMISSION_DENIED",
    "message": "Insufficient admin privileges for this operation",
    "details": "Required permission: manage_platform",
    "adminRole": "support-admin",
    "requiredRole": "super-admin"
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
```

### Common Error Codes

| Code | Description | Action |
|------|-------------|--------|
| `ADMIN_AUTHENTICATION_FAILED` | Admin authentication failed | Check admin credentials |
| `ADMIN_PERMISSION_DENIED` | Insufficient admin privileges | Upgrade admin role |
| `ORGANIZATION_NOT_FOUND` | Organization doesn't exist | Verify organization ID |
| `USER_NOT_FOUND` | User doesn't exist | Verify user ID |
| `SYSTEM_ERROR` | Internal system error | Contact technical support |

## Best Practices

### 1. Audit Logging

```javascript
class AdminAuditLogger {
  constructor(apiClient) {
    this.apiClient = apiClient;
  }
  
  async logAdminAction(action, target, details = {}) {
    const auditLog = {
      action,
      target,
      details,
      timestamp: new Date().toISOString(),
      adminId: this.getCurrentAdminId(),
      ipAddress: this.getClientIP(),
      userAgent: navigator.userAgent
    };
    
    try {
      await this.apiClient.makeRequest('/admin/audit/log', {
        method: 'POST',
        body: JSON.stringify(auditLog)
      });
    } catch (error) {
      console.error('Failed to log admin action:', error);
    }
  }
  
  getCurrentAdminId() {
    // Get current admin ID from token or session
    return this.apiClient.getCurrentAdminId();
  }
  
  getClientIP() {
    // Get client IP address
    return this.apiClient.getClientIP();
  }
}
```

### 2. Bulk Operations

```javascript
class AdminBulkOperations {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.batchSize = 100;
  }
  
  async bulkUpdateUsers(users, updates) {
    const batches = this.createBatches(users, this.batchSize);
    const results = [];
    
    for (const batch of batches) {
      try {
        const response = await this.apiClient.makeRequest('/admin/users/bulk-update', {
          method: 'POST',
          body: JSON.stringify({
            users: batch,
            updates
          })
        });
        
        results.push(...response.data);
      } catch (error) {
        console.error(`Failed to update batch:`, error);
        // Continue with next batch
      }
    }
    
    return results;
  }
  
  async bulkSuspendOrganizations(organizationIds, reason) {
    const batches = this.createBatches(organizationIds, this.batchSize);
    const results = [];
    
    for (const batch of batches) {
      try {
        const response = await this.apiClient.makeRequest('/admin/organizations/bulk-suspend', {
          method: 'POST',
          body: JSON.stringify({
            organizationIds: batch,
            reason
          })
        });
        
        results.push(...response.data);
      } catch (error) {
        console.error(`Failed to suspend batch:`, error);
      }
    }
    
    return results;
  }
  
  createBatches(items, batchSize) {
    const batches = [];
    for (let i = 0; i < items.length; i += batchSize) {
      batches.push(items.slice(i, i + batchSize));
    }
    return batches;
  }
}
```

### 3. System Monitoring

```javascript
class AdminSystemMonitor {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.metrics = {
      apiCalls: 0,
      errors: 0,
      responseTime: 0
    };
  }
  
  async getSystemHealth() {
    const health = await this.apiClient.makeRequest('/admin/system/health');
    return health.data;
  }
  
  async getPlatformMetrics() {
    const metrics = await this.apiClient.makeRequest('/admin/platform/metrics');
    return metrics.data;
  }
  
  async getErrorLogs(filters = {}) {
    const logs = await this.apiClient.makeRequest('/admin/logs/errors', {
      method: 'POST',
      body: JSON.stringify(filters)
    });
    return logs.data;
  }
  
  async getAPIUsageStats() {
    const stats = await this.apiClient.makeRequest('/admin/api/usage-stats');
    return stats.data;
  }
  
  async monitorSystemHealth() {
    setInterval(async () => {
      try {
        const health = await this.getSystemHealth();
        if (health.status !== 'healthy') {
          await this.handleSystemIssue(health);
        }
      } catch (error) {
        console.error('System health check failed:', error);
      }
    }, 60000); // Check every minute
  }
  
  async handleSystemIssue(health) {
    // Send alert to monitoring system
    await this.apiClient.makeRequest('/admin/alerts/system-issue', {
      method: 'POST',
      body: JSON.stringify({
        issue: health.issues,
        timestamp: new Date().toISOString()
      })
    });
  }
}
```

## Integration Examples

### Admin Dashboard Integration

```javascript
class AdminDashboard {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.auditLogger = new AdminAuditLogger(apiClient);
  }
  
  async loadDashboardData() {
    const [organizations, users, systemHealth, metrics] = await Promise.all([
      this.apiClient.makeRequest('/admin/organizations'),
      this.apiClient.makeRequest('/admin/users'),
      this.apiClient.makeRequest('/admin/system/health'),
      this.apiClient.makeRequest('/admin/platform/metrics')
    ]);
    
    return {
      organizations: organizations.data,
      users: users.data,
      systemHealth: systemHealth.data,
      metrics: metrics.data
    };
  }
  
  async suspendOrganization(organizationId, reason) {
    await this.auditLogger.logAdminAction('suspend_organization', organizationId, { reason });
    
    const response = await this.apiClient.makeRequest(`/admin/organizations/${organizationId}/suspend`, {
      method: 'POST',
      body: JSON.stringify({ reason })
    });
    
    return response.data;
  }
  
  async resetUserPassword(userId) {
    await this.auditLogger.logAdminAction('reset_password', userId);
    
    const response = await this.apiClient.makeRequest(`/admin/users/${userId}/reset-password`, {
      method: 'POST'
    });
    
    return response.data;
  }
}
```

### Monitoring Tool Integration

```javascript
class AdminMonitoringTool {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.alerts = [];
  }
  
  async startMonitoring() {
    // Monitor system health
    setInterval(async () => {
      await this.checkSystemHealth();
    }, 30000);
    
    // Monitor API usage
    setInterval(async () => {
      await this.checkAPIUsage();
    }, 300000);
    
    // Monitor error rates
    setInterval(async () => {
      await this.checkErrorRates();
    }, 60000);
  }
  
  async checkSystemHealth() {
    try {
      const health = await this.apiClient.makeRequest('/admin/system/health');
      
      if (health.data.status !== 'healthy') {
        this.createAlert('system_health', health.data);
      }
    } catch (error) {
      this.createAlert('monitoring_error', { error: error.message });
    }
  }
  
  async checkAPIUsage() {
    try {
      const usage = await this.apiClient.makeRequest('/admin/api/usage-stats');
      
      if (usage.data.rateLimitExceeded > 0) {
        this.createAlert('rate_limit_exceeded', usage.data);
      }
    } catch (error) {
      this.createAlert('usage_monitoring_error', { error: error.message });
    }
  }
  
  createAlert(type, data) {
    const alert = {
      type,
      data,
      timestamp: new Date().toISOString(),
      severity: this.getSeverity(type)
    };
    
    this.alerts.push(alert);
    this.sendAlert(alert);
  }
  
  getSeverity(type) {
    const severityMap = {
      'system_health': 'high',
      'rate_limit_exceeded': 'medium',
      'monitoring_error': 'high'
    };
    
    return severityMap[type] || 'low';
  }
  
  async sendAlert(alert) {
    // Send alert to monitoring system
    await this.apiClient.makeRequest('/admin/alerts', {
      method: 'POST',
      body: JSON.stringify(alert)
    });
  }
}
```

## Security Considerations

### Admin Access Control

```javascript
class AdminAccessControl {
  constructor() {
    this.sessionTimeout = 15 * 60 * 1000; // 15 minutes
    this.lastActivity = Date.now();
  }
  
  checkSessionValidity() {
    if (Date.now() - this.lastActivity > this.sessionTimeout) {
      this.invalidateSession();
      return false;
    }
    return true;
  }
  
  updateActivity() {
    this.lastActivity = Date.now();
  }
  
  invalidateSession() {
    // Clear admin session
    localStorage.removeItem('admin_token');
    window.location.href = '/admin/login';
  }
  
  requireAdminRole(requiredRole) {
    const currentRole = this.getCurrentAdminRole();
    const roleHierarchy = ['support-admin', 'platform-admin', 'super-admin'];
    
    const currentLevel = roleHierarchy.indexOf(currentRole);
    const requiredLevel = roleHierarchy.indexOf(requiredRole);
    
    if (currentLevel < requiredLevel) {
      throw new Error(`Insufficient admin privileges. Required: ${requiredRole}`);
    }
  }
}
```
