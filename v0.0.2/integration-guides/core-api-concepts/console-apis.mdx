# Console APIs

Console APIs are designed for internal dashboard applications and administrative tools that provide user-facing interfaces for the Weir platform. These APIs require user authentication and provide access to organization-specific data and functionality.

## Overview

Console APIs are used by:
- **Dashboard applications** for end-user interfaces
- **Administrative tools** for platform management
- **Internal web applications** requiring user context
- **Console-based integrations** with user authentication

## Authentication

Console APIs use **Bearer Token Authentication** with user credentials:

### User Login Flow

```javascript
// 1. User login
const loginResponse = await fetch('https://api-dev.weir.ai/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    username: 'user@example.com',
    password: 'password123'
  })
});

const { data } = await loginResponse.json();
const { accessToken, refreshToken } = data;

// 2. Use access token for subsequent requests
const teamsResponse = await fetch('https://api-dev.weir.ai/org/teams', {
  headers: {
    'Authorization': `Bearer ${accessToken}`,
    'x-source': 'console'
  }
});
```

### Token Management

```javascript
class ConsoleAPIClient {
  constructor() {
    this.accessToken = localStorage.getItem('access_token');
    this.refreshToken = localStorage.getItem('refresh_token');
  }
  
  async makeRequest(endpoint, options = {}) {
    const token = await this.getValidToken();
    
    const response = await fetch(`https://api-dev.weir.ai${endpoint}`, {
      ...options,
      headers: {
        'Authorization': `Bearer ${token}`,
        'x-source': 'console',
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
    
    if (response.status === 401) {
      await this.refreshAccessToken();
      return this.makeRequest(endpoint, options);
    }
    
    return response.json();
  }
  
  async getValidToken() {
    if (!this.accessToken || this.isTokenExpired()) {
      await this.refreshAccessToken();
    }
    return this.accessToken;
  }
  
  async refreshAccessToken() {
    const response = await fetch('https://api-dev.weir.ai/auth/refresh/token', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        refreshToken: this.refreshToken
      })
    });
    
    const { data } = await response.json();
    this.accessToken = data.accessToken;
    this.refreshToken = data.refreshToken;
    
    localStorage.setItem('access_token', this.accessToken);
    localStorage.setItem('refresh_token', this.refreshToken);
  }
}
```

## Request Headers

Console APIs require specific headers for proper functionality:

```javascript
const headers = {
  'Authorization': 'Bearer your-access-token',
  'x-source': 'console',                    // Required for Console APIs
  'Content-Type': 'application/json',
  'x-request-id': 'req-123456',            // Optional: Request tracking
  'x-client-version': '1.0.0'              // Optional: Client version
};
```

## User Context

Console APIs operate within user context, providing access to:

### Organization Data
- Teams and team members
- User permissions and roles
- Organization settings
- User-specific preferences

### Scoped Access
- Users can only access data within their organization
- Role-based permissions control feature access
- Team-level access controls

```javascript
class UserContextAPI {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.userContext = null;
  }
  
  async loadUserContext() {
    const response = await this.apiClient.makeRequest('/auth/me');
    this.userContext = response.data;
    return this.userContext;
  }
  
  async getTeams() {
    if (!this.userContext) {
      await this.loadUserContext();
    }
    
    return this.apiClient.makeRequest('/org/teams');
  }
  
  async createTeam(teamData) {
    // Ensure user has permission to create teams
    if (!this.userContext?.permissions?.canCreateTeams) {
      throw new Error('Insufficient permissions to create teams');
    }
    
    return this.apiClient.makeRequest('/org/create/team', {
      method: 'POST',
      body: JSON.stringify(teamData)
    });
  }
}
```

## Error Handling

Console APIs return user-friendly error messages:

```json
{
  "success": false,
  "error": {
    "code": "INSUFFICIENT_PERMISSIONS",
    "message": "You do not have permission to perform this action",
    "details": "Contact your administrator to request access"
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
```

### Common Error Codes

| Code | Description | User Action |
|------|-------------|-------------|
| `AUTHENTICATION_REQUIRED` | User not logged in | Redirect to login page |
| `INSUFFICIENT_PERMISSIONS` | User lacks required permissions | Contact administrator |
| `TEAM_NOT_FOUND` | Team doesn't exist or not accessible | Check team ID or permissions |
| `INVALID_USER_DATA` | User data validation failed | Check input format |
| `RATE_LIMIT_EXCEEDED` | Too many requests | Wait and retry |

## Best Practices

### 1. Session Management

```javascript
class SessionManager {
  constructor() {
    this.sessionTimeout = 30 * 60 * 1000; // 30 minutes
    this.lastActivity = Date.now();
    this.setupActivityTracking();
  }
  
  setupActivityTracking() {
    // Track user activity
    ['click', 'keypress', 'scroll'].forEach(event => {
      document.addEventListener(event, () => {
        this.lastActivity = Date.now();
      });
    });
    
    // Check session timeout
    setInterval(() => {
      if (Date.now() - this.lastActivity > this.sessionTimeout) {
        this.handleSessionTimeout();
      }
    }, 60000); // Check every minute
  }
  
  handleSessionTimeout() {
    // Clear tokens and redirect to login
    localStorage.removeItem('access_token');
    localStorage.removeItem('refresh_token');
    window.location.href = '/login';
  }
}
```

### 2. Permission Checking

```javascript
class PermissionManager {
  constructor(userContext) {
    this.userContext = userContext;
  }
  
  canCreateTeams() {
    return this.userContext?.permissions?.canCreateTeams || false;
  }
  
  canManageTeam(teamId) {
    const team = this.userContext?.teams?.find(t => t.id === teamId);
    return team?.role === 'admin' || team?.role === 'owner';
  }
  
  canInviteMembers(teamId) {
    const team = this.userContext?.teams?.find(t => t.id === teamId);
    return ['admin', 'owner', 'manager'].includes(team?.role);
  }
  
  checkPermission(permission) {
    if (!this[permission]()) {
      throw new Error(`Insufficient permissions: ${permission}`);
    }
  }
}
```

### 3. Optimistic Updates

```javascript
class OptimisticConsoleAPI {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.pendingOperations = new Map();
  }
  
  async createTeam(teamData) {
    const tempId = `temp-${Date.now()}`;
    const optimisticTeam = {
      id: tempId,
      ...teamData,
      status: 'creating'
    };
    
    // Add to pending operations
    this.pendingOperations.set(tempId, {
      type: 'create',
      data: teamData,
      timestamp: Date.now()
    });
    
    try {
      const response = await this.apiClient.makeRequest('/org/create/team', {
        method: 'POST',
        body: JSON.stringify(teamData)
      });
      
      // Remove from pending operations
      this.pendingOperations.delete(tempId);
      
      return response.data;
    } catch (error) {
      // Remove from pending operations on error
      this.pendingOperations.delete(tempId);
      throw error;
    }
  }
  
  getPendingOperations() {
    return Array.from(this.pendingOperations.values());
  }
}
```

## Integration Examples

### React Integration

```jsx
import React, { createContext, useContext, useState, useEffect } from 'react';

const ConsoleAPIContext = createContext();

export const ConsoleAPIProvider = ({ children }) => {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [apiClient] = useState(new ConsoleAPIClient());

  useEffect(() => {
    loadUser();
  }, []);

  const loadUser = async () => {
    try {
      const userData = await apiClient.getUser();
      setUser(userData);
    } catch (error) {
      console.error('Failed to load user:', error);
    } finally {
      setLoading(false);
    }
  };

  const login = async (credentials) => {
    const response = await apiClient.login(credentials);
    setUser(response.user);
    return response;
  };

  const logout = async () => {
    await apiClient.logout();
    setUser(null);
  };

  return (
    <ConsoleAPIContext.Provider value={{
      user,
      loading,
      login,
      logout,
      apiClient
    }}>
      {children}
    </ConsoleAPIContext.Provider>
  );
};

export const useConsoleAPI = () => {
  const context = useContext(ConsoleAPIContext);
  if (!context) {
    throw new Error('useConsoleAPI must be used within ConsoleAPIProvider');
  }
  return context;
};
```

### Vue.js Integration

```javascript
// console-api.js
import { ref, reactive } from 'vue';

export function useConsoleAPI() {
  const user = ref(null);
  const loading = ref(false);
  const apiClient = new ConsoleAPIClient();

  const login = async (credentials) => {
    loading.value = true;
    try {
      const response = await apiClient.login(credentials);
      user.value = response.user;
      return response;
    } finally {
      loading.value = false;
    }
  };

  const logout = async () => {
    await apiClient.logout();
    user.value = null;
  };

  const getTeams = async () => {
    return apiClient.makeRequest('/org/teams');
  };

  const createTeam = async (teamData) => {
    return apiClient.makeRequest('/org/create/team', {
      method: 'POST',
      body: JSON.stringify(teamData)
    });
  };

  return {
    user,
    loading,
    login,
    logout,
    getTeams,
    createTeam
  };
}
```

## Monitoring and Analytics

### User Activity Tracking

```javascript
class UserActivityTracker {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.activity = [];
  }
  
  trackAction(action, data = {}) {
    this.activity.push({
      action,
      data,
      timestamp: Date.now(),
      userAgent: navigator.userAgent,
      url: window.location.href
    });
    
    // Send to analytics service
    this.sendToAnalytics(action, data);
  }
  
  async sendToAnalytics(action, data) {
    try {
      await this.apiClient.makeRequest('/analytics/track', {
        method: 'POST',
        body: JSON.stringify({
          action,
          data,
          timestamp: Date.now()
        })
      });
    } catch (error) {
      console.error('Failed to send analytics:', error);
    }
  }
}
```
