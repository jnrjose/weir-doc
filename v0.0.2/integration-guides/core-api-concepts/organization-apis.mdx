# Organization APIs

Organization APIs provide comprehensive management capabilities for organizations, teams, and user administration within the Weir platform. These APIs enable organizations to manage their structure, users, and resources effectively.

## Overview

Organization APIs are used for:
- **Organization management** and configuration
- **Team creation and management** within organizations
- **User administration** and role management
- **Resource allocation** and access control
- **Platform and client management** for organizations

## Authentication

Organization APIs use **Bearer Token Authentication** with organization context:

### Organization Context Authentication

```javascript
// 1. User login with organization context
const loginResponse = await fetch('https://api-dev.weir.ai/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    username: 'user@example.com',
    password: 'password123'
  })
});

const { data } = await loginResponse.json();
const { accessToken, organizationId } = data;

// 2. Use access token for organization-scoped requests
const orgInfoResponse = await fetch('https://api-dev.weir.ai/org/information', {
  headers: {
    'Authorization': `Bearer ${accessToken}`,
    'x-organization-id': organizationId
  }
});
```

### Organization-Scoped API Client

```javascript
class OrganizationAPIClient {
  constructor(accessToken, organizationId) {
    this.accessToken = accessToken;
    this.organizationId = organizationId;
  }
  
  async makeRequest(endpoint, options = {}) {
    const response = await fetch(`https://api-dev.weir.ai${endpoint}`, {
      ...options,
      headers: {
        'Authorization': `Bearer ${this.accessToken}`,
        'x-organization-id': this.organizationId,
        'Content-Type': 'application/json',
        ...options.headers
      }
    });
    
    if (!response.ok) {
      throw new Error(`API request failed: ${response.status}`);
    }
    
    return response.json();
  }
  
  // Organization-specific methods
  async getOrganizationInfo() {
    return this.makeRequest('/org/information');
  }
  
  async updateOrganizationInfo(updates) {
    return this.makeRequest('/org/information', {
      method: 'PATCH',
      body: JSON.stringify(updates)
    });
  }
}
```

## Request Headers

Organization APIs require specific headers for proper functionality:

```javascript
const headers = {
  'Authorization': 'Bearer your-access-token',
  'x-organization-id': 'org-123',          // Required for organization context
  'Content-Type': 'application/json',
  'x-source': 'console',                   // API source identifier
  'x-request-id': 'org-req-123456',       // Request tracking
  'x-client-version': 'org-tool-1.0.0'    // Client version
};
```

## Organization Context

Organization APIs operate within organization context, providing access to:

### Organization Data
- Organization information and settings
- Teams and team members
- Platforms and clients
- User roles and permissions

### Scoped Access
- Users can only access data within their organization
- Team-level access controls
- Role-based permissions within the organization

```javascript
class OrganizationContextManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.organizationContext = null;
  }
  
  async loadOrganizationContext() {
    const response = await this.apiClient.makeRequest('/org/information');
    this.organizationContext = response.data;
    return this.organizationContext;
  }
  
  async getTeams() {
    if (!this.organizationContext) {
      await this.loadOrganizationContext();
    }
    
    return this.apiClient.makeRequest('/org/teams');
  }
  
  async createTeam(teamData) {
    // Ensure user has permission to create teams
    if (!this.organizationContext?.permissions?.canCreateTeams) {
      throw new Error('Insufficient permissions to create teams');
    }
    
    return this.apiClient.makeRequest('/org/create/team', {
      method: 'POST',
      body: JSON.stringify(teamData)
    });
  }
  
  async inviteTeamMember(teamId, memberData) {
    // Ensure user has permission to invite members
    if (!this.organizationContext?.permissions?.canInviteMembers) {
      throw new Error('Insufficient permissions to invite members');
    }
    
    return this.apiClient.makeRequest(`/org/invite/team/member/${teamId}`, {
      method: 'POST',
      body: JSON.stringify(memberData)
    });
  }
}
```

## Error Handling

Organization APIs return organization-specific error messages:

```json
{
  "success": false,
  "error": {
    "code": "TEAM_NOT_FOUND",
    "message": "Team not found in your organization",
    "details": "The specified team ID does not exist or you do not have access to it",
    "organizationId": "org-123"
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
```

### Common Error Codes

| Code | Description | Action |
|------|-------------|--------|
| `ORGANIZATION_NOT_FOUND` | Organization doesn't exist | Verify organization ID |
| `TEAM_NOT_FOUND` | Team not found in organization | Check team ID and permissions |
| `INSUFFICIENT_PERMISSIONS` | User lacks required permissions | Contact organization admin |
| `MEMBER_ALREADY_EXISTS` | User is already a team member | Check existing members |
| `INVALID_TEAM_DATA` | Team data validation failed | Check input format |
| `RATE_LIMIT_EXCEEDED` | Organization rate limit exceeded | Wait and retry |

## Best Practices

### 1. Organization Data Caching

```javascript
class OrganizationDataCache {
  constructor(apiClient, ttl = 300000) { // 5 minutes
    this.apiClient = apiClient;
    this.cache = new Map();
    this.ttl = ttl;
  }
  
  async getOrganizationInfo() {
    const cacheKey = 'org-info';
    const cached = this.cache.get(cacheKey);
    
    if (cached && Date.now() - cached.timestamp < this.ttl) {
      return cached.data;
    }
    
    const response = await this.apiClient.makeRequest('/org/information');
    this.cache.set(cacheKey, {
      data: response.data,
      timestamp: Date.now()
    });
    
    return response.data;
  }
  
  async getTeams() {
    const cacheKey = 'teams';
    const cached = this.cache.get(cacheKey);
    
    if (cached && Date.now() - cached.timestamp < this.ttl) {
      return cached.data;
    }
    
    const response = await this.apiClient.makeRequest('/org/teams');
    this.cache.set(cacheKey, {
      data: response.data,
      timestamp: Date.now()
    });
    
    return response.data;
  }
  
  invalidateCache() {
    this.cache.clear();
  }
}
```

### 2. Team Management Operations

```javascript
class TeamManager {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.teams = new Map();
  }
  
  async createTeam(teamData) {
    const response = await this.apiClient.makeRequest('/org/create/team', {
      method: 'POST',
      body: JSON.stringify(teamData)
    });
    
    const team = response.data;
    this.teams.set(team.id, team);
    
    return team;
  }
  
  async getTeam(teamId) {
    if (this.teams.has(teamId)) {
      return this.teams.get(teamId);
    }
    
    const response = await this.apiClient.makeRequest(`/org/team/${teamId}`);
    const team = response.data;
    this.teams.set(teamId, team);
    
    return team;
  }
  
  async updateTeam(teamId, updates) {
    const response = await this.apiClient.makeRequest(`/org/team/${teamId}`, {
      method: 'PATCH',
      body: JSON.stringify(updates)
    });
    
    const updatedTeam = response.data;
    this.teams.set(teamId, updatedTeam);
    
    return updatedTeam;
  }
  
  async deleteTeam(teamId) {
    await this.apiClient.makeRequest(`/org/team/${teamId}`, {
      method: 'DELETE'
    });
    
    this.teams.delete(teamId);
  }
  
  async inviteMember(teamId, memberData) {
    const response = await this.apiClient.makeRequest(`/org/invite/team/member/${teamId}`, {
      method: 'POST',
      body: JSON.stringify(memberData)
    });
    
    // Refresh team data to include new member
    await this.getTeam(teamId);
    
    return response.data;
  }
}
```

### 3. Bulk Operations

```javascript
class OrganizationBulkOperations {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.batchSize = 50;
  }
  
  async bulkCreateTeams(teamsData) {
    const batches = this.createBatches(teamsData, this.batchSize);
    const results = [];
    
    for (const batch of batches) {
      try {
        const response = await this.apiClient.makeRequest('/org/teams/bulk-create', {
          method: 'POST',
          body: JSON.stringify({ teams: batch })
        });
        
        results.push(...response.data);
      } catch (error) {
        console.error(`Failed to create team batch:`, error);
        // Continue with next batch
      }
    }
    
    return results;
  }
  
  async bulkInviteMembers(teamId, membersData) {
    const batches = this.createBatches(membersData, this.batchSize);
    const results = [];
    
    for (const batch of batches) {
      try {
        const response = await this.apiClient.makeRequest(`/org/team/${teamId}/members/bulk-invite`, {
          method: 'POST',
          body: JSON.stringify({ members: batch })
        });
        
        results.push(...response.data);
      } catch (error) {
        console.error(`Failed to invite member batch:`, error);
      }
    }
    
    return results;
  }
  
  createBatches(items, batchSize) {
    const batches = [];
    for (let i = 0; i < items.length; i += batchSize) {
      batches.push(items.slice(i, i + batchSize));
    }
    return batches;
  }
}
```

## Integration Examples

### React Organization Dashboard

```jsx
import React, { createContext, useContext, useState, useEffect } from 'react';

const OrganizationContext = createContext();

export const OrganizationProvider = ({ children }) => {
  const [organization, setOrganization] = useState(null);
  const [teams, setTeams] = useState([]);
  const [loading, setLoading] = useState(true);
  const [apiClient] = useState(new OrganizationAPIClient());

  useEffect(() => {
    loadOrganizationData();
  }, []);

  const loadOrganizationData = async () => {
    try {
      const [orgInfo, teamsData] = await Promise.all([
        apiClient.getOrganizationInfo(),
        apiClient.getTeams()
      ]);
      
      setOrganization(orgInfo.data);
      setTeams(teamsData.data.items);
    } catch (error) {
      console.error('Failed to load organization data:', error);
    } finally {
      setLoading(false);
    }
  };

  const createTeam = async (teamData) => {
    const response = await apiClient.createTeam(teamData);
    setTeams(prev => [...prev, response.data]);
    return response;
  };

  const inviteMember = async (teamId, memberData) => {
    const response = await apiClient.inviteMember(teamId, memberData);
    // Refresh teams to get updated member count
    await loadOrganizationData();
    return response;
  };

  return (
    <OrganizationContext.Provider value={{
      organization,
      teams,
      loading,
      createTeam,
      inviteMember,
      loadOrganizationData
    }}>
      {children}
    </OrganizationContext.Provider>
  );
};

export const useOrganization = () => {
  const context = useContext(OrganizationContext);
  if (!context) {
    throw new Error('useOrganization must be used within OrganizationProvider');
  }
  return context;
};
```

### Vue.js Organization Management

```javascript
// organization-manager.js
import { ref, reactive } from 'vue';

export function useOrganizationManager() {
  const organization = ref(null);
  const teams = ref([]);
  const loading = ref(false);
  const apiClient = new OrganizationAPIClient();

  const loadOrganization = async () => {
    loading.value = true;
    try {
      const response = await apiClient.getOrganizationInfo();
      organization.value = response.data;
    } catch (error) {
      console.error('Failed to load organization:', error);
    } finally {
      loading.value = false;
    }
  };

  const loadTeams = async () => {
    loading.value = true;
    try {
      const response = await apiClient.getTeams();
      teams.value = response.data.items;
    } catch (error) {
      console.error('Failed to load teams:', error);
    } finally {
      loading.value = false;
    }
  };

  const createTeam = async (teamData) => {
    const response = await apiClient.createTeam(teamData);
    teams.value.push(response.data);
    return response;
  };

  const updateTeam = async (teamId, updates) => {
    const response = await apiClient.updateTeam(teamId, updates);
    const index = teams.value.findIndex(t => t.id === teamId);
    if (index !== -1) {
      teams.value[index] = response.data;
    }
    return response;
  };

  const deleteTeam = async (teamId) => {
    await apiClient.deleteTeam(teamId);
    teams.value = teams.value.filter(t => t.id !== teamId);
  };

  return {
    organization,
    teams,
    loading,
    loadOrganization,
    loadTeams,
    createTeam,
    updateTeam,
    deleteTeam
  };
}
```

## Monitoring and Analytics

### Organization Metrics

```javascript
class OrganizationMetrics {
  constructor(apiClient) {
    this.apiClient = apiClient;
    this.metrics = {
      teamCount: 0,
      memberCount: 0,
      platformCount: 0,
      clientCount: 0
    };
  }
  
  async loadMetrics() {
    try {
      const [teams, platforms, clients] = await Promise.all([
        this.apiClient.makeRequest('/org/teams'),
        this.apiClient.makeRequest('/org/platforms'),
        this.apiClient.makeRequest('/org/clients')
      ]);
      
      this.metrics.teamCount = teams.data.items.length;
      this.metrics.platformCount = platforms.data.items.length;
      this.metrics.clientCount = clients.data.items.length;
      
      // Calculate total member count
      let totalMembers = 0;
      for (const team of teams.data.items) {
        const membersResponse = await this.apiClient.makeRequest(`/org/team/members/${team.id}`);
        totalMembers += membersResponse.data.items.length;
      }
      this.metrics.memberCount = totalMembers;
      
      return this.metrics;
    } catch (error) {
      console.error('Failed to load organization metrics:', error);
      throw error;
    }
  }
  
  getMetrics() {
    return this.metrics;
  }
}
```
