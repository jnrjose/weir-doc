# Delete Payment Card

Remove a payment card from your organization.

<Warning>
  **Caution**: If this is the only payment card and you have active subscriptions, you may need to add another card first.
</Warning>

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.weir.ai/org/card/card_123456789' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'x-source: console'
```
</RequestExample>

<ResponseExample>
```json Success Response
{
  "message": "Card deleted successfully",
  "status": "success"
}
```
</ResponseExample>

## Path Parameters

<ParamField path="cardId" type="string" required>
Unique identifier of the card to delete.
</ParamField>

## Usage Examples

<CodeGroup>
```javascript JavaScript
const deleteCard = async (cardId, accessToken) => {
  const response = await fetch(`https://api.weir.ai/org/card/${cardId}`, {
    method: 'DELETE',
    headers: {
      'Authorization': `Bearer ${accessToken}`,
      'x-source': 'console'
    }
  });
  if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
  return await response.json();
};
```

```python Python
import requests

def delete_card(card_id, access_token):
    response = requests.delete(
        f'https://api.weir.ai/org/card/{card_id}',
        headers={
            'Authorization': f'Bearer {access_token}',
            'x-source': 'console'
        }
    )
    response.raise_for_status()
    return response.json()
```
</CodeGroup>
