# Get All Platforms

Retrieve a list of all platforms across all organizations (admin only).

<RequestExample>
```bash cURL
curl -X GET 'https://api.weir.ai/admin/platforms' \
  -H 'Authorization: Bearer YOUR_ADMIN_ACCESS_TOKEN'
```
</RequestExample>

## Usage Examples

<CodeGroup>
```javascript JavaScript
const getAllPlatforms = async (accessToken) => {
  const response = await fetch('https://api.weir.ai/admin/platforms', {
    headers: { 'Authorization': `Bearer ${accessToken}` }
  });
  if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
  return await response.json();
};
```

```python Python
import requests

def get_all_platforms(access_token):
    response = requests.get(
        'https://api.weir.ai/admin/platforms',
        headers={'Authorization': f'Bearer {access_token}'}
    )
    response.raise_for_status()
    return response.json()
```
</CodeGroup>
