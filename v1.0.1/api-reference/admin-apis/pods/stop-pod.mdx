# Stop Pod

Stop a pod completely and terminate all operations.

<RequestExample>
```bash cURL
curl -X POST 'https://api.weir.ai/pax/stop/pod/pod_123456789' \
  -H 'Authorization: Bearer YOUR_ADMIN_ACCESS_TOKEN'
```
</RequestExample>

<ResponseExample>
```json Success Response
{
  "data": {
    "podId": "pod_123456789",
    "status": "stopped",
    "stoppedAt": "2024-01-22T15:30:00Z"
  },
  "message": "Pod stopped successfully",
  "status": "success"
}
```
</ResponseExample>

## Path Parameters

<ParamField path="podId" type="string" required>
Unique pod identifier.
</ParamField>

## Usage Examples

<CodeGroup>
```javascript JavaScript
const stopPod = async (podId, accessToken) => {
  const response = await fetch(`https://api.weir.ai/pax/stop/pod/${podId}`, {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${accessToken}` }
  });
  if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
  return await response.json();
};
```

```python Python
import requests

def stop_pod(pod_id, access_token):
    response = requests.post(
        f'https://api.weir.ai/pax/stop/pod/{pod_id}',
        headers={'Authorization': f'Bearer {access_token}'}
    )
    response.raise_for_status()
    return response.json()
```
</CodeGroup>
