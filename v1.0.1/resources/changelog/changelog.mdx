# Weir AI API Changelog

<Update label="Version 1.0.1" description="Released October 2025">
## 🚀 New Features

### Team Management System
- **Create Team**: New endpoint to create teams with custom names and configurations
- **Invite Team Members**: Send invitations to team members with specific roles
- **Get Teams**: Retrieve all teams with pagination support
- **Delete Team**: Remove teams and clean up associated resources
- **Get Team Members**: List all members of a specific team
- **Update Team Member Role**: Modify member roles and permissions

### Enhanced Authentication
- **Mobile Registration**: New mobile-specific registration endpoint (`/auth/m/register`)
- **Resend Registration OTP**: Ability to resend OTP for registration validation
- **Validate Registration**: Enhanced registration validation with OTP verification
- **Improved Token Management**: Better refresh token handling and automatic token updates

### Platform Management
- **Create Platform**: Enhanced platform creation with team association
- **Get Platforms**: Retrieve all platforms with filtering options
- **Delete Platform**: Remove platforms and associated resources
- **Verify Platform**: New platform verification endpoint for domain validation

### Client Management
- **Create Client**: Enhanced client creation with environment specification
- **Get Clients**: Retrieve all clients with proper authentication
- **Refresh Client**: Regenerate client credentials and tokens
- **Delete Client**: Remove clients and clean up associated resources

### Talent and License Management
- **Get Agency Talent Roster**: Retrieve all talent associated with an agency
- **Invite Talent to Agency**: Send invitations to talent for agency collaboration
- **Search Agency Talent**: Advanced search functionality for talent discovery
- **Get Talent Licenses**: Retrieve all licenses for talent management
- **Create License by Agency**: Create licenses for talent with image upload support
- **Add Images to License**: Upload and manage license images
- **Remove Image from License**: Delete specific images from licenses

### Administrative Features
- **Pod Management**: Complete lifecycle management for pods
  - Create, Get, Start, Pause, Stop individual pods
  - Bulk operations for starting, pausing, and stopping all pods
- **Mail Template System**: Full CRUD operations for email templates
  - Create, Get, Update, Delete mail templates
- **Enhanced Logging**: Advanced logging capabilities
  - Create log entries with different types and schemes
  - Search logs with filtering and pagination
  - Get all logs with comprehensive filtering options

### User Management
- **Update User Profile**: Enhanced profile management with comprehensive fields
- **User Change Password**: Secure password change functionality
- **Get User Profile**: Retrieve complete user profile information

## 🔄 Breaking Changes

<Warning>
  **Important**: The following changes may require updates to your existing integrations.
</Warning>

### Authentication Changes
- **Token Format**: Access tokens now include additional metadata for better security
- **Refresh Token**: Refresh token expiration has been updated to 30 days (previously 7 days)
- **Header Requirements**: Some endpoints now require the `x-source` header to specify the API call type

### Response Format Changes
- **Team Management**: Team-related responses now include additional metadata fields
- **Platform Management**: Platform responses include verification status and team association
- **Client Management**: Client responses include environment information and creation timestamps
- **Error Responses**: Error responses now include more detailed error codes and descriptions

### Parameter Changes
- **Team Creation**: Team creation now requires a `name` parameter
- **Platform Creation**: Platform creation now includes `teamId` and `type` parameters
- **Client Creation**: Client creation now includes `environment` parameter
- **License Creation**: License creation now supports file uploads for images
